Genera un [Nx Plugin](https://nx.dev/extending-nx/intro/getting-started) completo en TypeScript con un servidor [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) integrado. Este generador crea una base para construir generadores personalizados que pueden ser utilizados sin problemas por asistentes de IA para la generación automatizada de código y el andamiaje de proyectos.

## Uso

### Generar un Nx Plugin

Puedes generar un TypeScript Nx Plugin de dos maneras:

<RunGenerator generator="ts#nx-plugin" />

### Opciones

<GeneratorParameters generator="ts#nx-plugin" />

## Salida del Generador

El generador creará la siguiente estructura de proyecto:

<FileTree>
- your-plugin/
  - src/
    - index.ts Empty entry point for your plugin
    - mcp-server/
      - index.ts Exports your server
      - server.ts Main MCP server configuration
      - stdio.ts Entry point for your MCP server with STDIO transport
      - http.ts Entry point for your MCP server with Streamable HTTP transport
      - tools/
        - create-workspace-command.ts Tool for workspace creation guidance
        - general-guidance.ts Tool for general Nx and plugin guidance
        - list-generators.ts Tool to list available generators
        - generator-guide.ts Tool for detailed generator information
      - utils.ts Utility functions for the MCP server
  - generators.json Nx generator configuration (initially empty)
  - package.json Plugin package configuration
  - tsconfig.json TypeScript configuration (CommonJS for Nx compatibility)
  - project.json Nx project configuration with build and package targets
</FileTree>

## Trabajar con tu Nx Plugin

### Agregar Generadores

Una vez que tengas tu proyecto de plugin, puedes agregar generadores usando el generador <Link path="/es/guides/nx-generator">`ts#nx-generator`</Link>:

<RunGenerator generator="ts#nx-generator" requiredParameters={{ project: 'your-plugin' }} />

Esto agregará un nuevo generador a tu plugin.

:::tip[Documentación del Generador]
Lee la <Link path="/es/guides/nx-generator">guía de `ts#nx-generator`</Link> para obtener detalles sobre cómo implementar generadores.
:::

Asegúrate de escribir un `README.md` detallado para tu generador, ya que esto es utilizado por la herramienta `generator-guide` del servidor MCP.

### Targets del Proyecto

El plugin generado incluye varios targets importantes:

#### Target Build
Compila tu código TypeScript y prepara el plugin para su uso:

<NxCommands commands={['build your-plugin']} />

#### Target Package
Crea un paquete distribuible listo para publicar en NPM:

<NxCommands commands={['package your-plugin']} />

El target package incluye todos los activos necesarios:
- Archivos JavaScript compilados
- Archivos de declaración TypeScript
- Archivos de configuración de generadores y ejecutores
- Archivos de documentación y licencia

## Integración del Servidor MCP

El plugin configura un servidor MCP usando el generador <Link path="/es/guides/ts-mcp-server">`ts#mcp-server`</Link>.

### Herramientas

El plugin incluye un servidor MCP completo que proporciona a los asistentes de IA las siguientes herramientas:

- `general-guidance`: Obtén mejores prácticas para trabajar con Nx y tu plugin
- `create-workspace-command`: Aprende cómo crear nuevos workspaces que puedan usar tu plugin
- `list-generators`: Lista todos los generadores disponibles en tu plugin
- `generator-guide`: Obtén información detallada sobre generadores específicos, incluyendo esquemas y uso

## Publicar tu Plugin

### Preparar para la Publicación

1. **Actualizar Información del Paquete**: Edita el [`package.json`](https://docs.npmjs.com/cli/v10/configuring-npm/package-json) de tu plugin con el nombre, versión, descripción e información del repositorio adecuados.

2. **Construir el Paquete**:
   <NxCommands commands={['package your-plugin']} />

3. **Probar Localmente**: Puedes probar tu plugin localmente instalándolo en otro workspace:
   ```bash
   npm install /path/to/your/workspace/dist/your-plugin/package
   ```

### Publicar en NPM

Una vez que tu plugin esté listo:

```bash
cd dist/your-plugin/package
npm publish
```

### Usar Plugins Publicados

Después de publicar, otros pueden instalar y usar tu plugin:

<InstallCommand pkg="your-plugin-name" />

Luego usar tus generadores:

<RunGenerator namespace="your-plugin-name" generator="your-generator-name" />

#### Configurar Asistentes de IA con tu Plugin Publicado

El servidor MCP de tu plugin publicado se puede configurar de la siguiente manera:

```json {3-6}
{
  "mcpServers": {
    "aws-nx-mcp": {
      "command": "npx",
      "args": ["-y", "-p", "your-plugin-name", "your-plugin-name-mcp-server"]
    }
  }
}
```
