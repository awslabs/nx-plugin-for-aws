Este generador se utiliza para conectar proyectos entre sí, como sitios web que llaman a APIs. Simplemente selecciona el proyecto de origen (por ejemplo, el proyecto que llamará a tu API) y el proyecto de destino (por ejemplo, tu proyecto de API), y este generador se encargará de integrar ambos.

:::tip[Dibújalo visualmente]
¿Prefieres diseñar tu espacio de trabajo primero? El <Link path="get_started/graph-builder">Graph Builder</Link> te permite arrastrar proyectos y dibujar las conexiones entre ellos, y luego te proporciona los comandos para estructurar todo.
:::

## Uso

### Ejecutar el Generador

<RunGenerator generator="connection" />

### Opciones

<GeneratorParameters generator="connection" />

:::note[Configuración de Runtime]
El generador de conexión hace uso de <Link path="guides/runtime-config">Runtime Configuration</Link> para pasar valores en tiempo de despliegue (como URLs de API, configuraciones de Cognito y ARNs de runtime de agentes) entre proyectos generados y componentes en tiempo de ejecución para que puedan descubrirse y conectarse entre sí.
:::

:::tip[Desarrollo Local]
Los proyectos conectados pueden ejecutarse en tu máquina con los targets `serve` y `dev`. Consulta la guía de <Link path="guides/local-development">Local Development</Link> para más detalles.
:::
