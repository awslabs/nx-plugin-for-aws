Nx Plugin for AWS proporciona un generador para integrar rápidamente tu <Link path="guides/ts-agent">TypeScript Agent</Link> con un sitio web React. Configura toda la configuración necesaria para conectarse a tu agente a través de tRPC sobre WebSocket, incluyendo soporte para autenticación con AWS IAM y Cognito. La integración proporciona seguridad de tipos completa de extremo a extremo entre tu frontend y el enrutador tRPC del agente.

## Requisitos previos

Antes de usar este generador, asegúrate de tener:

1. Un sitio web React (generado usando el <Link path="guides/react-website">generador `ts#website`</Link>)
2. Un TypeScript Agent (generado usando el <Link path="guides/ts-agent">generador `ts#agent`</Link>)
3. Cognito Auth agregado a través del <Link path="/guides/react-website-auth">generador `ts#website#auth`</Link>

## Uso

### Ejecutar el generador

## Salida del generador

El generador crea la siguiente estructura en tu aplicación React:

<FileTree>

- src
  - components
    - \<AgentName>AgentClientProvider.tsx Configura el cliente tRPC WebSocket y los enlaces al enrutador tRPC de tu agente
    - QueryClientProvider.tsx Proveedor del cliente TanStack React Query
  - hooks
    - useSigV4.tsx Hook para firmar solicitudes con SigV4 (solo IAM)
    - use\<AgentName>Agent.tsx Hooks que devuelven el proxy de opciones tRPC y el cliente tRPC vanilla

</FileTree>

Además, instala las dependencias requeridas:

  - `@trpc/client`
  - `@trpc/tanstack-react-query`
  - `@tanstack/react-query`
  - `aws4fetch` (si se usa autenticación IAM)

## Cómo funciona

### Conexión WebSocket

El cliente generado se conecta a tu Agent a través de tRPC sobre WebSocket. El agente expone un enrutador tRPC (incluyendo la suscripción `invoke` para transmitir respuestas del agente) sobre un endpoint WebSocket.

- **Desplegado**: El ARN del runtime del agente se carga desde la <Link path="guides/runtime-config">Configuración de Runtime</Link>. Ejecutar este generador de conexión también parchea el constructo CDK/Terraform generado del agente para publicar su ARN en el `runtime-config.json` del sitio web (bajo el namespace `connection`), por lo que solo los agentes que conectes explícitamente se exponen al frontend. El ARN se convierte a una URL WebSocket siguiendo el protocolo WebSocket de Bedrock AgentCore Runtime: `wss://bedrock-agentcore.<region>.amazonaws.com/runtimes/<encoded-arn>/ws`
- **Desarrollo local**: Al ejecutar con `dev`, la anulación de configuración de runtime establece el valor a una URL local `ws://` (por ejemplo, `ws://localhost:8081/ws`), y el cliente se conecta directamente

### Autenticación

El código generado maneja la autenticación dependiendo de la configuración de tu agente:

- **IAM** (predeterminado): Usa URLs prefirmadas de AWS SigV4 para autenticar la conexión WebSocket. Las credenciales se obtienen del Identity Pool de Cognito configurado con la autenticación de tu sitio web. En modo `dev`, la firma se omite automáticamente cuando <Link path="guides/react-website#runtime-configuration">`runtime-config.json`</Link> no está presente
- **Cognito**: Incrusta el token de acceso JWT en el encabezado `Sec-WebSocket-Protocol` como un token bearer codificado en base64url, siguiendo el [protocolo de autenticación WebSocket de AgentCore](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-get-started-websocket.html)

## Uso del código generado

### Uso de TanStack Query

El caso de uso más común es transmitir la respuesta del agente usando la suscripción `invoke` con el hook `use<AgentName>Agent`, que devuelve un [proxy de opciones tRPC](https://trpc.io/docs/client/tanstack-react-query) para usar con TanStack Query:

```tsx {1-2,7-22}
import { useSubscription } from '@trpc/tanstack-react-query';
import { useMyAgentAgent } from './hooks/useMyAgentAgent';

function ChatComponent() {
  const trpc = useMyAgentAgent();

  const subscription = useSubscription(
    trpc.invoke.subscriptionOptions(
      { prompt: 'What can you help me with?' },
      {
        enabled: true,
        onStarted: () => {
          console.log('Agent started responding');
        },
        onData: (token) => {
          console.log('Received token:', token);
        },
        onError: (error) => {
          console.error('Agent error:', error);
        },
      },
    ),
  );

  return (
    <div>
      <p>Status: {subscription.status}</p>
      {subscription.data && <p>Latest token: {subscription.data}</p>}
      {subscription.error && <p>Error: {subscription.error.message}</p>}
    </div>
  );
}
```

:::note[Proxy de opciones tRPC]
Para más detalles sobre el proxy de opciones tRPC y la integración con TanStack Query, consulta la [documentación de tRPC TanStack React Query](https://trpc.io/docs/client/tanstack-react-query).
:::

### Uso del cliente tRPC vanilla

El hook `use<AgentName>AgentClient` proporciona acceso al [cliente tRPC vanilla](https://trpc.io/docs/client/vanilla) para tener más control sobre el ciclo de vida de la suscripción:

```tsx {2,5,9-22,25}
import { useState } from 'react';
import { useMyAgentAgentClient } from './hooks/useMyAgentAgent';

function ChatComponent() {
  const client = useMyAgentAgentClient();
  const [messages, setMessages] = useState<string[]>([]);

  const sendMessage = (prompt: string) => {
    const subscription = client.invoke.subscribe(
      { prompt },
      {
        onData: (token) => {
          setMessages((prev) => [...prev, token]);
        },
        onComplete: () => {
          console.log('Agent finished');
        },
        onError: (error) => {
          console.error('Error:', error);
        },
      },
    );

    // Clean up when done
    return () => subscription.unsubscribe();
  };

  return (
    <div>
      <button onClick={() => sendMessage('Hello!')}>Send</button>
      <div>
        {messages.map((msg, i) => (
          <span key={i}>{msg}</span>
        ))}
      </div>
    </div>
  );
}
```

:::note[Cliente tRPC vanilla]
Para más detalles sobre el cliente tRPC vanilla, consulta la [documentación del cliente Vanilla de tRPC](https://trpc.io/docs/client/vanilla).
:::

## Desarrollo local

El generador de conexión configura automáticamente la integración `dev` para tu sitio web react:

1. Ejecutar `nx dev <website>` también iniciará el servidor local del agente
2. La configuración de runtime se anula para apuntar a la URL WebSocket local (por ejemplo, `ws://localhost:8081/ws`)
3. Al igual que con las APIs conectadas, la autenticación se omite en modo `dev` cuando <Link path="guides/react-website#runtime-configuration">`runtime-config.json`</Link> no está presente

:::tip[Hot Reloading]
El sitio web y el agente conectado se recargarán en caliente, permitiéndote iterar rápidamente en ambos juntos sin desplegar a AWS.
:::

## Seguridad de tipos

La integración proporciona seguridad de tipos completa de extremo a extremo. Tu IDE proporcionará autocompletado completo y verificación de tipos para todas las llamadas a procedimientos del agente. Los tipos se infieren automáticamente de la definición del enrutador tRPC de tu agente, asegurando que cualquier cambio en la API de tu agente se refleje inmediatamente en tu código frontend.
