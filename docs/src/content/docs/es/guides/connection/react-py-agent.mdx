Nx Plugin for AWS proporciona un generador para integrar rápidamente tu <Link path="guides/py-agent">Python Agent</Link> con un sitio web React. Configura toda la configuración necesaria para conectarse a tu agente a través de un cliente generado por OpenAPI con seguridad de tipos, incluyendo soporte para autenticación AWS IAM y Cognito.

:::tip[Agentes AG-UI]
Si tu Python Agent fue generado con `protocol=ag-ui`, el generador de conexión en su lugar configura [CopilotKit](https://docs.copilotkit.ai/aws-strands) y un `HttpAgent` de [`@ag-ui/client`](https://docs.ag-ui.com/) en el sitio web React. Consulta la guía <Link path="guides/connection/react-agui">React a AG-UI Agent</Link> para más detalles.
:::

## Requisitos previos

Antes de usar este generador, asegúrate de tener:

1. Un sitio web React (generado usando el <Link path="guides/react-website">generador `ts#website`</Link>)
2. Un Python Agent con `protocol=http` (generado usando el <Link path="guides/py-agent">generador `py#agent`</Link>)
3. Cognito Auth agregado a través del <Link path="/guides/react-website-auth">generador `ts#website#auth`</Link>

## Uso

### Ejecutar el generador

<RunGenerator generator="connection" />

Se te pedirá que selecciones tu sitio web React como el proyecto de origen y el proyecto que contiene tu Python Agent como el proyecto de destino. Si tu proyecto de destino contiene múltiples componentes (como múltiples agentes u otros tipos de componentes), se te pedirá que especifiques un `targetComponent` para desambiguar.

`targetComponent` acepta el `--name` que le diste al generador del agente en cualquier formato de mayúsculas/minúsculas (`ResearchAgent`, `research-agent`), la ruta del componente relativa a la raíz del proyecto de destino, o su id de generador.

## Salida del generador

El generador crea lo siguiente en tu proyecto Python Agent:

<FileTree>

- scripts
  - \<agent_name>_openapi.py Script to generate an OpenAPI specification from the agent's FastAPI app
- project.json A new `<agent-name>-openapi` target is added

</FileTree>

El generador crea la siguiente estructura en tu aplicación React:

<FileTree>

- src
  - components
    - \<AgentName>Provider.tsx Provider for the OpenAPI client
    - QueryClientProvider.tsx TanStack React Query client provider
  - hooks
    - useSigV4.tsx Hook for signing requests with SigV4 (IAM only)
    - use\<AgentName>.tsx Hook returning the TanStack Query options proxy for your agent's API
    - use\<AgentName>Client.tsx Hook returning the vanilla API client
  - generated
    - \<agent-name>
      - types.gen.ts Generated types from the agent's Pydantic models
      - client.gen.ts Type-safe client for calling your agent's API
      - options-proxy.gen.ts TanStack Query hooks options for interacting with your agent
- project.json Targets added for client generation and watching for changes
- .gitignore The generated client files are ignored by default

</FileTree>

## Cómo funciona

### Generación del cliente OpenAPI

En tiempo de compilación, la aplicación FastAPI del Python Agent se inspecciona para generar una especificación OpenAPI. Esta especificación se utiliza luego para generar un cliente TypeScript con seguridad de tipos con hooks de TanStack Query, siguiendo el mismo patrón que la <Link path="guides/connection/react-fastapi">conexión React a FastAPI</Link>.

Cada agente obtiene su propio script OpenAPI con alcance (por ejemplo, `scripts/agent_openapi.py`) para que los proyectos con múltiples agentes puedan generar especificaciones individuales.

### Configuración en tiempo de ejecución

Ejecutar este generador de conexión también parchea el constructo CDK/Terraform generado del agente para publicar su ARN de tiempo de ejecución AgentCore en el `runtime-config.json` del sitio web (bajo el espacio de nombres `connection`), por lo que solo los agentes que conectes explícitamente están expuestos al frontend. Consulta <Link path="guides/runtime-config">Configuración en tiempo de ejecución</Link> para más detalles.

### Autenticación

El código generado maneja la autenticación dependiendo de la configuración de tu agente:

- **IAM** (predeterminado): Usa AWS SigV4 para firmar solicitudes HTTP. Las credenciales se obtienen del Identity Pool de Cognito configurado con la autenticación de tu sitio web
- **Cognito**: Incrusta el token de acceso JWT en un encabezado Authorization
- **None**: Sin autenticación

## Uso del código generado

### Uso del hook de API

El hook `use<AgentName>` proporciona opciones de TanStack Query para llamar a los endpoints de la API de tu agente:

```tsx
import { useState } from 'react';
import { useMutation } from '@tanstack/react-query';
import { useMyAgent } from '../hooks/useMyAgent';
import type { StreamChunk } from '../generated/my-agent/types.gen';

function ChatComponent() {
  const api = useMyAgent();
  const [chunks, setChunks] = useState<StreamChunk[]>([]);

  const invoke = useMutation(api.invoke.mutationOptions({
    onSuccess: async (stream) => {
      setChunks([]);
      for await (const chunk of stream) {
        setChunks((prev) => [...prev, chunk]);
      }
    },
  }));

  const handleSend = (prompt: string) => {
    invoke.mutate({ prompt });
  };

  return (
    <div>
      <button onClick={() => handleSend('Hello!')}>Send</button>
      {invoke.isPending && <p>Agent is thinking...</p>}
      {chunks.map((chunk, i) => (
        <span key={i}>{chunk.content}</span>
      ))}
    </div>
  );
}
```

### Uso del cliente vanilla

El hook `use<AgentName>Client` proporciona acceso directo al cliente de API:

```tsx
import { useState } from 'react';
import { useMyAgentClient } from '../hooks/useMyAgentClient';
import type { StreamChunk } from '../generated/my-agent/types.gen';

function ChatComponent() {
  const client = useMyAgentClient();
  const [chunks, setChunks] = useState<StreamChunk[]>([]);

  const handleSend = async (prompt: string) => {
    setChunks([]);
    for await (const chunk of client.invoke({ prompt })) {
      setChunks((prev) => [...prev, chunk]);
    }
  };

  return (
    <div>
      <button onClick={() => handleSend('Hello!')}>Send</button>
      {chunks.map((chunk, i) => (
        <span key={i}>{chunk.content}</span>
      ))}
    </div>
  );
}
```

## Desarrollo local

El generador de conexión configura automáticamente la integración `dev`:

1. Ejecutar `nx dev <website>` también iniciará el servidor FastAPI local del agente
2. La configuración en tiempo de ejecución se sobrescribe para apuntar a la URL HTTP local (por ejemplo, `http://localhost:8081/`)
3. El cliente TypeScript se regenera automáticamente cuando cambia la API del agente

<NxCommands commands={['dev <WebsiteProject>']} />

:::tip[Hot Reloading]
El sitio web y el agente conectado se recargarán en caliente, lo que te permite iterar rápidamente en ambos juntos sin implementar en AWS.
:::
