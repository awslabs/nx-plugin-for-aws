Esta guía te acompaña a través de un ejemplo de migración de un proyecto [AWS PDK](https://github.com/aws/aws-pdk) al Nx Plugin para AWS, además de proporcionar orientación general sobre este tema.

Migrar al Nx Plugin para AWS proporciona los siguientes beneficios sobre PDK:

- Compilaciones más rápidas
- Más fácil de usar (UI y CLI)
- Amigable con vibe-coding (<Link path="/get_started/building-with-ai">¡prueba nuestro servidor MCP!</Link>)
- Tecnologías más modernas
- Desarrollo local de API y sitios web
- Más control (modifica archivos generados para adaptarlos a tu caso de uso)
- ¡Y más!

:::caution[No es una Guía Paso a Paso]
Hay muchos matices y consideraciones al migrar un proyecto. Esta guía es para un ejemplo simple, y puede haber pasos faltantes aquí que sean necesarios para tu proyecto.

Esta guía opta por un enfoque donde creamos un espacio de trabajo nuevo y copiamos piezas de nuestro proyecto PDK a un nuevo proyecto. Si necesitas migrar de manera diferente, o tienes alguna pregunta sobre cómo pasar de PDK al Nx Plugin para AWS, [¡comunícate en las discusiones de GitHub](https://github.com/awslabs/nx-plugin-for-aws/discussions)!

Ten en cuenta también que algunas características de PDK no tienen equivalentes exactos. Consulta la sección de [Preguntas Frecuentes](#preguntas-frecuentes) para algunas sugerencias/ideas sobre estas.
:::

:::caution[Guía en un Punto en el Tiempo]
Esta guía está escrita como una guía en un punto en el tiempo y muy probablemente no se actualizará a medida que el Nx Plugin para AWS evolucione. Para compensar esto, la guía fija la versión de `@aws/nx-plugin` a `1.0.0-rc.47`. Puedes intentar con la última versión si sigues la guía, pero puede haber algunas desviaciones de la misma.
:::

## Ejemplo de Migración: Aplicación de Lista de Compras

En esta guía, usaremos la [Aplicación de Lista de Compras del Tutorial de PDK](https://aws.github.io/aws-pdk/getting_started/shopping_list_app.html) como nuestro proyecto objetivo a migrar. Sigue los pasos en ese tutorial para crear el proyecto objetivo si deseas seguir la guía tú mismo.

La aplicación de lista de compras consiste en los siguientes tipos de proyecto PDK:

- `MonorepoTsProject`
- `TypeSafeApiProject`
- `CloudscapeReactTsWebsiteProject`
- `InfrastructureTsProject`

### Crear Espacio de Trabajo

Para comenzar, crearemos un nuevo espacio de trabajo para nuestro nuevo proyecto. Aunque es más extremo que una migración in situ, este enfoque nos da el resultado final más limpio. Crear un espacio de trabajo Nx es equivalente a usar el `MonorepoTsProject` de PDK:

<CreateNxWorkspaceCommand workspace="shopping-list" iac="cdk" tag="1.0.0-rc.47" />

Abre el directorio `shopping-list` que este comando crea en tu IDE favorito.
