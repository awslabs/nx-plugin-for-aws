title: Empaquetado de TypeScript

import NxCommands from '@components/nx-commands.astro';

El generador configura automáticamente un target `bundle` que utiliza [Rolldown](https://rolldown.rs/) para crear un paquete de despliegue:

<NxCommands commands={['bundle <project-name>']} />

La configuración de Rolldown se encuentra en `rolldown.config.ts`, con una entrada por cada bundle a generar. Rolldown gestiona la creación de múltiples bundles en paralelo si están definidos.

:::tip[Configuración Personalizada]
Puedes ajustar la configuración de Rolldown en `rolldown.config.ts`, por ejemplo, si tienes dependencias que dependen de rutas de archivos y no pueden ser empaquetadas, puedes agregarlas a la lista de módulos `external`.
:::
