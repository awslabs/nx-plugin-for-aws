### Archivos de Configuración

La mayoría de los asistentes de IA que soportan MCP utilizan un enfoque de configuración similar. Necesitarás crear o actualizar un archivo de configuración con los detalles de tu servidor MCP:

```json
{
  "mcpServers": {
    "your-mcp-server": {
      "command": "uv",
      "args": [
        "run",
        "python",
        "-m",
        "my_module.mcp_server.stdio"
      ],
      "env": {
        "VIRTUAL_ENV": "/path/to/your/project/.venv"
      }
    }
  }
}
```

:::caution[Resolución de Rutas]
Si recibes un error como `ENOENT uv` al conectarte a tu servidor, es posible que necesites especificar la ruta completa a `uv`, la cual puedes obtener ejecutando `which uv` en tu terminal.
:::
