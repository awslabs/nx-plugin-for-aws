### Archivos de Configuración

La mayoría de los asistentes de IA que soportan MCP utilizan un enfoque de configuración similar. Necesitarás crear o actualizar un archivo de configuración con los detalles de tu servidor MCP:

```json
{
  "mcpServers": {
    "your-mcp-server": {
      "command": "npx",
      "args": ["tsx", "/path/to/your-mcp-server/stdio.ts"]
    }
  }
}
```

:::caution[Resolución de Rutas]
Si recibes un error como `ENOENT npx` al conectarte a tu servidor, es posible que necesites especificar la ruta completa a `npx`, la cual puedes obtener ejecutando `which npx` en tu terminal.
:::

### Recarga en Caliente

Mientras desarrollas tu servidor MCP, es posible que desees configurar la bandera `--watch` para que el asistente de IA siempre vea las últimas versiones de herramientas/recursos:

```json {5}
{
  "mcpServers": {
    "your-mcp-server": {
      "command": "npx",
      "args": ["tsx", "--watch", "/path/to/your-mcp-server/stdio.ts"]
    }
  }
}
```

:::note[Actualización de Herramientas]
Si agregas nuevas herramientas o recursos, es posible que necesites actualizar tu servidor MCP en el asistente de IA.
:::
