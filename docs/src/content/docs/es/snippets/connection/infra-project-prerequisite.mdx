:::note[Proyecto de infraestructura requerido]
Los generadores de agente, servidor MCP y Gateway envían sus constructos y módulos a `packages/common`, pero no crean una aplicación desde la cual desplegarlos — por lo que `packages/infra` no existe hasta que lo generes. Ejecuta el generador <Link path="guides/typescript-infrastructure">`ts#infra`</Link> (CDK) o el generador <Link path="guides/terraform-project">`terraform#project`</Link> (Terraform) antes de editar el archivo a continuación.
:::
