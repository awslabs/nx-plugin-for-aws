---
title: Credenciales de Administrador
---
import Infrastructure from '@components/infrastructure.astro';

La contraseña del usuario administrador (master) de Aurora es generada y rotada por Aurora mismo en AWS Secrets Manager, utilizando [contraseñas de usuario master administradas por RDS](https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/rds-secrets-manager.html). Tu código de infraestructura nunca recibe la contraseña, por lo que no puede filtrarse en una plantilla de CloudFormation o archivo de estado de Terraform. Aurora rota el secreto cada 7 días sin ninguna función de rotación que desplegar o mantener.

El secreto está cifrado con la misma clave KMS administrada por el cliente que el clúster.

Tu aplicación nunca usa estas credenciales. Se conecta como un usuario de base de datos con privilegios mínimos usando autenticación IAM — solo los manejadores de migración y create-db-user leen el secreto de administrador, y a cada uno se le otorga acceso solo a ese secreto y su clave KMS.

<Infrastructure>
<Fragment slot="cdk">

El secreto de administrador está expuesto como `secret.secretArn` en el clúster subyacente, y `grantSecretRead` otorga a un consumidor acceso de lectura a él:

```ts title="packages/infra/src/stacks/application-stack.ts"
import { MyDatabase } from '@my-scope/common-constructs';

const db = new MyDatabase(this, 'Db', { ... });

db.grantSecretRead(myFunction);
```
</Fragment>
<Fragment slot="terraform">

El ARN del secreto de administrador está expuesto como la salida `secret_arn`, junto con el `kms_key_arn` necesario para descifrarlo:

```hcl title="packages/infra/src/main.tf"
module "my_database" {
  source = "../../common/terraform/src/app/dbs/my-database"
  ...
}

output "database_secret_arn" {
  value = module.my_database.secret_arn
}
```

Un secreto administrado por RDS contiene un objeto JSON con `username` y `password` solamente — sin detalles de conexión. Toma el host, puerto y nombre de base de datos de las salidas `writer_endpoint`, `cluster_port` y `database_name` del módulo.
</Fragment>
</Infrastructure>
