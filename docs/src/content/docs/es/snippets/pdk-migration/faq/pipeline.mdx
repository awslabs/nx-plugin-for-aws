PDK proporcionaba un [`PDKPipelineProject`](https://aws.github.io/aws-pdk/developer_guides/pipeline/index.html) que configuraba un proyecto de infraestructura CDK y hacía uso de un constructo CDK que envolvía algunos recursos de [CDK Pipelines](https://docs.aws.amazon.com/cdk/api/v2/docs/aws-cdk-lib.pipelines-readme.html).

Para migrar desde esto, puedes usar los constructos de CDK Pipelines directamente. Sin embargo, en la práctica es probable que sea más sencillo usar algo como GitHub actions o GitLab CI/CD, donde defines [CDK Stages](https://docs.aws.amazon.com/cdk/v2/guide/stages.html) y ejecutas el comando deploy para el stage apropiado directamente.
