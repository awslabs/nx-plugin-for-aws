---
title: Elegir entre REST y HTTP
---
:::note[Elección del tipo de API]
Puedes elegir entre una [REST API](https://docs.aws.amazon.com/apigateway/latest/developerguide/apigateway-rest-api.html) o una [HTTP API](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api.html) para desplegar tu API, consulta la [API Gateway Developer Guide](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-vs-rest.html) para ayudarte a decidir.
:::
