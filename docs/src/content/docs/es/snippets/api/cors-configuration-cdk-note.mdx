:::note[Configuración CORS en CDK]
Si tu solución incluye un sitio web, puedes configurar su distribución CloudFront como el único origen CORS permitido en el API gateway / integraciones AWS Lambda de API para APIs HTTP / REST.
Puedes llamar al método `restrictCorsTo` de la API con constructos de sitios web, distribuciones CloudFront, cadenas de origen o una combinación de ellos.

```ts
import { MyApi, MyWebsite } from '@my-scope/common-constructs';

export class ExampleStack extends Stack {
  constructor(scope: Construct, id: string) {
    const api = new MyApi(this, 'MyApi', {
      integrations: MyApi.defaultIntegrations(this).build(),
    });
    const website = new MyWebsite(this, 'MyWebsite');
    api.restrictCorsTo(website, 'http://localhost:4200', 'http://localhost:4300');
  }
}
```

El constructo `MyWebsite` puede generarse usando el <Link path="/guides/react-website">generador `ts#website`</Link>. Este ejemplo asume que los puertos del servidor de desarrollo local y de vista previa del sitio web son `4200`/`4300` - verifica su `project.json` (o `vite.config.mts`) para los puertos realmente asignados, ya que cada sitio web generado de esta manera obtiene los suyos propios.
:::
