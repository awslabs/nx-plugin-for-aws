:::note[Configuración CORS de CDK]
Si tu solución incluye un sitio web, puedes configurar su distribución de CloudFront como el único origen CORS permitido en el API gateway / integraciones de AWS Lambda API para APIs HTTP / REST.
Puedes llamar al método `restrictCorsTo` de la API con constructos de sitio web, distribuciones de CloudFront, cadenas de origen o una combinación de ellos.

```ts
import { MyApi, MyWebsite } from '@my-scope/common-constructs';

export class ExampleStack extends Stack {
  constructor(scope: Construct, id: string) {
    const api = new MyApi(this, 'MyApi', {
      integrations: MyApi.defaultIntegrations(this).build(),
    });
    const website = new MyWebsite(this, 'MyWebsite');
    api.restrictCorsTo(website, 'http://localhost:4200');
  }
}
```

El constructo `MyWebsite` se puede generar usando el <Link path="/guides/react-website">generador `ts#website`</Link>
:::
