Un asistente de IA que puede acceder al Nx Plugin for AWS estructura tus proyectos de la misma manera que tú lo harías: de forma consistente, con la seguridad, observabilidad, seguridad de tipos y desarrollo local que el plugin incorpora, y con mucho menos de tu tiempo dedicado a conectar las piezas.

## Ya configurado en tu espacio de trabajo

Los espacios de trabajo creados con el preset de Nx Plugin for AWS incluyen configuración MCP a nivel de proyecto para agentes de codificación comunes — Claude Code, Cursor, Kiro, Gemini CLI, GitHub Copilot y OpenAI Codex — para que un agente que trabaje dentro del espacio de trabajo pueda usar el [servidor MCP](https://modelcontextprotocol.io/introduction) del plugin sin configuración adicional.

Abre tu espacio de trabajo en tu asistente y pídele lo que quieras:

<Prompt>
Add a React website with an AG-UI agent, an MCP server for its tools and a DynamoDB table, and wire them together.
</Prompt>

Busca los generadores que ofrece el plugin, los ejecuta en el orden que sus dependencias necesitan, y completa la lógica de negocio desde ahí.

## Instala globalmente, o para mejores resultados

La <Link path="get_started/quick-start">configuración del espacio de trabajo</Link> anterior es suficiente para construir. Instala un plugin o power también si quieres que el servidor MCP esté disponible en todos tus proyectos, o quieres la documentación de orientación y las guías de flujo de trabajo que vienen con ellos:

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    El Nx Plugin for AWS se distribuye como un [Kiro Power](https://kiro.dev/docs/powers/) que agrupa el servidor MCP con documentación de orientación y guías de flujo de trabajo.

    <Steps>

    1. Abre el panel de Powers en Kiro y haz clic en **Add power from GitHub**
    2. Ingresa la siguiente URL:

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. Haz clic en **Install**

    </Steps>

    Kiro configura automáticamente el servidor MCP — no se requiere configuración adicional.

  </TabItem>
  <TabItem label="Kiro CLI">
    Ejecuta el siguiente comando:

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    Consulta la [documentación de Kiro CLI MCP](https://kiro.dev/docs/cli/mcp/) para más detalles.

  </TabItem>
  <TabItem label="Claude Code">
    El Nx Plugin for AWS se distribuye como un [plugin de Claude Code](https://code.claude.com/docs/en/plugins) que agrupa una [Skill](https://code.claude.com/docs/en/skills) con el servidor MCP.

    Ejecuta los siguientes comandos dentro de Claude Code, uno a la vez:

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    Luego ejecuta `/reload-plugins` para activar el plugin.

  </TabItem>
  <TabItem label="Cursor">
    Agrega lo siguiente a `~/.cursor/mcp.json` (o `.cursor/mcp.json` en tu proyecto):

    <Snippet name="mcp/config" />

    Consulta la [documentación de Cursor MCP](https://cursor.com/docs/mcp) para más detalles.

  </TabItem>
  <TabItem label="Codex">
    Agrega lo siguiente a `~/.codex/config.toml`:

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    Consulta la [documentación de configuración de Codex](https://developers.openai.com/codex/config-reference) para más detalles.

  </TabItem>
  <TabItem label="Other">
    La mayoría de los asistentes compatibles con MCP usan un archivo de configuración JSON. Agrega la siguiente entrada:

    <Snippet name="mcp/config" />

    Si tienes problemas como `ENOENT npx`, reemplaza el comando con la ruta completa a `npx` (encuéntrala con `which npx`).

    Para documentación específica del asistente:

    <Snippet name="mcp/assistant-docs" />

  </TabItem>
</Tabs>

## Comienza a Codificar con Vibe

Con el plugin disponible globalmente, tu asistente también puede crear el espacio de trabajo. Prueba un prompt como:

<Prompt>
Build a multi-agent application using the Nx Plugin for AWS. I want a React frontend that talks to a backend orchestrator agent which delegates to specialised research and writing agents.
</Prompt>

O para un punto de partida más pequeño:

<Prompt>
Use the Nx Plugin for AWS to scaffold a React website backed by a tRPC API, with Cognito auth and CDK infrastructure.
</Prompt>
