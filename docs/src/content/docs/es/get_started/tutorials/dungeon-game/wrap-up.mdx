## Conclusión

¡Felicitaciones! Has creado un juego de aventuras de Mazmorras con IA Agéntica que utiliza muchos de los generadores disponibles dentro del `@aws/nx-plugin`.  🎉🎉🎉

## ¿Qué sigue?

Te recomendamos que intentes extender la base de código con las siguientes capacidades por tu cuenta:

1. Agrega el <Link path="guides/license">generador de licencias</Link> a tu proyecto, el cual administrará automáticamente los archivos LICENSE y los encabezados del código fuente en tu espacio de trabajo.
2. <Link path="get_started/tutorials/contribute-generator">Contribuye tu propio generador</Link> para simplificar la adición de nuevas APIs tRPC.
3. Agrega una nueva api `resetToAction` (usando tu generador anterior) en GameAPI que te permita retroceder en el tiempo y eliminar todas las acciones desde un punto dado. Actualiza la interfaz de usuario para agregar un botón en una burbuja de conversación para restablecer a este punto (y llamar a la API recién creada).
4. Explora las diversas guías de componentes usando la navegación izquierda.

## Destruyendo recursos

¿Quieres seguir jugando y agregar primero un dispositivo de borde? Continúa con
<Link path="get_started/tutorials/dungeon-game/greengrass-dice">Opcional: lanza dados con Greengrass</Link>.
El Story Agent llama a una herramienta que solicita un lanzamiento desde un dispositivo y usa el
valor devuelto en el juego. Mantén tu mazmorra desplegada para esa ruta; incluye
instrucciones para eliminar solo la extensión o toda la aplicación.

1. Para destruir los recursos de AWS que fueron creados, ejecuta el siguiente comando:

<NxCommands commands={['destroy-sandbox infra']} />

    Esto te solicitará una lista de pilas para eliminar, que debería comprender `dungeon-adventure-infra-sandbox/Application/GameUI/waf` y `dungeon-adventure-infra-sandbox/Application`.

2. Ingresa `y` para continuar. CloudFormation destruirá tus pilas.

:::note[Si la protección contra eliminación de AppConfig bloquea la eliminación de la pila]
Deja de usar la aplicación del tutorial. En la pestaña **Resources** de la pila fallida, registra
el ID físico exacto de su aplicación AppConfig y los IDs de solo
el entorno y los perfiles de configuración cuya eliminación falló.

Espera el [intervalo de protección contra eliminación](https://docs.aws.amazon.com/appconfig/2019-10-09/APIReference/API_DeletionProtectionSettings.html) de la cuenta después de la última lectura de configuración
y reintenta la destrucción, o elimina solo estos recursos descartados del tutorial:
usa `aws appconfig delete-environment` con `--application-id` y
`--environment-id`, y `aws appconfig delete-configuration-profile` con
`--application-id` y `--configuration-profile-id`. Proporciona los IDs registrados
y `--deletion-protection-check BYPASS`, con `--profile` y
`--region` explícitos, en cada llamada. Luego vuelve a ejecutar el comando de destrucción.
:::

:::caution[Recursos retenidos]
La eliminación de pilas deja estos recursos para una limpieza separada:

- El **grupo de usuarios de Cognito**, que `ts#website#auth` crea con protección contra eliminación habilitada.
- El **rol IAM de SMS del grupo**, retenido con el grupo para que aún pueda ser actualizado y eliminado.
- El **bucket de sesión del Story Agent**, que contiene el historial de conversación y tiene por defecto `RemovalPolicy.RETAIN`.
- El **grupo de registros de acceso de Game API**.
- Cuatro **claves KMS administradas por el cliente** para los registros WAF del grupo de usuarios, registros de Game API, sesiones del Story Agent y sitio web.
- El **rol IAM de CloudWatch de API Gateway**, cuya configuración de cuenta regional es compartida por las APIs REST.

Registra el ARN del rol de SMS de la configuración de SMS del grupo de usuarios antes de eliminar
el grupo. Desactiva la protección contra eliminación del grupo, elimina el grupo, luego elimina
su rol de SMS y cualquier política adjunta que pertenezca a esta aplicación. Vacía el
bucket de sesión, incluyendo versiones de objetos y marcadores de eliminación, antes de eliminarlo.
Elimina el grupo de registros de acceso de Game API cuando ya no necesites sus registros.

Conserva cualquier clave KMS necesaria para leer los datos que retienes. Programa la eliminación de las
claves no utilizadas de esta aplicación con un período de espera de al menos siete días.
Las claves permanecen en `PendingDeletion` hasta que finalice ese período.

Preserva el rol de API Gateway si otras APIs REST lo utilizan. Verifica la configuración del rol de
CloudWatch de la cuenta regional y las dependencias antes de eliminar un rol no utilizado
propiedad del tutorial, y actualiza su referencia de cuenta antes de eliminarlo.
:::
