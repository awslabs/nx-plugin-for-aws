Esboza los proyectos que tu espacio de trabajo necesita y las conexiones entre ellos, y el constructor genera los comandos que estructuran exactamente lo que dibujaste. Cópialos, ejecútalos y tendrás un espacio de trabajo funcional.

Arrastra componentes desde la paleta al lienzo, arrastra desde el borde derecho de un componente a otro para conectarlos, y edita las propiedades de cada componente a la derecha. Los comandos generados en la parte inferior se actualizan con cada cambio — presiona **Copy** para tomar el script completo.

## Cómo funciona

Cada componente en el lienzo se mapea a un generador, y cada conexión al <Link path="guides/connection">generador de conexiones</Link>. Los comandos se emiten en orden de dependencia: primero el espacio de trabajo, luego los proyectos, luego los componentes que alojan, luego las conexiones que los conectan.

Un proyecto `infra` se agrega al final — <Link path="guides/typescript-infrastructure">`ts#infra`</Link> o <Link path="guides/terraform-project">`terraform#project`</Link>, según tu elección de IaC. Cada proyecto generado proporciona constructos para que este los instancie, así que esto es lo que despliegas. Debido a que posee ese nombre, ningún componente en el lienzo puede llamarse `infra`.

Arrastra el fondo del lienzo para desplazarte, y arrastra un componente para reposicionarlo. Shift-clic para seleccionar varios componentes y moverlos como un grupo.

La paleta lista cada tipo de proyecto y componente que puede participar en una conexión, y solo puedes dibujar las conexiones que el plugin soporta — así que un grafo que valida es un grafo que se estructura.

Dos reglas vale la pena conocer:

- **Los componentes comparten un proyecto anfitrión.** Un agente y un servidor MCP se agregan _a_ un proyecto en lugar de ser proyectos por sí mismos. Dales el mismo nombre de proyecto anfitrión para ponerlos en un proyecto, o nombres diferentes para un proyecto cada uno.
- **Algunas conexiones restringen sus extremos.** Conectar un agente a otro agente requiere que el objetivo use el protocolo `a2a`, por ejemplo. Donde una configuración de propiedad rompería una conexión que has dibujado, el constructor lo indica contra el componente y la conexión.

:::tip[¿Prefieres construir con IA?]
El plugin incluye un servidor MCP, así que tu agente de codificación puede estructurar y conectar proyectos por ti. Consulta <Link path="get_started/building-with-ai">Construyendo con IA</Link>.
:::
