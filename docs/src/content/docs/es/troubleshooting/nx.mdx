Esta página proporciona orientación para solucionar problemas que puedes encontrar al usar Nx.

## Nx Daemon

El [Nx Daemon](https://nx.dev/docs/concepts/nx-daemon) es un proceso que observa continuamente los cambios en el espacio de trabajo para recalcular su gráfico de proyectos. Esto proporciona un aumento de rendimiento, particularmente para proyectos grandes, pero a veces puede ser la causa de problemas dependiendo de tu entorno.

Esto puede manifestarse de diferentes maneras, una de las cuales es el siguiente error:

```bash
 NX   Could not find project "@scope/project"

Pass --verbose to see the stacktrace.
```

Para este y cualquier otro error inesperado, siempre vale la pena restablecer Nx y volver a intentarlo en caso de un problema con el daemon. Puedes usar el siguiente comando:

<NxCommands commands={['reset']} />

Si esto falla, puedes intentar [deshabilitar el daemon por completo](https://nx.dev/docs/concepts/nx-daemon#turning-it-off).

:::warning[Daemon requerido]
El comando `nx watch` requiere el daemon, por lo tanto, algunos de tus objetivos de recarga en caliente pueden no funcionar si lo deshabilitas.
:::
