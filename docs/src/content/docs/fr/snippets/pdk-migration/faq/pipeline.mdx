PDK fournissait un [`PDKPipelineProject`](https://aws.github.io/aws-pdk/developer_guides/pipeline/index.html) qui configurait un projet d'infrastructure CDK et utilisait un construct CDK qui encapsulait certaines ressources [CDK Pipelines](https://docs.aws.amazon.com/cdk/api/v2/docs/aws-cdk-lib.pipelines-readme.html).

Pour migrer depuis cela, vous pouvez utiliser les constructs CDK Pipelines directement. En pratique, cependant, il est probablement plus simple d'utiliser quelque chose comme GitHub actions ou GitLab CI/CD, où vous définissez des [CDK Stages](https://docs.aws.amazon.com/cdk/v2/guide/stages.html) et exécutez la commande de déploiement pour le stage approprié directement.
