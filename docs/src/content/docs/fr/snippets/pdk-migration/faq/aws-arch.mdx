[AWS Arch](https://aws.github.io/aws-pdk/developer_guides/aws-arch/index.html) fournissait des mappages entre les ressources CloudFormation et leurs icônes d'architecture associées pour CDK Graph ci-dessus.

Consultez la [page AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) pour les ressources liées aux icônes. [Diagrams](https://diagrams.mingrammer.com/) fournit également un moyen de créer des diagrammes sous forme de code.

Si vous utilisiez cela directement, envisagez de forker le projet et d'en prendre la responsabilité !
