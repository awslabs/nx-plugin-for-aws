:::note[Projet d'infrastructure requis]
Les générateurs d'agent, de serveur MCP et de Gateway fournissent leurs constructs et modules dans `packages/common`, mais ils ne créent pas d'application pour les déployer — donc `packages/infra` n'existe pas tant que vous ne le générez pas. Exécutez le générateur <Link path="guides/typescript-infrastructure">`ts#infra`</Link> (CDK) ou le générateur <Link path="guides/terraform-project">`terraform#project`</Link> (Terraform) avant de modifier le fichier ci-dessous.
:::
