:::caution[Expérimental]
Ce générateur est expérimental. Son comportement et la sortie générée peuvent changer dans une version future sans qu'une migration ne soit publiée pour appliquer le changement à un espace de travail existant, vous devrez donc peut-être réconcilier ces changements vous-même lors de la mise à niveau.
:::
