:::note[Configuration CORS CDK]
Si votre solution inclut un site web, vous pouvez configurer sa distribution CloudFront comme seule origine CORS autorisée dans la passerelle API / les intégrations AWS Lambda API pour les API HTTP / REST.
Vous pouvez appeler la méthode `restrictCorsTo` de l'API avec des constructs de site web, des distributions CloudFront, des chaînes d'origine, ou un mélange de ceux-ci.

```ts
import { MyApi, MyWebsite } from '@my-scope/common-constructs';

export class ExampleStack extends Stack {
  constructor(scope: Construct, id: string) {
    const api = new MyApi(this, 'MyApi', {
      integrations: MyApi.defaultIntegrations(this).build(),
    });
    const website = new MyWebsite(this, 'MyWebsite');
    api.restrictCorsTo(website, 'http://localhost:4200', 'http://localhost:4300');
  }
}
```

Le construct `MyWebsite` peut être généré en utilisant le <Link path="/guides/react-website">générateur `ts#website`</Link>. Cet exemple suppose que les ports du serveur de développement local et de prévisualisation du site web sont `4200`/`4300` - vérifiez son `project.json` (ou `vite.config.mts`) pour les ports qui lui sont réellement attribués, car chaque site web généré de cette manière obtient les siens.
:::
