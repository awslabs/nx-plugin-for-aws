Ce guide vous accompagne à travers un exemple de migration d'un projet [AWS PDK](https://github.com/aws/aws-pdk) vers le Nx Plugin for AWS, tout en fournissant des conseils généraux sur ce sujet.

Migrer vers le Nx Plugin for AWS offre les avantages suivants par rapport à PDK :

- Builds plus rapides
- Plus facile à utiliser (UI et CLI)
- Compatible avec le vibe-coding (<Link path="/get_started/building-with-ai">essayez notre serveur MCP !</Link>)
- Technologies plus modernes
- Développement local d'API et de sites web
- Plus de contrôle (modifiez les fichiers générés pour correspondre à votre cas d'usage)
- Et plus encore !

:::caution[Pas un guide étape par étape]
Il existe de nombreuses nuances et considérations lors de la migration d'un projet. Ce guide concerne un exemple simple, et il peut manquer des étapes nécessaires pour votre projet.

Ce guide opte pour une approche où nous créons un espace de travail vierge et copions des éléments de notre projet PDK dans un nouveau projet. Si vous devez migrer différemment, ou si vous avez des questions sur le passage de PDK au Nx Plugin for AWS, [contactez-nous sur GitHub discussions](https://github.com/awslabs/nx-plugin-for-aws/discussions) !

Notez également que certaines fonctionnalités de PDK n'ont pas d'équivalents exacts. Consultez la section [FAQ](#frequently-asked-questions) pour quelques astuces/idées à ce sujet.
:::

:::caution[Guide ponctuel]
Ce guide est rédigé comme un guide ponctuel et ne sera très probablement pas mis à jour au fur et à mesure de l'évolution du Nx Plugin for AWS. Pour compenser cela, le guide épingle la version de `@aws/nx-plugin` à `1.0.0-rc.47`. Vous pouvez essayer avec la dernière version si vous suivez le guide, mais il peut y avoir quelques écarts par rapport au guide.
:::

## Exemple de migration : Application de liste de courses

Dans ce guide, nous utiliserons l'[Application de liste de courses du tutoriel PDK](https://aws.github.io/aws-pdk/getting_started/shopping_list_app.html) comme projet cible à migrer. Suivez les étapes de ce tutoriel pour créer le projet cible si vous souhaitez suivre vous-même.

L'application de liste de courses se compose des types de projets PDK suivants :

- `MonorepoTsProject`
- `TypeSafeApiProject`
- `CloudscapeReactTsWebsiteProject`
- `InfrastructureTsProject`

### Créer l'espace de travail

Pour commencer, nous allons créer un nouvel espace de travail pour notre nouveau projet. Bien que plus extrême qu'une migration sur place, cette approche nous donne le résultat final le plus propre. Créer un espace de travail Nx équivaut à utiliser le `MonorepoTsProject` de PDK :

<CreateNxWorkspaceCommand workspace="shopping-list" iac="cdk" tag="1.0.0-rc.47" />

Ouvrez le répertoire `shopping-list` créé par cette commande dans votre IDE préféré.
