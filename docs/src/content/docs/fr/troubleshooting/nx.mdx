Cette page fournit des conseils de dépannage pour les problèmes que vous pourriez rencontrer lors de l'utilisation de Nx.

## Nx Daemon

Le [Nx Daemon](https://nx.dev/docs/concepts/nx-daemon) est un processus qui surveille en continu les changements dans l'espace de travail afin de recalculer son graphe de projet. Cela offre un gain de performance, particulièrement pour les grands projets, mais peut parfois être la cause de problèmes selon votre environnement.

Cela peut se manifester de différentes manières, dont l'une est l'erreur suivante :

```bash
 NX   Could not find project "@scope/project"

Pass --verbose to see the stacktrace.
```

Pour cela, et pour toute autre erreur inattendue, il vaut toujours la peine de réinitialiser Nx et de réessayer en cas de problème avec le daemon. Vous pouvez utiliser la commande suivante :

<NxCommands commands={['reset']} />

Si cela échoue, vous pouvez essayer de [désactiver complètement le daemon](https://nx.dev/docs/concepts/nx-daemon#turning-it-off).

:::warning[Daemon Requis]
La commande `nx watch` nécessite le daemon, et par conséquent certaines de vos cibles de rechargement à chaud peuvent ne pas fonctionner si vous le désactivez.
:::
