## Conclusion

Félicitations ! Vous avez créé un jeu d'aventure de donjon IA agentique qui utilise de nombreux générateurs disponibles dans le `@aws/nx-plugin`.  🎉🎉🎉

## Et ensuite ?

Nous vous recommandons d'essayer d'étendre la base de code avec les capacités suivantes par vous-même :

1. Ajoutez le <Link path="guides/license">générateur de licence</Link> à votre projet qui gérera automatiquement les fichiers LICENSE et les en-têtes de code source dans votre espace de travail.
2. <Link path="get_started/tutorials/contribute-generator">Contribuez votre propre générateur</Link> pour simplifier l'ajout de nouvelles API tRPC.
3. Ajoutez une nouvelle API `resetToAction` (en utilisant votre générateur ci-dessus) dans GameAPI qui vous permet de remonter dans le temps et de supprimer toutes les actions à partir d'un point donné. Mettez à jour l'interface utilisateur pour ajouter un bouton sur une bulle de conversation pour réinitialiser à ce point (et appeler l'API nouvellement créée).
4. Explorez les différents guides de composants en utilisant la navigation de gauche.

## Destruction des ressources

1. Pour détruire les ressources AWS qui ont été créées, exécutez la commande suivante :

<NxCommands commands={['destroy infra "dungeon-adventure-infra-sandbox/*"']} />

    Cela vous demandera une liste de piles à supprimer qui devrait comprendre `dungeon-adventure-infra-sandbox/Application/GameUI/waf` et `dungeon-adventure-infra-sandbox/Application`.

2. Entrez `Y` pour continuer. CloudFormation détruira vos piles.
