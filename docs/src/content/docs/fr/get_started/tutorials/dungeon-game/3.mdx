## Tâche 1 : Implémenter l'agent Story

L'agent Story est un agent [Strands](https://strandsagents.com/) généré avec `--protocol=ag-ui` dans le <Link path="get_started/tutorials/dungeon-game/1">Module 1</Link>, afin que l'interface utilisateur puisse diffuser depuis celui-ci via le [protocole Agent-User Interaction](https://docs.copilotkit.ai/aws-strands/protocol) via CopilotKit. Il utilise le serveur MCP Inventory pour gérer les objets du joueur, et persiste déjà l'historique des conversations via le `session.py` que le générateur a provisionné dans le Module 1 — une fois déployé, c'est le [`S3SessionManager`](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/agents/sessions/) intégré de Strands qui écrit dans le même bucket S3 que celui depuis lequel le `queryActions` de l'API Game lit, afin que le navigateur puisse reconstruire les transcriptions lors d'une nouvelle visite.

### Implémentation de l'agent

Mettez à jour `agent.py` dans `packages/story/dungeon_adventure_story/agent` :

<E2EDiff lang="python" before="dungeon-adventure/3/agent.py.old.template" after="dungeon-adventure/3/agent.py.template" />

`agent.py` supprime l'outil d'exemple `subtract` et remplace le prompt système par un prompt de maître de donjon qui invite le premier message de l'utilisateur à indiquer le nom et le genre du joueur, et utilise les outils du serveur MCP Inventory. `main.py` n'a besoin d'aucune modification ici — la gestion des sessions était déjà configurée lors de la génération de l'agent.

### Discuter avec votre agent

La cible `agent-chat` générée ouvre un REPL interactif contre votre agent. Il s'exécute de manière autonome et se connecte à votre agent s'exécutant localement, donc démarrez d'abord le serveur local de l'agent dans un terminal :

<NxCommands commands={["agent-dev story"]} />

Ensuite, dans un second terminal, démarrez le chat :

<NxCommands commands={["agent-chat story"]} />

Votre premier message devrait indiquer à l'agent le nom de votre héros et le genre (par exemple : `My name is Alice. Start my zombie adventure.`) et l'histoire sera diffusée en retour.

<Aside type="caution" title="Identifiants AWS requis">
Bien que l'agent s'exécute localement, il invoque [Amazon Bedrock](https://aws.amazon.com/bedrock/) pour le LLM. Vous aurez besoin d'identifiants AWS dans votre environnement avec accès au [modèle par défaut de Strands](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/model-providers/amazon-bedrock/). Consultez la [documentation du fournisseur de modèles Strands](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/model-providers/amazon-bedrock/) pour plus de détails.
</Aside>
