Installez le [Claude Plugin](https://code.claude.com/docs/en/plugins), [Kiro Power](https://kiro.dev/docs/powers/), ou le [MCP Server](https://modelcontextprotocol.io/introduction) pour permettre aux assistants IA de travailler efficacement avec le plugin. En les utilisant, vous pouvez accélérer votre flux de travail de développement avec l'IA tout en bénéficiant de projets structurés de manière cohérente, en passant moins de temps sur la configuration des composants principaux et en profitant de la sécurité, de l'observabilité, de la sûreté des types et du développement local intégrés dans le plugin.

## Configurez votre assistant IA

:::tip[La configuration au niveau du projet est automatique]
Les espaces de travail créés avec le preset Nx Plugin for AWS incluent déjà une configuration MCP au niveau du projet pour les agents de codage courants (Claude Code, Cursor, Kiro, Gemini CLI, GitHub Copilot et OpenAI Codex). Tout agent travaillant dans l'espace de travail peut utiliser le serveur MCP sans configuration supplémentaire. Les étapes ci-dessous configurent le serveur MCP globalement pour une utilisation dans tous vos projets.
:::

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    Le Nx Plugin for AWS est fourni sous forme de [Kiro Power](https://kiro.dev/docs/powers/) qui regroupe le serveur MCP avec de la documentation de pilotage et des guides de flux de travail.

    <Steps>

    1. Ouvrez le panneau Powers dans Kiro et cliquez sur **Add power from GitHub**
    2. Entrez l'URL suivante :

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. Cliquez sur **Install**

    </Steps>

    Kiro configure automatiquement le serveur MCP — aucune configuration supplémentaire n'est requise.

  </TabItem>
  <TabItem label="Kiro CLI">
    Exécutez la commande suivante :

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    Consultez la [documentation MCP de Kiro CLI](https://kiro.dev/docs/cli/mcp/) pour plus de détails.

  </TabItem>
  <TabItem label="Claude Code">
    Le Nx Plugin for AWS est distribué sous forme de [plugin Claude Code](https://code.claude.com/docs/en/plugins) qui regroupe une [Skill](https://code.claude.com/docs/en/skills) avec le serveur MCP.

    Exécutez les commandes suivantes dans Claude Code, une à la fois :

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    Ensuite, exécutez `/reload-plugins` pour activer le plugin.

  </TabItem>
  <TabItem label="Cursor">

    <Snippet name="mcp/config" />

    Consultez la [documentation MCP de Cursor](https://cursor.com/docs/mcp) pour plus de détails.

  </TabItem>
  <TabItem label="Codex">
    Ajoutez ce qui suit à `~/.codex/config.toml` :

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    Consultez la [documentation de configuration de Codex](https://developers.openai.com/codex/config-reference) pour plus de détails.

## Commencez le Vibe Coding

Demandez à votre assistant IA de construire quelque chose en utilisant le `nx-plugin-for-aws` ! Il créera généralement un espace de travail, structurera avec les générateurs applicables, puis remplira la logique métier.

Essayez une invite comme :

> _"Construis une application multi-agents en utilisant le Nx Plugin for AWS. Je veux un frontend React qui communique avec un agent orchestrateur backend qui délègue à des agents de recherche et d'écriture spécialisés."_

Ou pour un point de départ plus simple :

> _"Utilise le Nx Plugin for AWS pour structurer un site web React soutenu par une API tRPC, avec l'authentification Cognito et l'infrastructure CDK."_
