Un assistant IA qui peut accéder au Nx Plugin for AWS structure vos projets de la même manière que vous le feriez : de manière cohérente, avec la sécurité, l'observabilité, la sûreté des types et le développement local intégrés dans le plugin, et en passant beaucoup moins de temps à assembler les pièces.

## Déjà configuré dans votre espace de travail

Les espaces de travail créés avec le preset Nx Plugin for AWS incluent une configuration MCP au niveau du projet pour les agents de codage courants — Claude Code, Cursor, Kiro, Gemini CLI, GitHub Copilot et OpenAI Codex — afin qu'un agent travaillant dans l'espace de travail puisse utiliser le [serveur MCP](https://modelcontextprotocol.io/introduction) du plugin sans configuration supplémentaire.

Ouvrez votre espace de travail dans votre assistant et demandez-lui ce que vous voulez :

<Prompt>
Add a React website with an AG-UI agent, an MCP server for its tools and a DynamoDB table, and wire them together.
</Prompt>

Il recherche les générateurs offerts par le plugin, les exécute dans l'ordre requis par leurs dépendances et remplit la logique métier à partir de là.

## Installer globalement, ou pour de meilleurs résultats

La <Link path="get_started/quick-start">configuration de l'espace de travail</Link> ci-dessus suffit pour construire. Installez également un plugin ou un power si vous souhaitez que le serveur MCP soit disponible dans tous vos projets, ou si vous voulez la documentation de pilotage et les guides de flux de travail qui les accompagnent :

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    Le Nx Plugin for AWS est fourni sous forme de [Kiro Power](https://kiro.dev/docs/powers/) qui regroupe le serveur MCP avec de la documentation de pilotage et des guides de flux de travail.

    <Steps>

    1. Ouvrez le panneau Powers dans Kiro et cliquez sur **Add power from GitHub**
    2. Entrez l'URL suivante :

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. Cliquez sur **Install**

    </Steps>

    Kiro configure automatiquement le serveur MCP — aucune configuration supplémentaire n'est requise.

  </TabItem>
  <TabItem label="Kiro CLI">
    Exécutez la commande suivante :

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    Consultez la [documentation MCP de Kiro CLI](https://kiro.dev/docs/cli/mcp/) pour plus de détails.

  </TabItem>
  <TabItem label="Claude Code">
    Le Nx Plugin for AWS est distribué sous forme de [plugin Claude Code](https://code.claude.com/docs/en/plugins) qui regroupe une [Skill](https://code.claude.com/docs/en/skills) avec le serveur MCP.

    Exécutez les commandes suivantes dans Claude Code, une à la fois :

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    Ensuite, exécutez `/reload-plugins` pour activer le plugin.

  </TabItem>
  <TabItem label="Cursor">
    Ajoutez ce qui suit à `~/.cursor/mcp.json` (ou `.cursor/mcp.json` dans votre projet) :

    <Snippet name="mcp/config" />

    Consultez la [documentation MCP de Cursor](https://cursor.com/docs/mcp) pour plus de détails.

  </TabItem>
  <TabItem label="Codex">
    Ajoutez ce qui suit à `~/.codex/config.toml` :

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    Consultez la [documentation de configuration de Codex](https://developers.openai.com/codex/config-reference) pour plus de détails.

  </TabItem>
  <TabItem label="Other">
    La plupart des assistants compatibles MCP utilisent un fichier de configuration JSON. Ajoutez l'entrée suivante :

    <Snippet name="mcp/config" />

    Si vous rencontrez des problèmes tels que `ENOENT npx`, remplacez la commande par le chemin complet vers `npx` (trouvez-le avec `which npx`).

    Pour la documentation spécifique à l'assistant :

    <Snippet name="mcp/assistant-docs" />

  </TabItem>
</Tabs>

## Commencez le Vibe Coding

Avec le plugin disponible globalement, votre assistant peut également créer l'espace de travail. Essayez une invite comme :

<Prompt>
Build a multi-agent application using the Nx Plugin for AWS. I want a React frontend that talks to a backend orchestrator agent which delegates to specialised research and writing agents.
</Prompt>

Ou pour un point de départ plus simple :

<Prompt>
Use the Nx Plugin for AWS to scaffold a React website backed by a tRPC API, with Cognito auth and CDK infrastructure.
</Prompt>
