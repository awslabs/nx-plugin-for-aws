---
title: Métriques d'utilisation
description: Comment @aws/nx-plugin collecte les métriques
---

Afin de nous aider à améliorer le Nx Plugin for AWS, nous collectons des métriques sur l'utilisation des générateurs. Ce processus n'implique aucune requête réseau supplémentaire, nous exploitons simplement les métriques d'utilisation AWS existantes.

Pour rester transparents, nous ajoutons un ID, une version et une liste d'ID de générateurs aux descriptions des CloudFormation Stack. Cela est fait dans le `MetricsAspect` dans `common/constructs` pour CDK ou dans le Cloudformation stack `metrics.tf` pour Terraform.

## Désactivation

Le code des métriques se trouve entièrement dans votre workspace, vous pouvez donc le désactiver en le supprimant :

- **CDK** : supprimez la classe `MetricsAspect` et l'appel `Aspects.of(this).add(new MetricsAspect())` de `packages/common/constructs/src/core/app.ts`.
- **Terraform** : supprimez `packages/common/terraform/src/metrics/metrics.tf`.

Les générateurs ne rajouteront pas le code des métriques une fois supprimé.
