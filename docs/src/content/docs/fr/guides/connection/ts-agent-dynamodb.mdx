Le générateur `connection` relie un <Link path="guides/ts-agent">TypeScript Agent</Link> à un projet <Link path="guides/ts-dynamodb">TypeScript DynamoDB</Link>, en configurant le développement local pour que les deux démarrent ensemble automatiquement.

## Prérequis

Avant d'utiliser ce générateur, assurez-vous d'avoir :

1. Un projet <Link path="guides/ts-agent">`ts#agent`</Link>
2. Un projet <Link path="guides/ts-dynamodb">`ts#dynamodb`</Link>

## Utilisation

### Exécuter le générateur

<RunGenerator generator="connection" />

Sélectionnez votre projet Agent comme source et votre projet DynamoDB comme cible. Si le projet contient plusieurs composants agent, spécifiez `sourceComponent` pour lever l'ambiguïté.

<GeneratorParameters generator="connection" />

## Sortie du générateur

Le générateur met à jour la cible `<agent-name>-dev` de l'agent dans `project.json` pour dépendre de la cible `dev` du projet DynamoDB. Aucun fichier source n'est modifié.

## Utiliser DynamoDB dans les Agents

Importez les factories d'entités depuis le package DynamoDB et utilisez-les dans votre définition d'agent :

```ts title="packages/my-service/src/my-agent/agent.ts"
import { createExampleEntity } from '@my-scope/my-table';

export const getAgent = async () => {
  // ...
  return new Agent({
    tools: [
      tool({
        name: 'list_examples',
        description: 'List all example items',
        func: async () => {
          const entity = await createExampleEntity();
          const result = await entity.scan.go();
          return result.data;
        },
      }),
    ],
  });
};
```

## Infrastructure

Pour permettre à la fonction Lambda de l'agent d'accéder à la table DynamoDB, accordez les permissions nécessaires dans votre infrastructure.

<Infrastructure>
<Fragment slot="cdk">

```ts title="packages/infra/src/stacks/application-stack.ts"
import { MyTable } from '@my-scope/common-constructs';

const table = new MyTable(this, 'Table');
const myAgent = new MyAgent(this, 'MyAgent');

table.grantReadWriteData(myAgent);
```

`grantReadWriteData` accorde à la fois les permissions DynamoDB et KMS au rôle d'exécution de l'agent.
</Fragment>
<Fragment slot="terraform">

Accordez au rôle d'exécution de l'agent l'accès à la table et à sa clé de chiffrement KMS via `additional_iam_policy_statements` :

```hcl title="packages/infra/src/main.tf"
module "my_table" {
  source = "../../common/terraform/src/app/dynamodb/my-table"
}

module "my_agent" {
  source = "../../common/terraform/src/app/agents/my-agent"

  additional_iam_policy_statements = [
    {
      Effect = "Allow"
      Action = [
        "dynamodb:GetItem", "dynamodb:PutItem", "dynamodb:UpdateItem",
        "dynamodb:DeleteItem", "dynamodb:Query", "dynamodb:Scan",
        "dynamodb:BatchGetItem", "dynamodb:BatchWriteItem",
      ]
      Resource = [
        module.my_table.table_arn,
        "${module.my_table.table_arn}/index/*",
      ]
    },
    {
      Effect = "Allow"
      Action = [
        "kms:Encrypt",
        "kms:Decrypt",
        "kms:ReEncrypt*",
        "kms:GenerateDataKey*",
        "kms:DescribeKey",
      ]
      Resource = [module.my_table.kms_key_arn]
    },
  ]
}
```
</Fragment>
</Infrastructure>
