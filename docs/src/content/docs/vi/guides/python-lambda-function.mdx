Trình tạo Hàm Lambda Python cung cấp khả năng thêm một hàm lambda vào một dự án python hiện có.

Trình tạo này tạo một lambda handler python mới với cấu hình cơ sở hạ tầng AWS CDK hoặc Terraform. Backend được tạo sử dụng AWS Lambda cho triển khai serverless, với tùy chọn type-safety sử dụng [Parser từ AWS Lambda Powertools](https://docs.powertools.aws.dev/lambda/python/latest/utilities/parser/). Nó thiết lập [AWS Lambda Powertools](https://docs.powertools.aws.dev/lambda/python/latest/) cho khả năng quan sát, bao gồm logging, AWS X-Ray tracing và Cloudwatch Metrics.

## Triển khai Hàm của bạn

Triển khai hàm chính nằm trong `<function-name>.py`. Đây là một ví dụ:

```python
import os

from aws_lambda_powertools import Logger, Metrics, Tracer
from aws_lambda_powertools.metrics import MetricUnit
from aws_lambda_powertools.utilities.parser import event_parser
from aws_lambda_powertools.utilities.parser.models import EventBridgeModel
from aws_lambda_powertools.utilities.typing import LambdaContext

os.environ["POWERTOOLS_METRICS_NAMESPACE"] = "Foo"
os.environ["POWERTOOLS_SERVICE_NAME"] = "Foo"

logger: Logger = Logger()
metrics: Metrics = Metrics()
tracer: Tracer = Tracer()

@tracer.capture_lambda_handler
@metrics.log_metrics
@event_parser(model=EventBridgeModel)
def lambda_handler(event: EventBridgeModel, context: LambdaContext):
    logger.info("Received event", extra={"event": event.model_dump() })
    metrics.add_metric(name="InvocationCount", unit=MetricUnit.Count, value=1)

    try:
        # TODO: Implement
        metrics.add_metric(name="SuccessCount", unit=MetricUnit.Count, value=1)
        # TODO: Implement success response if required
    except Exception as e:
        logger.exception(e)
        metrics.add_metric(name="ErrorCount", unit=MetricUnit.Count, value=1)
        # TODO: Implement error response if required
```

Trình tạo thiết lập một số tính năng tự động:

1. Tích hợp AWS Lambda Powertools cho khả năng quan sát
2. Thu thập metrics
3. Type-safety sử dụng `@event_parser`

### Khả năng quan sát với AWS Lambda Powertools

#### Logging

Trình tạo cấu hình structured logging sử dụng AWS Lambda Powertools.

```python
def lambda_handler(event: EventBridgeModel, context: LambdaContext):
    logger.info("Received event", extra={"event": event.model_dump()})
```

:::tip[Correlation ID]
Khuyến nghị thiết lập correlation id cho tất cả các yêu cầu duy nhất để dễ dàng gỡ lỗi và giám sát hơn. Vui lòng tham khảo tài liệu [aws powertools logger](https://docs.powertools.aws.dev/lambda/python/2.22.0/core/logger/#setting-a-correlation-id) để biết các phương pháp hay nhất về correlation id.
:::

Logger tự động bao gồm:

- Các yêu cầu event
- Thông tin Lambda context
- Chỉ báo cold start

#### Tracing

AWS X-Ray tracing được cấu hình tự động. Bạn có thể thêm các subsegment tùy chỉnh vào traces của mình:

```python
def lambda_handler(event: EventBridgeModel, context: LambdaContext):
    # Creates a new subsegment
    with tracer.provider.in_subsegment("function-subsegment"):
        # Your logic here
        return ....
```

#### Metrics

CloudWatch metrics được thu thập tự động cho mỗi yêu cầu. Bạn có thể thêm các metric tùy chỉnh:

```python
def lambda_handler(event: EventBridgeModel, context: LambdaContext):
    metrics.add_metric(name="NewMetric", unit=MetricUnit.Count, value=1)
    return ...
```

Các metric mặc định bao gồm:

- Số lần gọi
- Số lần thành công/thất bại
- Metrics cold start

### Type Safety

<OptionFilter not when={{ event: 'Any' }} description="Typed event wires @event_parser with a Pydantic model">
Nếu bạn chọn một `event` khi tạo hàm lambda của mình, hàm của bạn được trang bị [`@event_parser` từ AWS Lambda Powertools](https://docs.powertools.aws.dev/lambda/python/latest/utilities/parser/). Ví dụ:

```python {3}
@event_parser(model=EventBridgeModel)
def lambda_handler(event: EventBridgeModel, context: LambdaContext):
    event.detail_type # <- type-safe with IDE autocompletion
```

Điều này cho phép bạn định nghĩa các data model sử dụng [Pydantic](https://docs.pydantic.dev/latest/), theo cách tương tự như làm việc với <Link path="guides/fastapi">Fast API</Link>.

:::tip[Custom Event Data]
Nếu bạn có dữ liệu tùy chỉnh lồng trong một event, ví dụ như DynamoDB stream hoặc EventBridge event, bạn có thể hưởng lợi từ việc sử dụng [Envelopes](https://docs.powertools.aws.dev/lambda/python/latest/utilities/parser/#envelopes) để cung cấp type-safety cho dữ liệu tùy chỉnh đó.
:::
</OptionFilter>

<OptionFilter when={{ event: 'Any' }} description="event=Any — no parser decorator, event is untyped">
Nếu bạn chọn `Any` cho `event` của mình, decorator `@event_parser` không được áp dụng và handler nhận một event dict không có kiểu. Tạo lại với một `event` cụ thể nếu bạn muốn xác thực Pydantic và truy cập trường có kiểu.
</OptionFilter>

## Đóng gói

Trình tạo tự động cấu hình đóng gói Python cho các gói triển khai Lambda sử dụng [uv](https://docs.astral.sh/uv/):

<NxCommands commands={['bundle <project-name>']} />

:::note[Hành vi Đóng gói]
Điều này đóng gói toàn bộ dự án làm gói triển khai. Để giảm thiểu kích thước triển khai, bạn có thể muốn chia nhiều hàm lambda trên nhiều dự án Python được tạo bằng trình tạo <Link path="guides/python-project">`py#project`</Link>.
:::

Quá trình này sử dụng:

1. [`uv export`](https://docs.astral.sh/uv/reference/cli/#uv-export) để xuất các phụ thuộc Python của bạn sang tệp `requirements.txt`
2. [`uv pip install`](https://docs.astral.sh/uv/reference/cli/#uv-pip-install) để cài đặt các phụ thuộc cho nền tảng đích (`x86_64-manylinux_2_28`) cho triển khai Lambda

:::note[Thay đổi Kiến trúc]
Nếu bạn thay đổi [kiến trúc lambda sang ARM](https://docs.aws.amazon.com/lambda/latest/dg/foundation-arch.html), bạn sẽ cần chỉnh sửa bundle target của mình để sử dụng target `aarch64-manylinux_2_28`.
:::
