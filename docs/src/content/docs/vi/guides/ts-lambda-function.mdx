Trình tạo Hàm Lambda TypeScript cung cấp khả năng thêm một hàm lambda vào một dự án TypeScript hiện có.

Trình tạo này tạo một handler lambda TypeScript mới với cấu hình cơ sở hạ tầng AWS CDK hoặc Terraform. Handler được tạo sử dụng [AWS Lambda Powertools for TypeScript](https://docs.powertools.aws.dev/lambda/typescript/latest/) để quan sát, bao gồm ghi log, truy vết AWS X-Ray và CloudWatch Metrics, cũng như tùy chọn type-safety cho sự kiện bằng cách sử dụng [Parser from AWS Lambda Powertools](https://docs.powertools.aws.dev/lambda/typescript/latest/utilities/parser/)

## Triển khai Hàm của bạn

Triển khai hàm chính nằm trong `<function-name>.ts`. Đây là một ví dụ:

```typescript
import { parser } from '@aws-lambda-powertools/parser/middleware';
import { EventBridgeSchema } from '@aws-lambda-powertools/parser/schemas';
import { z } from 'zod';
import middy from '@middy/core';
import { Tracer } from '@aws-lambda-powertools/tracer';
import { captureLambdaHandler } from '@aws-lambda-powertools/tracer/middleware';
import { injectLambdaContext } from '@aws-lambda-powertools/logger/middleware';
import { Logger } from '@aws-lambda-powertools/logger';
import { Metrics } from '@aws-lambda-powertools/metrics';
import { logMetrics } from '@aws-lambda-powertools/metrics/middleware';
import type { Context } from 'aws-lambda';
export type { Context };

process.env.POWERTOOLS_METRICS_NAMESPACE = 'MyFunction';
process.env.POWERTOOLS_SERVICE_NAME = 'MyFunction';

const tracer = new Tracer();
const logger = new Logger();
const metrics = new Metrics();

export const myFunction = async (
  event: z.infer<typeof EventBridgeSchema>,
): Promise<void> => {
  logger.info('Received event', event);

  // TODO: implement
};

export const handler = middy()
  .use(captureLambdaHandler(tracer))
  .use(injectLambdaContext(logger))
  .use(logMetrics(metrics))
  .use(parser({ schema: EventBridgeSchema }))
  .handler(myFunction);

```

Trình tạo thiết lập một số tính năng tự động:

1. **Middy middleware stack** để tăng cường chức năng Lambda
2. **Tích hợp AWS Lambda Powertools** để quan sát
3. **Thu thập số liệu** với CloudWatch
4. **Type-safety** sử dụng parser middleware
5. **Đóng gói với Rolldown** để tối ưu hóa các gói triển khai

### Khả năng quan sát với AWS Lambda Powertools

#### Ghi log

Trình tạo cấu hình ghi log có cấu trúc bằng cách sử dụng AWS Lambda Powertools với tự động chèn ngữ cảnh thông qua Middy middleware.

```typescript
export const handler = middy()
  .use(injectLambdaContext(logger))
  .handler(myFunction);
```

#### Truy vết

Truy vết AWS X-Ray được cấu hình tự động thông qua middleware `captureLambdaHandler`. Bạn có thể thêm các subsegment tùy chỉnh vào các trace của mình:

```typescript
const tracer = new Tracer();

export const myFunction = async (
  event: z.infer<typeof EventBridgeSchema>,
): Promise<void> => {
  // Creates a new subsegment
  const subsegment = tracer.getSegment()?.addNewSubsegment('custom-operation');
  try {
    // Your logic here
  } catch (error) {
    subsegment?.addError(error as Error);
    throw error;
  } finally {
    subsegment?.close();
  }
};

export const handler = middy()
  .use(captureLambdaHandler(tracer))
  .handler(myFunction);
```

#### Số liệu

Số liệu CloudWatch được thu thập tự động cho mỗi yêu cầu thông qua middleware `logMetrics`. Bạn có thể thêm các số liệu tùy chỉnh:

```typescript
const metrics = new Metrics();

export const myFunction = async (
  event: z.infer<typeof EventBridgeSchema>,
): Promise<void> => {
  metrics.addMetric("CustomMetric", MetricUnit.Count, 1);
  metrics.addMetric("ProcessingTime", MetricUnit.Milliseconds, processingTime);
};

export const handler = middy()
  .use(logMetrics(metrics))
  .handler(myFunction);
```

### Type Safety

<OptionFilter not when={{ event: 'Any' }} description="event provides a typed Zod schema for the incoming event">
Nếu bạn đã chọn một `event` khi tạo hàm lambda của mình, hàm của bạn được trang bị [`parser` middleware from AWS Lambda Powertools](https://docs.powertools.aws.dev/lambda/typescript/latest/utilities/parser/). Ví dụ:

```typescript {4}
export const myFunction = async (
  event: z.infer<typeof EventBridgeSchema>,
): Promise<void> => {
  event.detail // <- type-safe with IDE autocompletion
};

export const handler = middy()
  .use(parser({ schema: EventBridgeSchema }))
  .handler(myFunction);
```

Điều này cung cấp type safety tại thời điểm biên dịch và xác thực thời gian chạy cho các sự kiện Lambda của bạn.

:::caution[Xử lý Lỗi]
Nếu bạn không muốn handler của mình ném ra lỗi khi sự kiện không tuân theo schema, bạn có thể sử dụng [tùy chọn `safeParse`](https://docs.powertools.aws.dev/lambda/typescript/latest/utilities/parser/#safe-parsing).
:::

:::tip[Dữ liệu Sự kiện Tùy chỉnh]
Nếu bạn có dữ liệu tùy chỉnh lồng trong một sự kiện, ví dụ như một luồng DynamoDB hoặc sự kiện EventBridge, bạn có thể được hưởng lợi từ việc sử dụng [Envelopes](https://docs.powertools.aws.dev/lambda/typescript/latest/utilities/parser/#envelopes) để cung cấp type-safety cho dữ liệu tùy chỉnh đó.
:::
</OptionFilter>

<OptionFilter when={{ event: 'Any' }} description="event=Any — no parser middleware, event is typed as `any`">
Nếu bạn đã chọn `Any` cho `event` của mình, middleware `parser` không được kết nối và tham số `event` được gõ là `any`. Tạo lại hàm với một `event` cụ thể nếu bạn muốn type safety tại thời điểm biên dịch và xác thực thời gian chạy.
</OptionFilter>
