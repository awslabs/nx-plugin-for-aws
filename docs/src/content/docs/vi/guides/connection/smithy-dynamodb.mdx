Generator `connection` kết nối một <Link path="guides/ts-smithy-api">Smithy API</Link> với dự án <Link path="guides/ts-dynamodb">TypeScript DynamoDB</Link>, cấu hình phát triển cục bộ để cả hai khởi động cùng nhau một cách tự động.

## Điều kiện tiên quyết

Trước khi sử dụng generator này, hãy đảm bảo bạn có:

1. Một dự án <Link path="guides/ts-smithy-api">Smithy TypeScript API</Link> (được tạo bằng `ts#api` sử dụng `--framework=smithy`)
2. Một dự án <Link path="guides/ts-dynamodb">`ts#dynamodb`</Link>

## Kết quả của Generator

Generator cập nhật `project.json` của Smithy API để thêm một dependency từ target `dev` của nó đến target `dev` của dự án DynamoDB. Không có file nguồn nào bị sửa đổi.

## Sử dụng DynamoDB trong Operations

Import các entity factory từ package DynamoDB và sử dụng chúng bên trong các triển khai operation của bạn:

```ts title="packages/api/src/operations/list-examples.ts"
import { createExampleEntity } from '@my-scope/my-table';
import { ServiceContext } from '../context.js';
import { ListExamples as ListExamplesOperation } from '../generated/ssdk/index.js';

export const ListExamples: ListExamplesOperation<ServiceContext> = async () => {
  const entity = await createExampleEntity();
  const result = await entity.scan.go();
  return { items: result.data };
};
```
