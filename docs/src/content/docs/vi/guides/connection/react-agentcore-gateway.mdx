Generator `connection` có thể kết nối một <Link path="guides/react-website">React website</Link> với các agent được đặt phía sau một <Link path="guides/agentcore-gateway">AgentCore Gateway</Link> được tạo với `protocol: http`.

Trình duyệt chỉ giao tiếp với Gateway — các yêu cầu đến `<gatewayUrl>/<targetName>/invocations` được proxy đến agent runtime phía sau nó. Bởi vì website không bao giờ cần tiếp cận trực tiếp các runtime, các agent có thể được triển khai bên trong VPC, với Gateway là điểm vào duy nhất được quản lý cung cấp xác thực và khả năng quan sát.

## Điều kiện tiên quyết

Trước khi sử dụng generator này, hãy đảm bảo bạn có:

1. Một dự án <Link path="guides/react-website">React website</Link>
2. Một dự án <Link path="guides/agentcore-gateway">`agentcore-gateway`</Link> được tạo với `protocol: http`
3. Ít nhất một agent AG-UI hoặc HTTP được gắn vào Gateway thông qua <Link path="guides/connection/agentcore-gateway-agent">Gateway to agent connection generator</Link>

Generator tạo một website client cho **mỗi** agent AG-UI hoặc HTTP được gắn vào Gateway (các target A2A bị bỏ qua — chúng sử dụng JSON-RPC agent-to-agent, không phải giao thức trình duyệt). Nó tạo ra các client giống như khi kết nối website trực tiếp với từng agent (<Link path="guides/connection/react-agui">AG-UI/CopilotKit</Link> cho các agent AG-UI, một <Link path="guides/connection/react-py-agent">OpenAPI client</Link> cho các Python HTTP agent), được định tuyến qua Gateway thay vì tại runtime.

:::note[Xác thực]
Trình duyệt xác thực với **Gateway**, không phải các agent: SigV4 cho IAM Gateway (thông qua identity pool Cognito của website), hoặc JWT bearer token cho Cognito Gateway.
:::

## Đầu ra của Generator

Đối với mỗi agent AG-UI được đặt phía trước, các file giống như <Link path="guides/connection/react-agui">React to AG-UI agent connection</Link> được tạo ra (một `AguiProvider`, một hook `useAgui<Agent>` và một module component CopilotKit có theme), với hook đọc URL của Gateway từ runtime configuration:

<FileTree>

- packages/\<website>/src
  - components
    - AguiProvider.tsx CopilotKit provider đăng ký mỗi agent
    - copilot/ Các component chat có theme
  - hooks
    - useAgui\<Agent>.tsx Kết nối với agent thông qua route `/<targetName>/invocations` của Gateway

</FileTree>

Đối với mỗi Python HTTP agent được đặt phía trước, các file giống như <Link path="guides/connection/react-py-agent">React to Python agent connection</Link> được tạo ra (một OpenAPI client type-safe, các hook và một provider), với base URL của client được định tuyến qua Gateway.

URL của Gateway được đăng ký trong namespace `connection.gateways.<GatewayClassName>` của <Link path="guides/runtime-config">Runtime Configuration</Link>, do đó nó được xuất bản vào `runtime-config.json` của website.

## Cấp quyền truy cập cho người dùng website

Đối với **IAM** Gateway, cấp quyền cho người dùng đã xác thực của website để gọi nó (một **Cognito** Gateway không cần cấp quyền — trình duyệt xác thực bằng JWT bearer token của nó thay thế):

## Phát triển cục bộ

Target `dev` của website có thêm dependency vào target `dev` của dự án Gateway, target này khởi động local gateway cùng với mọi agent được gắn vào. Runtime configuration của website được ghi đè trong chế độ `local-dev` để trỏ URL của Gateway đến local gateway, do đó trình duyệt thực thi các route `/<targetName>/invocations` giống nhau ở cục bộ:

<NxCommands commands={["dev <website-name>"]} />

## Kết nối các agent mới

Generator kết nối website với các agent được gắn vào Gateway **tại thời điểm nó chạy**. Sau khi gắn thêm một agent khác vào Gateway, chạy lại connection generator để tạo website client của nó — các client hiện có không bị ảnh hưởng.
