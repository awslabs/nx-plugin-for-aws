Generator `connection` có thể kết nối <Link path="guides/ts-agent">TypeScript Agent</Link> của bạn với một [A2A](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-a2a.html) agent từ xa — có thể là <Link path="guides/ts-agent">TypeScript</Link> hoặc <Link path="guides/py-agent">Python</Link> — để agent của bạn có thể ủy quyền cho một agent khác như một công cụ.

Generator thiết lập tất cả các kết nối cần thiết để agent của bạn có thể khám phá và gọi A2A agent từ xa, cả khi triển khai lên AWS (thông qua Bedrock AgentCore) và khi chạy cục bộ.

## Điều kiện tiên quyết

Trước khi sử dụng generator này, hãy đảm bảo bạn có:

1. Một dự án TypeScript với component <Link path="guides/ts-agent">Strands Agent</Link> (bất kỳ giao thức nào)
2. Một dự án với component Agent được tạo bằng `--protocol=a2a` và `--auth=iam` (có thể là <Link path="guides/ts-agent">`ts#agent`</Link> hoặc <Link path="guides/py-agent">`py#agent`</Link>)
3. Cả hai component được tạo với `infra: agentcore`

## Kết quả của Generator

Generator tạo một package `agent-connection` được chia sẻ và sửa đổi mã agent của bạn:

<FileTree>

- packages/common/agent-connection
  - src
    - app
      - \<target-agent-name>-client-strands.ts High-level Strands client for the connected A2A agent
    - core
      - agentcore-endpoints.ts Framework-agnostic ARN/URL resolution
      - agentcore-fetch.ts Framework-agnostic SigV4 / JWT / session-forwarding fetch
      - agentcore-a2a-client-config.ts Framework-agnostic A2A client config (signed `clientFactory`)
      - agentcore-a2a-client-strands.ts Strands A2A client wrapping the config
    - index.ts Exports all clients
  - project.json
  - tsconfig.json

</FileTree>

Ngoài ra, nó:
- Chuyển đổi `agent.ts` của agent để đăng ký A2A agent từ xa như một Strands `tool`
- Cập nhật target `dev` của agent để phụ thuộc vào target `dev` của target agent
- Cài đặt các dependency cần thiết

## Sử dụng A2A Agent đã kết nối

Generator chuyển đổi `agent.ts` của agent để bao bọc A2A agent từ xa như một công cụ:

```ts title="packages/example/src/my-agent/agent.ts" {2,5-12,15}
import { Agent, tool } from '@strands-agents/sdk';
import { RemoteAgentClientStrands } from '@my-scope/agent-connection';
import { z } from 'zod';

export const getAgent = async () => {
  const remoteAgent = await RemoteAgentClientStrands.create();
  const remoteAgentTool = tool({
    name: 'askRemoteAgent',
    description: 'Delegate a question to the remote RemoteAgent A2A agent and return its reply.',
    inputSchema: z.object({ prompt: z.string() }),
    callback: async ({ prompt }) => (await remoteAgent.invoke(prompt)).toString(),
  });
  return new Agent({
    systemPrompt: '...',
    tools: [remoteAgentTool],
  });
};
```

Session ID của AgentCore được truyền tự động đến remote agent thông qua header `X-Amzn-Bedrock-AgentCore-Runtime-Session-Id`, vì vậy `create()` không nhận tham số nào: agent server liên kết session của request đến vào một ngữ cảnh [`AsyncLocalStorage`](https://nodejs.org/api/async_context.html#class-asynclocalstorage) (`enterSessionContext` trong `router.ts` được tạo, hoặc `runWithSessionId` trong middleware session A2A/AG-UI), và fetch của connection client trong `agentcore-fetch.ts` đóng dấu nó trên mọi lời gọi đi — đảm bảo tính nhất quán cho [Bedrock AgentCore Observability](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/observability.html).

Bên trong, `RemoteAgentClientStrands.create()` trả về một Strands `A2AAgent` được cấu hình với `clientFactory` ký SigV4 khi triển khai lên AWS, và một endpoint `http://localhost:<port>/` đơn giản khi `LOCAL_DEV=true`. Việc ký và phân giải endpoint nằm trong `agentcore-a2a-client-config.ts` không phụ thuộc framework; chỉ có `agentcore-a2a-client-strands.ts` mỏng phụ thuộc vào Strands.

## Phát triển cục bộ

Generator cấu hình target `dev` của host agent để:
1. Tự động khởi động (các) A2A agent đã kết nối
2. Đặt `LOCAL_DEV=true` để client được tạo kết nối trực tiếp với `http://localhost:<port>/` thay vì AgentCore

Chạy agent cục bộ với:

<NxCommands commands={["<agent-name>-dev <project-name>"]} />

Điều này sẽ khởi động cả host agent và tất cả các A2A agent đã kết nối, với host agent gọi các remote agent qua HTTP đơn giản trên các cổng cục bộ được chỉ định của chúng.
