Generator `connection` kết nối một <Link path="guides/ts-mcp-server">TypeScript MCP Server</Link> với dự án <Link path="guides/ts-dynamodb">TypeScript DynamoDB</Link>, cấu hình phát triển cục bộ để cả hai khởi động cùng nhau tự động.

## Điều kiện tiên quyết

Trước khi sử dụng generator này, hãy đảm bảo bạn có:

1. Một dự án <Link path="guides/ts-mcp-server">`ts#mcp-server`</Link>
2. Một dự án <Link path="guides/ts-dynamodb">`ts#dynamodb`</Link>

## Kết quả của Generator

Generator cập nhật target `<mcp-server-name>-dev` của MCP server trong `project.json` để phụ thuộc vào target `dev` của dự án DynamoDB. Không có file nguồn nào được sửa đổi.

## Sử dụng DynamoDB trong Tools

Import các entity factory từ package DynamoDB và sử dụng chúng bên trong `createServer`:

```ts title="packages/my-service/src/my-mcp/server.ts"
import { createExampleEntity } from '@my-scope/my-table';

export const createServer = async () => {
  const server = new McpServer({ name: 'my-service', version: '1.0.0' });

  server.tool('list_examples', 'List all example items', {}, async () => {
    const entity = await createExampleEntity();
    const result = await entity.scan.go();
    return {
      content: [{ type: 'text', text: JSON.stringify(result.data) }],
    };
  });

  return server;
};
```

## Infrastructure

Để cho phép MCP server truy cập bảng DynamoDB, hãy cấp các quyền cần thiết trong infrastructure của bạn.

<Infrastructure>
<Fragment slot="cdk">

```ts title="packages/infra/src/stacks/application-stack.ts"
import { MyTable } from '@my-scope/common-constructs';

const table = new MyTable(this, 'Table');
const myMcpServer = new MyMcpServer(this, 'MyMcpServer');

table.grantReadWriteData(myMcpServer);
```

`grantReadWriteData` cấp cả quyền DynamoDB và KMS cho execution role của MCP server.
</Fragment>
<Fragment slot="terraform">

Cấp quyền truy cập cho runtime role của MCP server vào bảng và khóa mã hóa KMS của nó thông qua `additional_iam_policy_statements`:

```hcl title="packages/infra/src/main.tf"
module "my_table" {
  source = "../../common/terraform/src/app/dynamodb/my-table"
}

module "my_mcp_server" {
  source = "../../common/terraform/src/app/mcp-servers/my-mcp-server"

  additional_iam_policy_statements = [
    {
      Effect = "Allow"
      Action = [
        "dynamodb:GetItem", "dynamodb:PutItem", "dynamodb:UpdateItem",
        "dynamodb:DeleteItem", "dynamodb:Query", "dynamodb:Scan",
        "dynamodb:BatchGetItem", "dynamodb:BatchWriteItem",
      ]
      Resource = [
        module.my_table.table_arn,
        "${module.my_table.table_arn}/index/*",
      ]
    },
    {
      Effect = "Allow"
      Action = [
        "kms:Encrypt",
        "kms:Decrypt",
        "kms:ReEncrypt*",
        "kms:GenerateDataKey*",
        "kms:DescribeKey",
      ]
      Resource = [module.my_table.kms_key_arn]
    },
  ]
}
```
</Fragment>
</Infrastructure>
