Trình tạo `connection` cho phép <Link path="guides/py-agent">Python Agent</Link> gọi một dịch vụ container được tạo bằng <Link path="guides/ts-container">`ts#container`</Link> hoặc <Link path="guides/py-container">`py#container`</Link>. Nó thêm một client vào dự án `agent_connection` dùng chung, client này đọc URL của dịch vụ từ cấu hình runtime và ký mỗi yêu cầu bằng thông tin xác thực AWS của chính agent.

## Cách hoạt động

Một dịch vụ container với `infra=ecs` chạy trên Amazon ECS (Elastic Container Service) đằng sau một Application Load Balancer nội bộ. Với `ingress=http-api` mặc định, một Amazon API Gateway HTTP API (một điểm cuối HTTPS được quản lý) kết nối đến load balancer đó thông qua VPC link, đây là kết nối riêng tư của API Gateway vào VPC của bạn. Agent gọi HTTP API.

Client ký mỗi yêu cầu bằng SigV4, quy trình ký yêu cầu của AWS, sử dụng thông tin xác thực của vai trò agent. HTTP API chấp nhận yêu cầu khi vai trò đó có thể gọi `execute-api:Invoke` trên nó. HTTP API kết thúc bất kỳ yêu cầu nào mất hơn 30 giây, vì vậy một route chạy lâu hơn phải trả về sớm và hoàn thành công việc của nó ở chế độ nền.

Trình tạo từ chối một dịch vụ mà nó không thể kết nối theo cách này. Dịch vụ phải có `infra=ecs`, vì `infra=none` không tạo điểm cuối nào. Nó phải có `ingress=http-api`, vì một dịch vụ `private` chỉ có thể truy cập được từ bên trong VPC của nó. Nó phải có `auth=iam`, vì agent ký các yêu cầu của nó bằng thông tin xác thực IAM và không có token Cognito để gửi.

## Điều kiện tiên quyết

Trước khi sử dụng trình tạo này, hãy đảm bảo bạn có:

1. Một dự án <Link path="guides/py-agent">`py#agent`</Link>
2. Một dịch vụ container với `infra=ecs`, `ingress=http-api` và `auth=iam` (được tạo bằng trình tạo <Link path="guides/ts-container">`ts#container`</Link> hoặc <Link path="guides/py-container">`py#container`</Link>)

## Đầu ra của trình tạo

Trình tạo tạo các tệp sau trong dự án `agent_connection` dùng chung:

<FileTree>

- packages/common/agent\_connection
  - my\_scope\_agent\_connection
    - app
      - \<service\_name>\_client.py Client đọc URL của dịch vụ từ cấu hình runtime và ký các yêu cầu bằng SigV4
    - \_\_init\_\_.py Xuất `get_<service_name>_client`

</FileTree>

Nó thêm `httpx` và `boto3` vào dự án `agent_connection`, thêm dự án `agent_connection` làm phụ thuộc của dự án agent của bạn, và làm cho target `<agent-name>-dev` của agent khởi động target `<service-name>-serve` của dịch vụ.

## Sử dụng Client

`get_<service_name>_client()` đọc URL của dịch vụ từ namespace `connection` của <Link path="guides/runtime-config">cấu hình runtime</Link>, dưới `services.<ServiceName>`. Nó trả về một `httpx.Client` có các đường dẫn tương đối với dịch vụ. Trình tạo không thay đổi mã của agent của bạn. Để cho phép mô hình gọi dịch vụ, hãy bọc client trong một công cụ:

```python title="packages/my_project/my_project/my_agent/agent.py"
from my_scope_agent_connection import get_my_service_client
from strands import tool


@tool
def check_my_service() -> int:
    """Check whether the MyService container service is healthy."""
    with get_my_service_client() as client:
        return client.get("/health").status_code
```

Thêm `check_my_service` vào danh sách `tools` của agent của bạn. `get_my_service_client()` báo lỗi khi `RUNTIME_CONFIG_APP_ID` không được đặt, khi nó không thể tìm thấy AWS Region (từ `AWS_REGION`, `AWS_DEFAULT_REGION` hoặc phiên boto3) để ký yêu cầu, hoặc khi cấu hình runtime không có mục nhập cho dịch vụ.

## Cơ sở hạ tầng

Vai trò của agent cần quyền để gọi HTTP API của dịch vụ. Trình tạo không thay đổi stack hoặc module Terraform gốc của bạn. Thay vào đó, nó in mã để thêm, được hiển thị bên dưới cho một agent có tên `my-agent` và một dịch vụ có tên `my-service`. Cho đến khi bạn thêm nó, HTTP API sẽ từ chối các yêu cầu của agent với 403 Forbidden.

<Infrastructure>
<Fragment slot="cdk">

Trong ví dụ, `myService` là construct `MyService` của bạn và `myAgent` là construct `MyAgent` của bạn:

```ts title="packages/infra/src/stacks/application-stack.ts"
myService.grantInvoke(myAgent);
```

`grantInvoke` cho phép vai trò của agent gọi `execute-api:Invoke` trên HTTP API của dịch vụ.

</Fragment>
<Fragment slot="terraform">

Thêm câu lệnh vào `additional_iam_policy_statements` của agent, bên cạnh bất kỳ câu lệnh nào mà khối đã liệt kê. Trong ví dụ, `module "my_service"` triển khai dịch vụ:

```hcl title="packages/infra/src/main.tf"
module "my_agent" {
  source = "../../common/terraform/src/app/agents/my-agent"
  # ...existing arguments...
  additional_iam_policy_statements = [
    {
      Effect   = "Allow"
      Action   = ["execute-api:Invoke"]
      Resource = ["${module.my_service.api_execution_arn}/*"]
    },
  ]
}
```
