Đối với REST API, construct được tạo ra sẽ liên kết một [AWS WAFv2](https://docs.aws.amazon.com/waf/latest/developerguide/waf-chapter.html) Web ACL với API Gateway stage theo mặc định. Web ACL sử dụng bộ quy tắc mặc định được quản lý bởi AWS ([`AWSManagedRulesCommonRuleSet`](https://docs.aws.amazon.com/waf/latest/developerguide/aws-managed-rule-groups-baseline.html#aws-managed-rule-groups-baseline-crs) và [`AWSManagedRulesKnownBadInputsRuleSet`](https://docs.aws.amazon.com/waf/latest/developerguide/aws-managed-rule-groups-baseline.html#aws-managed-rule-groups-baseline-known-bad-inputs)), cung cấp bảo vệ chống lại các lỗ hổng web phổ biến bao gồm OWASP Top 10. Nhật ký yêu cầu WAF được ghi vào một nhóm CloudWatch Logs.

:::caution[Sự khác biệt của SizeRestrictions_BODY so với mặc định]
Quy tắc `SizeRestrictions_BODY` từ `AWSManagedRulesCommonRuleSet` được ghi đè thành `Count` thay vì `Block`, vì giới hạn 8 KB của quy tắc này quá hạn chế đối với hầu hết các API. Các yêu cầu có kích thước quá lớn vẫn sẽ được ghi lại dưới dạng số liệu để bạn có thể theo dõi chúng. Xem hướng dẫn [AWS WAF body size limits](https://docs.aws.amazon.com/waf/latest/developerguide/waf-rule-statement-oversize-handling.html) để biết thêm chi tiết. API Gateway tự nhiên thực thi [kích thước payload tối đa là 10 MB](https://docs.aws.amazon.com/apigateway/latest/developerguide/limits.html), trả về `413` cho các yêu cầu lớn hơn.
:::

Bạn có thể chỉnh sửa rest-api construct được tạo ra để thêm, xóa hoặc điều chỉnh các quy tắc (ví dụ: để thêm [quy tắc dựa trên tốc độ](https://docs.aws.amazon.com/waf/latest/developerguide/waf-rule-statement-type-rate-based.html) hoặc các nhóm quy tắc được quản lý bổ sung).

<Infrastructure>
<Fragment slot="cdk">
Để chọn không sử dụng (ví dụ: để đính kèm Web ACL của riêng bạn), đặt `enableWaf` thành `false`:

```ts {3}
const api = new MyApi(this, 'MyApi', {
  integrations: MyApi.defaultIntegrations(this).build(),
  enableWaf: false,
});
```
</Fragment>
<Fragment slot="terraform">
Để chọn không sử dụng (ví dụ: để đính kèm Web ACL của riêng bạn), đặt `enable_waf` thành `false`:

```hcl {5}
module "my_api" {
  source = "../../common/terraform/src/app/apis/my-api"

  asset_bucket_name = module.asset_bucket.bucket_name
  enable_waf        = false
}
```
</Fragment>
