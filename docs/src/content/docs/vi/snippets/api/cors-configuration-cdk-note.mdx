:::note[Cấu hình CORS CDK]
Nếu giải pháp của bạn bao gồm một website, bạn có thể cấu hình phân phối CloudFront của nó làm nguồn gốc CORS duy nhất được phép trong API gateway / tích hợp API AWS Lambda cho HTTP / REST APIs.
Bạn có thể gọi phương thức `restrictCorsTo` của API với các construct website, phân phối CloudFront, chuỗi nguồn gốc, hoặc kết hợp của chúng.

```ts
import { MyApi, MyWebsite } from '@my-scope/common-constructs';

export class ExampleStack extends Stack {
  constructor(scope: Construct, id: string) {
    const api = new MyApi(this, 'MyApi', {
      integrations: MyApi.defaultIntegrations(this).build(),
    });
    const website = new MyWebsite(this, 'MyWebsite');
    api.restrictCorsTo(website, 'http://localhost:4200', 'http://localhost:4300');
  }
}
```

Construct `MyWebsite` có thể được tạo bằng cách sử dụng <Link path="/vi/guides/react-website">trình tạo `ts#website`</Link>. Ví dụ này giả định rằng dev-server cục bộ và cổng xem trước của website là `4200`/`4300` - kiểm tra `project.json` (hoặc `vite.config.mts`) của nó để biết các cổng thực sự được gán cho nó, vì mỗi website được tạo theo cách này sẽ có cổng riêng.
:::
