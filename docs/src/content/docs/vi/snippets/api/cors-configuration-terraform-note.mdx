:::note[Cấu hình CORS trong Terraform]
Nếu giải pháp của bạn bao gồm một module website Terraform thì bạn có thể sử dụng tên miền CloudFront của nó để hạn chế CORS.
Với tên miền CloudFront `<domain_name>`, trong module Terraform để triển khai API của bạn, hãy thêm
- một thuộc tính `cors_allow_origins`, đặt thành `["http://localhost:4200", "http://localhost:4300", "https://<domain name>"]`, cho HTTP APIs. Điều này hạn chế CORS của API gateway chỉ cho distribution này và local host.
- một biến môi trường `ALLOWED_ORIGINS`, đặt thành `"https://<domain_name>"`, cho REST APIs. Điều này đặt CloudFront distribution là nguồn gốc CORS duy nhất được phép (ngoài local host) trong các tích hợp AWS Lambda. Lưu ý rằng hạn chế này không được áp dụng cho preflight OPTIONS - vui lòng +1 [GitHub issue này](https://github.com/awslabs/nx-plugin-for-aws/issues/377) để giúp ưu tiên giải quyết vấn đề này.

```hcl {6,9}
module "my_api" {
  source = "../../common/terraform/src/app/apis/my-api"

  asset_bucket_name = module.asset_bucket.bucket_name

  cors_allow_origins = ["http://localhost:4200", "http://localhost:4300", "https://<domain name>"] // Only required for HTTP API

  env = {
    ALLOWED_ORIGINS = "https://<domain name>" // Only required for REST API
    ENVIRONMENT = var.environment
    LOG_LEVEL   = "INFO"
  }
}
```
Construct `MyWebsite` có thể được tạo bằng cách sử dụng <Link path="/guides/react-website">generator `ts#website`</Link>. Ví dụ này giả định các cổng local của website là `4200`/`4300` - kiểm tra `project.json` (hoặc `vite.config.mts`) của nó để biết các cổng thực sự được gán cho nó, vì mỗi website được tạo theo cách này sẽ có cổng riêng.
:::
