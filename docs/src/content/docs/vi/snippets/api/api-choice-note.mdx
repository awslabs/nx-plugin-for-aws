---
title: Chọn giữa REST và HTTP
---
:::note[Lựa chọn Loại API]
Bạn có thể chọn giữa [REST API](https://docs.aws.amazon.com/apigateway/latest/developerguide/apigateway-rest-api.html) hoặc [HTTP API](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api.html) để triển khai API của mình, vui lòng tham khảo [API Gateway Developer Guide](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-vs-rest.html) để giúp bạn quyết định.
:::
