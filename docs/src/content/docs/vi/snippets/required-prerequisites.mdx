---
title: Điều kiện tiên quyết bắt buộc
---
- [Git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)
- [Node >= 22](https://nodejs.org/en/download) (Chúng tôi khuyến nghị sử dụng công cụ như [NVM](https://github.com/nvm-sh/nvm) để quản lý các phiên bản node của bạn)
  - xác minh bằng cách chạy `node --version`
- [UV >= 0.5.29](https://docs.astral.sh/uv/getting-started/installation/)
  1. cài đặt Python 3.14 bằng cách chạy: `uv python install 3.14`
  2. xác minh với `uv python list --only-installed`
