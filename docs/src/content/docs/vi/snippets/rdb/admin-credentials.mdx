Mật khẩu của người dùng admin (master) Aurora được tạo và xoay vòng bởi chính Aurora trong AWS Secrets Manager, sử dụng [RDS-managed master user passwords](https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/rds-secrets-manager.html). Mã cơ sở hạ tầng của bạn không bao giờ nhận được mật khẩu, vì vậy nó không thể rò rỉ vào template CloudFormation hoặc file state của Terraform. Aurora xoay vòng secret mỗi 7 ngày mà không cần bất kỳ hàm xoay vòng nào để triển khai hoặc bảo trì.

Secret được mã hóa bằng cùng một KMS key do khách hàng quản lý như cluster.

Ứng dụng của bạn không bao giờ sử dụng các thông tin xác thực này. Nó kết nối với tư cách là người dùng cơ sở dữ liệu có quyền tối thiểu bằng cách sử dụng xác thực IAM — chỉ các handler migration và create-db-user đọc admin secret, và mỗi handler được cấp quyền truy cập vào chỉ secret đó và KMS key của nó.

<Infrastructure>
<Fragment slot="cdk">

Admin secret được hiển thị dưới dạng `secret.secretArn` trên cluster cơ bản, và `grantSecretRead` cấp quyền truy cập đọc cho consumer:

```ts title="packages/infra/src/stacks/application-stack.ts"
import { MyDatabase } from '@my-scope/common-constructs';

const db = new MyDatabase(this, 'Db', { ... });

db.grantSecretRead(myFunction);
```
</Fragment>
<Fragment slot="terraform">

ARN của admin secret được hiển thị dưới dạng output `secret_arn`, cùng với `kms_key_arn` cần thiết để giải mã nó:

```hcl title="packages/infra/src/main.tf"
module "my_database" {
  source = "../../common/terraform/src/app/dbs/my-database"
  ...
}

output "database_secret_arn" {
  value = module.my_database.secret_arn
}
```

Một RDS-managed secret chứa một đối tượng JSON chỉ với `username` và `password` — không có chi tiết kết nối. Lấy host, port và tên cơ sở dữ liệu từ các output `writer_endpoint`, `cluster_port` và `database_name` của module.
</Fragment>
</Infrastructure>

:::caution[Xoay vòng thủ công]
Việc xoay vòng mật khẩu admin ngoài lịch trình của Aurora được thực hiện thông qua RDS API (`modify-db-cluster --rotate-master-user-password --apply-immediately`), không phải thông qua Secrets Manager. Việc đính kèm hàm xoay vòng của riêng bạn vào một RDS-managed secret sẽ bị từ chối.
:::
