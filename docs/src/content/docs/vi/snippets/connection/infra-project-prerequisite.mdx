:::note[Yêu cầu dự án hạ tầng]
Các trình tạo agent, MCP server và Gateway cung cấp các construct và module của chúng vào `packages/common`, nhưng chúng không tạo ứng dụng để triển khai chúng — do đó `packages/infra` không tồn tại cho đến khi bạn tạo nó. Chạy trình tạo <Link path="guides/typescript-infrastructure">`ts#infra`</Link> (CDK) hoặc trình tạo <Link path="guides/terraform-project">`terraform#project`</Link> (Terraform) trước khi chỉnh sửa tệp bên dưới.
:::
