[AWS Arch](https://aws.github.io/aws-pdk/developer_guides/aws-arch/index.html) cung cấp ánh xạ giữa các tài nguyên CloudFormation và các biểu tượng kiến trúc liên quan của chúng cho CDK Graph ở trên.

Tham khảo [trang AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) để biết các tài nguyên liên quan đến biểu tượng. [Diagrams](https://diagrams.mingrammer.com/) cũng cung cấp cách để xây dựng sơ đồ dưới dạng mã.

Nếu bạn đang sử dụng trực tiếp điều này, hãy cân nhắc fork dự án và tự quản lý!
