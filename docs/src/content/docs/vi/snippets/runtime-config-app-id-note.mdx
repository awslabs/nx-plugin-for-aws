title: Ghi chú về App ID của Runtime Config
---
import Link from '@components/link.astro';

:::note[Runtime config]
Điều này dựa vào biến môi trường `RUNTIME_CONFIG_APP_ID` để lấy cấu hình từ AWS AppConfig tại runtime. Các dự án được xây dựng với plugin này (API, Agent, MCP server) đã có biến này được cấu hình tự động. Đối với các dự án khác, hãy đảm bảo `RUNTIME_CONFIG_APP_ID` được thiết lập trong môi trường runtime với AppConfig application ID được cung cấp bởi cơ sở hạ tầng của bạn. Để biết thêm thông tin, xem <Link path="guides/runtime-config">hướng dẫn Runtime Configuration</Link>.
:::
