## Bước 1: Khởi Tạo Nx Workspace Mới

Chạy lệnh sau để tạo một <Link path="guides/workspace">Nx workspace</Link> với trình quản lý gói bạn chọn:

<CreateNxWorkspaceCommand workspace="my-project" />

:::tip[Chọn Nhà Cung Cấp IaC]
Bạn sẽ được nhắc chọn nhà cung cấp infrastructure as code (IaC) ưa thích, có thể là [CDK](https://docs.aws.amazon.com/cdk/) hoặc [Terraform](https://developer.hashicorp.com/terraform). Bạn có thể bỏ qua lời nhắc bằng cách chạy lệnh với `--iac`, ví dụ:

<Infrastructure>
<Fragment slot="cdk">
<CreateNxWorkspaceCommand workspace="my-project" iac="cdk" />
</Fragment>
<Fragment slot="terraform">
<CreateNxWorkspaceCommand workspace="my-project" iac="terraform" />
</Fragment>
</Infrastructure>
:::

Sau khi hoàn tất, điều hướng đến thư mục dự án:

```sh
cd my-project
```

## Bước 2: Sử Dụng Generators để Tạo Khung Dự Án

Chúng ta sẽ thêm tRPC API, React Website, Cognito Authentication, và CDK hoặc Terraform Infrastructure trong hướng dẫn bắt đầu nhanh này. Tùy thuộc vào loại dự án bạn đang xây dựng, bạn có thể chọn bất kỳ tổ hợp generators nào để nhanh chóng khởi tạo dự án của mình. Xem __Generators__ trong thanh điều hướng bên trái để xem danh sách đầy đủ các tùy chọn, hoặc thử <Link path="get_started/graph-builder">graph builder</Link> để xây dựng workspace của bạn một cách trực quan.

Để tiết kiệm thời gian, bạn có thể sử dụng nút bên dưới để sao chép các lệnh tạo khung cho toàn bộ ứng dụng.

<EmbeddedGraph preset="quick-start" workspace="my-project" iac="cdk" orientation="horizontal" skipWorkspace />

:::tip[Xây Dựng với AI]
<Link path="get_started/building-with-ai">Nx Plugin for AWS MCP Server</Link> đã được cấu hình sẵn trong workspace của bạn, vì vậy bạn có thể yêu cầu AI coding agent yêu thích của mình như Kiro hoặc Claude xây dựng các dự án này cho bạn thay vì tự gõ các lệnh CLI.
:::

Nếu không, hãy làm theo các bước bên dưới để chạy từng generator.

### Thêm tRPC API

<RunGenerator generator="ts#api" requiredParameters={{ name: 'demo-api', framework: 'trpc', auth: 'iam' }} />

Điều này sẽ tạo API bên trong thư mục `packages/demo-api`.

### Thêm React Website

<RunGenerator generator="ts#website" requiredParameters={{ name: 'demo-website' }} />

Điều này tạo khung một React website mới trong `packages/demo-website`.

### Thêm Cognito Authentication

<RunGenerator generator="ts#website#auth" requiredParameters={{ project: '@my-project/demo-website', cognitoDomain: 'my-demo' }} />

Điều này thiết lập cơ sở hạ tầng cần thiết và mã React để thêm Cognito Authentication vào website của bạn.

### Kết Nối Frontend với Backend

<RunGenerator generator="connection" requiredParameters={{ sourceProject: '@my-project/demo-website', targetProject: '@my-project/demo-api' }} noInteractive />

Điều này cấu hình các providers cần thiết để đảm bảo website của bạn có thể gọi tRPC API.

## Bước 3: Chạy Website và API Cục Bộ

Sử dụng lệnh sau để khởi động các dev server cục bộ cho website và các API được kết nối:

<PackageManagerShortCommand commands={["dev"]} />

Website của bạn sẽ có sẵn tại `http://localhost:4200`.

Các thay đổi đối với cả website và API sẽ được phản ánh theo thời gian thực vì cả website và API server cục bộ đều sẽ hot-reload.

## Bước 4: Định Nghĩa Cloud Resources và Triển Khai lên AWS

<Infrastructure>
<Fragment slot="cdk">
Mở `packages/infra/src/stacks/application-stack.ts` và thêm đoạn mã sau:

```typescript
import { Stack, StackProps } from 'aws-cdk-lib';
import { DemoApi, DemoWebsite, UserIdentity } from '@my-project/common-constructs';
import { Construct } from 'constructs';

export class ApplicationStack extends Stack {
  constructor(scope: Construct, id: string, props?: StackProps) {
    super(scope, id, props);

    const identity = new UserIdentity(this, 'identity');
    const api = new DemoApi(this, 'api', {
      integrations: DemoApi.defaultIntegrations(this).build(),
    });
    api.grantInvokeAccess(identity.identityPool.authenticatedRole);

    new DemoWebsite(this, 'website');
  }
}
```

Đây là tất cả CDK chúng ta cần viết để triển khai ứng dụng full stack của mình.
</Fragment>
<Fragment slot="terraform">
Mở `packages/infra/src/main.tf` và thêm đoạn mã sau:

```hcl
# Include metrics tracking for @aws/nx-plugin usage
module "metrics" {
  source = "../../common/terraform/src/metrics"
}

# Deploy user identity
module "user_identity" {
  source = "../../common/terraform/src/core/user-identity"
}

# Shared asset bucket — stages Lambda deployment zips for every lambda / API module
module "asset_bucket" {
  source = "../../common/terraform/src/core/asset-bucket"
}

# Deploy API
module "demo_api" {
  source = "../../common/terraform/src/app/apis/demo-api"

  asset_bucket_name = module.asset_bucket.bucket_name
}

# Grant authenticated users access to invoke the API
resource "aws_iam_policy" "api_invoke_policy" {
  name        = "DemoApiInvokePolicy"
  description = "Policy to allow authenticated users to invoke the API"

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect = "Allow"
        Action = "execute-api:Invoke"
        Resource = "${module.demo_api.api_execution_arn}/*/*"
      }
    ]
  })
}

resource "aws_iam_role_policy_attachment" "authenticated_api_access" {
  role       = module.user_identity.authenticated_role_name
  policy_arn = aws_iam_policy.api_invoke_policy.arn
}

# Deploy website
provider "aws" {
  alias  = "us_east_1"
  region = "us-east-1"
}

module "demo_website" {
  source = "../../common/terraform/src/app/static-websites/demo-website"

  providers = {
    aws.us_east_1 = aws.us_east_1
  }

  depends_on = [module.user_identity, module.demo_api]
}
```

Đây là tất cả Terraform chúng ta cần viết để triển khai ứng dụng full stack của mình.
</Fragment>
</Infrastructure>

### Build và Triển Khai Infrastructure

Tiếp theo, chạy lệnh sau để build dự án của bạn:

<PackageManagerShortCommand commands={["build"]} />

:::tip[Sửa Lỗi Lint]
Nếu bạn gặp bất kỳ lỗi lint nào, bạn có thể chạy lệnh sau để tự động sửa chúng.

<PackageManagerShortCommand commands={["lint"]} />
:::

Bootstrap cơ sở hạ tầng của bạn:

<Infrastructure>
<Fragment slot="cdk">
<NxCommands commands={['bootstrap infra']} />

:::tip[Bootstrap Regions]
CDK bootstrapping là bắt buộc cho cả AWS region triển khai mục tiêu của bạn và `us-east-1` để cho phép triển khai AWS WAF WebACL cho website.
:::
</Fragment>
<Fragment slot="terraform">
<NxCommands commands={['bootstrap infra']} />

:::tip[Thiết Lập Một Lần]
Terraform bootstrapping tạo một S3 bucket để lưu trữ các tệp Terraform state của bạn. Điều này chỉ cần thực hiện một lần cho mỗi tổ hợp AWS account/region.
:::
</Fragment>
</Infrastructure>

Triển khai dự án của bạn:

<Infrastructure>
<Fragment slot="cdk">
<NxCommands commands={['deploy infra "my-project-infra-sandbox/*"']} />
</Fragment>
<Fragment slot="terraform">
<NxCommands commands={['apply infra']} />

:::tip[Plan Trước Khi Apply]
Lệnh này sẽ chạy `terraform plan` trước để hiển thị những thay đổi sẽ được thực hiện, sau đó áp dụng những thay đổi đó để triển khai cơ sở hạ tầng của bạn.
:::
</Fragment>
</Infrastructure>

## Bước 5: Kiểm Tra Website với Cloud Resources Đã Triển Khai

<Steps>
1. Tải tệp `runtime-config.json`:

    <NxCommands commands={['load-runtime-config demo-website']} />

2. Khởi động local website server

    <NxCommands commands={['serve demo-website']} />
</Steps>

Website của bạn sẽ có sẵn tại `http://localhost:4200`, và sẽ trỏ đến các tài nguyên bạn đã triển khai cho API và authentication.
