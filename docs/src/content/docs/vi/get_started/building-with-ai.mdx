Cài đặt [Claude Plugin](https://code.claude.com/docs/en/plugins), [Kiro Power](https://kiro.dev/docs/powers/), hoặc [MCP Server](https://modelcontextprotocol.io/introduction) để cho phép các trợ lý AI làm việc hiệu quả với plugin. Bằng cách sử dụng những công cụ này, bạn có thể tăng tốc quy trình phát triển của mình với AI trong khi hưởng lợi từ việc các dự án của bạn được tạo khung một cách nhất quán, dành ít thời gian hơn cho việc thiết lập các thành phần chính và hưởng lợi từ tính bảo mật, khả năng quan sát, type-safety và phát triển cục bộ được tích hợp sẵn trong plugin.

## Cấu hình Trợ lý AI của bạn

:::tip[Cấu hình cấp dự án là tự động]
Các workspace được tạo với preset Nx Plugin for AWS đã bao gồm cấu hình MCP cấp dự án cho các coding agent phổ biến (Claude Code, Cursor, Kiro, Gemini CLI, GitHub Copilot và OpenAI Codex). Bất kỳ agent nào làm việc bên trong workspace đều có thể sử dụng MCP server mà không cần thiết lập thêm. Các bước dưới đây cấu hình MCP server toàn cục để sử dụng trên tất cả các dự án của bạn.
:::

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    Nx Plugin for AWS được cung cấp dưới dạng [Kiro Power](https://kiro.dev/docs/powers/) đi kèm với MCP server cùng tài liệu hướng dẫn và quy trình làm việc.

    <Steps>

    1. Mở bảng Powers trong Kiro và nhấp vào **Add power from GitHub**
    2. Nhập URL sau:

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. Nhấp vào **Install**

    </Steps>

    Kiro tự động cấu hình MCP server — không cần thiết lập thêm.

  </TabItem>
  <TabItem label="Kiro CLI">
    Chạy lệnh sau:

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    Xem [Kiro CLI MCP docs](https://kiro.dev/docs/cli/mcp/) để biết thêm chi tiết.

  </TabItem>
  <TabItem label="Claude Code">
    Nx Plugin for AWS được phân phối dưới dạng [Claude Code plugin](https://code.claude.com/docs/en/plugins) đi kèm với [Skill](https://code.claude.com/docs/en/skills) cùng MCP server.

    Chạy các lệnh sau bên trong Claude Code, từng lệnh một:

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    Sau đó chạy `/reload-plugins` để kích hoạt plugin.

  </TabItem>
  <TabItem label="Cursor">
    Thêm nội dung sau vào `~/.cursor/mcp.json` (hoặc `.cursor/mcp.json` trong dự án của bạn):

    <Snippet name="mcp/config" />

    Xem [Cursor MCP docs](https://cursor.com/docs/mcp) để biết thêm chi tiết.

  </TabItem>
  <TabItem label="Codex">
    Thêm nội dung sau vào `~/.codex/config.toml`:

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    Xem [Codex config docs](https://developers.openai.com/codex/config-reference) để biết thêm chi tiết.

  </TabItem>
  <TabItem label="Other">
    Hầu hết các trợ lý tương thích MCP sử dụng tệp cấu hình JSON. Thêm mục sau:

    <Snippet name="mcp/config" />

    Nếu bạn gặp vấn đề như `ENOENT npx`, hãy thay thế lệnh bằng đường dẫn đầy đủ đến `npx` (tìm nó bằng `which npx`).

    Để xem tài liệu cụ thể cho từng trợ lý:

## Bắt đầu Vibe Coding

Yêu cầu Trợ lý AI của bạn xây dựng thứ gì đó bằng cách sử dụng `nx-plugin-for-aws`! Nó thường sẽ tạo một workspace, tạo khung với các generator có thể áp dụng, sau đó điền vào logic nghiệp vụ.

Thử một prompt như:

> _"Build a multi-agent application using the Nx Plugin for AWS. I want a React frontend that talks to a backend orchestrator agent which delegates to specialised research and writing agents."_

Hoặc để có điểm khởi đầu nhỏ hơn:

> _"Use the Nx Plugin for AWS to scaffold a React website backed by a tRPC API, with Cognito auth and CDK infrastructure."_
