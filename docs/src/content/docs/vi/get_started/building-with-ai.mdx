## Đã được cấu hình trong workspace của bạn

Các workspace được tạo với preset Nx Plugin for AWS bao gồm cấu hình MCP cấp dự án cho các coding agent phổ biến — Claude Code, Cursor, Kiro, Gemini CLI, GitHub Copilot và OpenAI Codex — để một agent làm việc bên trong workspace có thể sử dụng [MCP server](https://modelcontextprotocol.io/introduction) của plugin mà không cần thiết lập thêm.

Mở workspace của bạn trong trợ lý và yêu cầu những gì bạn muốn:

<Prompt>
Add a React website with an AG-UI agent, an MCP server for its tools and a DynamoDB table, and wire them together.
</Prompt>

Nó sẽ tra cứu các generator mà plugin cung cấp, chạy chúng theo thứ tự mà các phụ thuộc cần, và điền vào logic nghiệp vụ từ đó.

## Cài đặt toàn cục

<Link path="get_started/quick-start">Cấu hình workspace</Link> ở trên là đủ để xây dựng. Cài đặt thêm một plugin hoặc power nếu bạn muốn MCP server có sẵn trên tất cả các dự án của mình:

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    Nx Plugin for AWS được cung cấp dưới dạng [Kiro Power](https://kiro.dev/docs/powers/) đi kèm với MCP server cùng tài liệu hướng dẫn và quy trình làm việc.

    <Steps>

    1. Mở bảng Powers trong Kiro và nhấp vào **Add power from GitHub**
    2. Nhập URL sau:

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. Nhấp vào **Install**

    </Steps>

    Kiro tự động cấu hình MCP server — không cần thiết lập thêm.

  </TabItem>
  <TabItem label="Kiro CLI">
    Chạy lệnh sau:

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    Xem [Kiro CLI MCP docs](https://kiro.dev/docs/cli/mcp/) để biết thêm chi tiết.

  </TabItem>
  <TabItem label="Claude Code">
    Nx Plugin for AWS được phân phối dưới dạng [Claude Code plugin](https://code.claude.com/docs/en/plugins) đi kèm với [Skill](https://code.claude.com/docs/en/skills) cùng MCP server.

    Chạy các lệnh sau bên trong Claude Code, từng lệnh một:

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    Sau đó chạy `/reload-plugins` để kích hoạt plugin.

  </TabItem>
  <TabItem label="Cursor">
    Thêm nội dung sau vào `~/.cursor/mcp.json` (hoặc `.cursor/mcp.json` trong dự án của bạn):

    <Snippet name="mcp/config" />

    Xem [Cursor MCP docs](https://cursor.com/docs/mcp) để biết thêm chi tiết.

  </TabItem>
  <TabItem label="Codex">
    Thêm nội dung sau vào `~/.codex/config.toml`:

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    Xem [Codex config docs](https://developers.openai.com/codex/config-reference) để biết thêm chi tiết.

  </TabItem>
  <TabItem label="Other">
    Hầu hết các trợ lý tương thích MCP sử dụng tệp cấu hình JSON. Thêm mục sau:

    <Snippet name="mcp/config" />

    Nếu bạn gặp vấn đề như `ENOENT npx`, hãy thay thế lệnh bằng đường dẫn đầy đủ đến `npx` (tìm nó bằng `which npx`).

    Để xem tài liệu cụ thể cho từng trợ lý:

    <Snippet name="mcp/assistant-docs" />

  </TabItem>
</Tabs>

## Bắt đầu Vibe Coding

Với plugin có sẵn toàn cục, trợ lý của bạn cũng có thể tạo workspace. Thử một prompt như:

<Prompt>
Build a multi-agent application using the Nx Plugin for AWS. I want a React frontend that talks to a backend orchestrator agent which delegates to specialised research and writing agents.
</Prompt>

Hoặc để có điểm khởi đầu nhỏ hơn:

<Prompt>
Use the Nx Plugin for AWS to scaffold a React website backed by a tRPC API, with Cognito auth and CDK infrastructure.
</Prompt>
