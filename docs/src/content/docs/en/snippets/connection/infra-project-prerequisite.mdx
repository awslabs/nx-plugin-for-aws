:::note[Infrastructure project required]
The agent, MCP server and Gateway generators vend their constructs and modules into `packages/common`, but they do not create an application to deploy them from — so `packages/infra` does not exist until you generate it. Run the <Link path="guides/typescript-infrastructure">`ts#infra`</Link> generator (CDK) or the <Link path="guides/terraform-project">`terraform#project`</Link> generator (Terraform) before editing the file below.
:::
