### 配置文件

大多数支持 MCP 的 AI 助手使用类似的配置方法。您需要创建或更新配置文件，添加您的 MCP 服务器详细信息：

```json
{
  "mcpServers": {
    "your-mcp-server": {
      "command": "uv",
      "args": [
        "run",
        "python",
        "-m",
        "my_module.mcp_server.stdio"
      ],
      "env": {
        "VIRTUAL_ENV": "/path/to/your/project/.venv"
      }
    }
  }
}
```

:::caution[路径解析]
如果您在连接到服务器时收到 `ENOENT uv` 等错误，您可能需要指定 `uv` 的完整路径，可以通过在终端中运行 `which uv` 来获取。
:::
