[AWS Arch](https://aws.github.io/aws-pdk/developer_guides/aws-arch/index.html) 为上述 CDK Graph 提供了 CloudFormation 资源与其关联架构图标之间的映射。

有关图标相关资源，请参阅 [AWS Architecture Icons 页面](https://aws.amazon.com/architecture/icons/)。[Diagrams](https://diagrams.mingrammer.com/) 也提供了一种以代码方式构建图表的方法。

如果您直接使用此功能，请考虑 fork 该项目并自行维护！
