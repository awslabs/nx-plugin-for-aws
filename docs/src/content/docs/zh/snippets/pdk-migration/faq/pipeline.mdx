PDK 提供了一个 [`PDKPipelineProject`](https://aws.github.io/aws-pdk/developer_guides/pipeline/index.html)，它设置了一个 CDK 基础设施项目，并使用了一个 CDK 构造来封装一些 [CDK Pipelines](https://docs.aws.amazon.com/cdk/api/v2/docs/aws-cdk-lib.pipelines-readme.html) 资源。

要从中迁移，您可以直接使用 CDK Pipelines 构造。但在实践中，使用 GitHub actions 或 GitLab CI/CD 之类的工具可能更直接，您可以在其中定义 [CDK Stages](https://docs.aws.amazon.com/cdk/v2/guide/stages.html) 并直接运行相应阶段的部署命令。
