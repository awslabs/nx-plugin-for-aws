import NxCommands from '@components/nx-commands.astro';

生成器会自动配置一个 `bundle` 目标，它使用 [Rolldown](https://rolldown.rs/) 来创建部署包：

<NxCommands commands={['bundle <project-name>']} />

Rolldown 配置可以在 `rolldown.config.ts` 中找到，每个要生成的包都有一个入口。Rolldown 会管理并行创建多个包（如果已定义）。

:::tip[自定义配置]
您可以在 `rolldown.config.ts` 中调整 Rolldown 的配置，例如，如果您有依赖于文件路径且无法打包的依赖项，可以将它们添加到 `external` 模块列表中。
:::
