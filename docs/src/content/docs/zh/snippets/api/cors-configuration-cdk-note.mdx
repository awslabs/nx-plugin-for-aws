:::note[CDK CORS 配置]
如果您的解决方案包含网站，您可以将其 CloudFront 分发配置为 API 网关 / API AWS Lambda 集成（用于 HTTP / REST API）中唯一允许的 CORS 源。
您可以使用网站构造、CloudFront 分发、源字符串或它们的混合来调用 API 的 `restrictCorsTo` 方法。

```ts
import { MyApi, MyWebsite } from '@my-scope/common-constructs';

export class ExampleStack extends Stack {
  constructor(scope: Construct, id: string) {
    const api = new MyApi(this, 'MyApi', {
      integrations: MyApi.defaultIntegrations(this).build(),
    });
    const website = new MyWebsite(this, 'MyWebsite');
    api.restrictCorsTo(website, 'http://localhost:4200', 'http://localhost:4300');
  }
}
```

`MyWebsite` 构造可以使用 <Link path="/zh/guides/react-website">`ts#website` 生成器</Link>生成。此示例假设网站的本地开发服务器和预览端口为 `4200`/`4300` - 请检查其 `project.json`（或 `vite.config.mts`）以获取实际分配给它的端口，因为以这种方式生成的每个网站都有自己的端口。
:::
