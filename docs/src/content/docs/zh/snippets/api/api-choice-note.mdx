---
title: 在 REST 和 HTTP 之间选择
---
:::note[API 类型选择]
您可以选择 [REST API](https://docs.aws.amazon.com/apigateway/latest/developerguide/apigateway-rest-api.html) 或 [HTTP API](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api.html) 来部署您的 API，请参考 [API Gateway Developer Guide](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-vs-rest.html) 以帮助您做出决定。
:::
