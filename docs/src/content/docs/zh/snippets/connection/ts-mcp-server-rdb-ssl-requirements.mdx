---
title: 不使用 RDS Proxy 连接时的 SSL 要求
---

当 MCP 服务器在不使用 RDS Proxy 的情况下连接到 Aurora 集群时，Node.js 必须信任 Amazon RDS 证书颁发机构 (CA)。Node.js 不会读取操作系统信任存储。它仅从 `NODE_EXTRA_CA_CERTS` 环境变量指向的文件加载额外的 CA 证书。

- 当 MCP 服务器的 `infra` 为 `agentcore-ecr` 时，连接生成器会更新 Dockerfile。它会将 Amazon RDS CA 证书包下载到 `/usr/local/share/ca-certificates/rds-bundle.crt` 并将 `NODE_EXTRA_CA_CERTS` 设置为该路径，因此无需配置任何内容。对于由早期插件版本生成的 Dockerfile，`nx migrate` 会添加 `NODE_EXTRA_CA_CERTS` 行。
- 当 MCP 服务器的 `infra` 为 `agentcore`（默认值）时，MCP 服务器将作为不包含 RDS CA 证书包的代码包进行部署。请保持启用 RDS Proxy（默认值），或使用 `agentcore-ecr`。

有关更多详细信息，请参阅 [Amazon RDS SSL/TLS 文档](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/UsingWithRDS.SSL.html)。使用 RDS Proxy 时，您无需配置 `NODE_EXTRA_CA_CERTS`。
