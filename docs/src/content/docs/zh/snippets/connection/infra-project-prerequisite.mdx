agent、MCP server 和 Gateway 生成器会将它们的构造和模块输出到 `packages/common`，但它们不会创建用于部署这些内容的应用程序——因此 `packages/infra` 在您生成它之前并不存在。在编辑下面的文件之前，请先运行 <Link path="guides/typescript-infrastructure">`ts#infra`</Link> 生成器（CDK）或 <Link path="guides/terraform-project">`terraform#project`</Link> 生成器（Terraform）。
