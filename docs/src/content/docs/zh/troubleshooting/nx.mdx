## Nx Daemon

[Nx Daemon](https://nx.dev/docs/concepts/nx-daemon) 是一个持续监视工作区变化的进程，用于重新计算项目图。这可以提供性能提升，特别是对于大型项目，但有时也可能因您的环境而导致问题。

这可能以不同的方式表现出来，其中之一是以下错误：

```bash
 NX   Could not find project "@scope/project"

Pass --verbose to see the stacktrace.
```

对于这个错误以及任何其他意外错误，始终值得重置 Nx 并重试，以防是守护进程问题。您可以使用以下命令：

<NxCommands commands={['reset']} />

如果这样做无效，您可以尝试[完全禁用守护进程](https://nx.dev/docs/concepts/nx-daemon#turning-it-off)。

:::note[需要守护进程]
`nx watch` 命令需要守护进程，因此依赖它来热重载本地开发服务器的 `dev` 目标需要启用守护进程。
:::
