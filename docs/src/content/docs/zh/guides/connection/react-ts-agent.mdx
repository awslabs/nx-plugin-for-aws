Nx Plugin for AWS 提供了一个生成器，可以快速将您的 <Link path="guides/ts-agent">TypeScript Agent</Link> 与 React 网站集成。它设置了通过 WebSocket 上的 tRPC 连接到您的 agent 所需的所有配置，包括 AWS IAM 和 Cognito 身份验证支持。该集成在您的前端和 agent 的 tRPC 路由器之间提供完整的端到端类型安全。

## 前置条件

在使用此生成器之前，请确保您具有：

1. 一个 React 网站（使用 <Link path="guides/react-website">`ts#website` 生成器</Link>生成）
2. 一个 TypeScript Agent（使用 <Link path="guides/ts-agent">`ts#agent` 生成器</Link>生成）
3. 通过 <Link path="/guides/react-website-auth">`ts#website#auth` 生成器</Link>添加的 Cognito Auth

## 生成器输出

生成器在您的 React 应用程序中创建以下结构：

<FileTree>

- src
  - components
    - \<AgentName>AgentClientProvider.tsx 设置 tRPC WebSocket 客户端并绑定到您的 agent 的 tRPC 路由器
    - QueryClientProvider.tsx TanStack React Query 客户端提供程序
  - hooks
    - useSigV4.tsx 用于使用 SigV4 签名请求的 Hook（仅限 IAM）
    - use\<AgentName>Agent.tsx 返回 tRPC 选项代理和原生 tRPC 客户端的 Hooks

</FileTree>

此外，它还会安装所需的依赖项：

  - `@trpc/client`
  - `@trpc/tanstack-react-query`
  - `@tanstack/react-query`
  - `aws4fetch`（如果使用 IAM 身份验证）

## 工作原理

### WebSocket 连接

生成的客户端通过 WebSocket 上的 tRPC 连接到您的 Agent。agent 通过 WebSocket 端点公开 tRPC 路由器（包括用于流式传输 agent 响应的 `invoke` 订阅）。

- **已部署**：agent 运行时 ARN 从<Link path="guides/runtime-config">运行时配置</Link>加载。运行此连接生成器还会修补 agent 生成的 CDK/Terraform 构造，以将其 ARN 发布到网站的 `runtime-config.json`（在 `connection` 命名空间下），因此只有您明确连接的 agent 才会暴露给前端。ARN 会按照 Bedrock AgentCore Runtime WebSocket 协议转换为 WebSocket URL：`wss://bedrock-agentcore.<region>.amazonaws.com/runtimes/<encoded-arn>/ws`
- **本地开发**：使用 `dev` 运行时，运行时配置覆盖将值设置为本地 `ws://` URL（例如 `ws://localhost:8081/ws`），客户端直接连接

### 身份验证

生成的代码根据您的 agent 配置处理身份验证：

- **IAM**（默认）：使用 AWS SigV4 预签名 URL 对 WebSocket 连接进行身份验证。凭证从配置了您网站身份验证的 Cognito Identity Pool 获取。在 `dev` 模式下，当<Link path="guides/react-website#runtime-configuration">`runtime-config.json`</Link>不存在时，会自动跳过签名
- **Cognito**：将 JWT 访问令牌作为 base64url 编码的 bearer 令牌嵌入 `Sec-WebSocket-Protocol` 标头中，遵循 [AgentCore WebSocket 身份验证协议](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-get-started-websocket.html)

## 使用生成的代码

### 使用 TanStack Query

最常见的用例是使用 `use<AgentName>Agent` hook 通过 `invoke` 订阅流式传输 agent 的响应，该 hook 返回一个 [tRPC 选项代理](https://trpc.io/docs/client/tanstack-react-query)，用于与 TanStack Query 一起使用：

```tsx {1-2,7-22}
import { useSubscription } from '@trpc/tanstack-react-query';
import { useMyAgentAgent } from './hooks/useMyAgentAgent';

function ChatComponent() {
  const trpc = useMyAgentAgent();

  const subscription = useSubscription(
    trpc.invoke.subscriptionOptions(
      { prompt: 'What can you help me with?' },
      {
        enabled: true,
        onStarted: () => {
          console.log('Agent started responding');
        },
        onData: (token) => {
          console.log('Received token:', token);
        },
        onError: (error) => {
          console.error('Agent error:', error);
        },
      },
    ),
  );

  return (
    <div>
      <p>Status: {subscription.status}</p>
      {subscription.data && <p>Latest token: {subscription.data}</p>}
      {subscription.error && <p>Error: {subscription.error.message}</p>}
    </div>
  );
}
```

:::note[tRPC 选项代理]
有关 tRPC 选项代理和 TanStack Query 集成的更多详细信息，请参阅 [tRPC TanStack React Query 文档](https://trpc.io/docs/client/tanstack-react-query)。
:::

### 使用原生 tRPC 客户端

`use<AgentName>AgentClient` hook 提供对[原生 tRPC 客户端](https://trpc.io/docs/client/vanilla)的访问，以便更好地控制订阅生命周期：

```tsx {2,5,9-22,25}
import { useState } from 'react';
import { useMyAgentAgentClient } from './hooks/useMyAgentAgent';

function ChatComponent() {
  const client = useMyAgentAgentClient();
  const [messages, setMessages] = useState<string[]>([]);

  const sendMessage = (prompt: string) => {
    const subscription = client.invoke.subscribe(
      { prompt },
      {
        onData: (token) => {
          setMessages((prev) => [...prev, token]);
        },
        onComplete: () => {
          console.log('Agent finished');
        },
        onError: (error) => {
          console.error('Error:', error);
        },
      },
    );

    // Clean up when done
    return () => subscription.unsubscribe();
  };

  return (
    <div>
      <button onClick={() => sendMessage('Hello!')}>Send</button>
      <div>
        {messages.map((msg, i) => (
          <span key={i}>{msg}</span>
        ))}
      </div>
    </div>
  );
}
```

:::note[原生 tRPC 客户端]
有关原生 tRPC 客户端的更多详细信息，请参阅 [tRPC Vanilla Client 文档](https://trpc.io/docs/client/vanilla)。
:::

## 本地开发

连接生成器会自动为您的 react 网站配置 `dev` 集成：

1. 运行 `nx dev <website>` 也会启动 agent 的本地服务器
2. 运行时配置被覆盖以指向本地 WebSocket URL（例如 `ws://localhost:8081/ws`）
3. 与连接的 API 类似，当<Link path="guides/react-website#runtime-configuration">`runtime-config.json`</Link>不存在时，在 `dev` 模式下会跳过身份验证

:::tip[热重载]
网站和连接的 agent 将热重载，使您能够快速迭代两者，而无需部署到 AWS。
:::

## 类型安全

该集成提供完整的端到端类型安全。您的 IDE 将为所有 agent 过程调用提供完整的自动完成和类型检查。类型会自动从您的 agent 的 tRPC 路由器定义中推断，确保对 agent API 的任何更改都会立即反映在您的前端代码中。
