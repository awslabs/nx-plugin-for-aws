生成一个完整的 TypeScript [Nx Plugin](https://nx.dev/extending-nx/intro/getting-started)，并集成 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) 服务器。此生成器创建了一个基础框架，用于构建可被 AI 助手无缝使用的自定义生成器，以实现自动化代码生成和项目脚手架。

## 用法

### 生成 Nx 插件

您可以通过两种方式生成 TypeScript Nx Plugin：

<RunGenerator generator="ts#nx-plugin" />

### 选项

<GeneratorParameters generator="ts#nx-plugin" />

## 生成器输出

生成器将创建以下项目结构：

<FileTree>
- your-plugin/
  - src/
    - index.ts Empty entry point for your plugin
    - mcp-server/
      - index.ts Exports your server
      - server.ts Main MCP server configuration
      - stdio.ts Entry point for your MCP server with STDIO transport
      - http.ts Entry point for your MCP server with Streamable HTTP transport
      - tools/
        - create-workspace-command.ts Tool for workspace creation guidance
        - general-guidance.ts Tool for general Nx and plugin guidance
        - list-generators.ts Tool to list available generators
        - generator-guide.ts Tool for detailed generator information
      - utils.ts Utility functions for the MCP server
  - generators.json Nx generator configuration (initially empty)
  - package.json Plugin package configuration
  - tsconfig.json TypeScript configuration (CommonJS for Nx compatibility)
  - project.json Nx project configuration with build and package targets
</FileTree>

## 使用您的 Nx 插件

### 添加生成器

一旦您有了插件项目，就可以使用 <Link path="/guides/nx-generator">`ts#nx-generator`</Link> 生成器来添加生成器：

<RunGenerator generator="ts#nx-generator" requiredParameters={{ pluginProject: 'your-plugin' }} />

这将向您的插件添加一个新的生成器。

:::tip[生成器文档]
阅读 <Link path="/guides/nx-generator">`ts#nx-generator` 指南</Link>了解如何实现生成器的详细信息。
:::

确保为您的生成器编写详细的 `README.md`，因为 MCP 服务器的 `generator-guide` 工具会使用它。

### 项目目标

生成的插件包含几个重要的目标：

#### 构建目标
编译您的 TypeScript 代码并准备插件以供使用：

<NxCommands commands={['build your-plugin']} />

#### 打包目标
创建一个可分发的包，准备发布到 NPM：

<NxCommands commands={['package your-plugin']} />

打包目标包含所有必要的资源：
- 编译后的 JavaScript 文件
- TypeScript 声明文件
- 生成器和执行器配置文件
- 文档和许可证文件

## MCP 服务器集成

该插件使用 <Link path="/guides/ts-mcp-server">`ts#mcp-server`</Link> 生成器配置 MCP 服务器。

### 工具

该插件包含一个完整的 MCP 服务器，为 AI 助手提供以下工具：

- `general-guidance`：获取使用 Nx 和您的插件的最佳实践
- `create-workspace-command`：了解如何创建可以使用您的插件的新工作区
- `list-generators`：列出您的插件中所有可用的生成器
- `generator-guide`：获取有关特定生成器的详细信息，包括模式和用法

## 发布您的插件

### 准备发布

1. **更新包信息**：编辑您的插件的 [`package.json`](https://docs.npmjs.com/cli/v10/configuring-npm/package-json)，填写正确的名称、版本、描述和仓库信息。

2. **构建包**：
   <NxCommands commands={['package your-plugin']} />

3. **本地测试**：您可以通过在另一个工作区中安装来本地测试您的插件：
   ```bash
   npm install /path/to/your/workspace/dist/your-plugin/package
   ```

### 发布到 NPM

一旦您的插件准备就绪：

```bash
cd dist/your-plugin/package
npm publish
```

### 使用已发布的插件

发布后，其他人可以安装和使用您的插件：

<InstallCommand pkg="your-plugin-name" />

然后使用您的生成器：

<RunGenerator namespace="your-plugin-name" generator="your-generator-name" />

#### 使用已发布的插件配置 AI 助手

您已发布的插件的 MCP 服务器可以按如下方式配置：

```json {3-6}
{
  "mcpServers": {
    "aws-nx-mcp": {
      "command": "npx",
      "args": ["-y", "-p", "your-plugin-name", "your-plugin-name-mcp-server"]
    }
  }
}
```
