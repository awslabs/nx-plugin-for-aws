## 已在您的工作空间中配置

使用 Nx Plugin for AWS 预设创建的工作空间包含了常见编码代理（Claude Code、Cursor、Kiro、Gemini CLI、GitHub Copilot 和 OpenAI Codex）的项目级 MCP 配置，因此在工作空间内工作的代理可以使用插件的 [MCP server](https://modelcontextprotocol.io/introduction)，无需进一步设置。

在您的助手中打开工作空间并询问您想要的内容：

<Prompt>
Add a React website with an AG-UI agent, an MCP server for its tools and a DynamoDB table, and wire them together.
</Prompt>

它会查找插件提供的生成器，按照依赖关系所需的顺序运行它们。使用您的代理从那里填充业务逻辑。

## 全局安装

上面的工作空间配置足以用于构建。如果您想使用 AI 创建新工作空间，或<Link path="get_started/existing-project">将 Nx Plugin for AWS 添加到现有项目</Link>，您可以全局安装：

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    Nx Plugin for AWS 作为 [Kiro Power](https://kiro.dev/docs/powers/) 发布，它将 MCP 服务器与指导文档和工作流程指南捆绑在一起。

    <Steps>

    1. 在 Kiro 中打开 Powers 面板，然后点击 **Add power from GitHub**
    2. 输入以下 URL：

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. 点击 **Install**

    </Steps>

    Kiro 会自动配置 MCP 服务器 — 无需额外设置。

  </TabItem>
  <TabItem label="Kiro CLI">
    运行以下命令：

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    有关更多详细信息，请参阅 [Kiro CLI MCP 文档](https://kiro.dev/docs/cli/mcp/)。

  </TabItem>
  <TabItem label="Claude Code">
    Nx Plugin for AWS 作为 [Claude Code plugin](https://code.claude.com/docs/en/plugins) 发布，它将 [Skill](https://code.claude.com/docs/en/skills) 与 MCP 服务器捆绑在一起。

    在 Claude Code 中依次运行以下命令：

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    然后运行 `/reload-plugins` 以激活插件。

  </TabItem>
  <TabItem label="Cursor">
    将以下内容添加到 `~/.cursor/mcp.json`（或项目中的 `.cursor/mcp.json`）：

    <Snippet name="mcp/config" />

    有关更多详细信息，请参阅 [Cursor MCP 文档](https://cursor.com/docs/mcp)。

  </TabItem>
  <TabItem label="Codex">
    将以下内容添加到 `~/.codex/config.toml`：

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    有关更多详细信息，请参阅 [Codex 配置文档](https://developers.openai.com/codex/config-reference)。

  </TabItem>
  <TabItem label="Other">
    大多数兼容 MCP 的助手使用 JSON 配置文件。添加以下条目：

    <Snippet name="mcp/config" />

    如果您遇到诸如 `ENOENT npx` 之类的问题，请将命令替换为 `npx` 的完整路径（使用 `which npx` 查找）。

    有关特定助手的文档：

  </TabItem>
</Tabs>
