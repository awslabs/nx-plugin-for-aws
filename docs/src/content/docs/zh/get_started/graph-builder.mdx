绘制您的工作区所需的项目及其之间的连接，构建器会生成用于搭建您所绘制内容的命令。复制它们，运行它们，您就拥有了一个可工作的工作区。

从调色板拖动组件到画布上，从一个组件的右边缘拖动到另一个组件以连接它们，并在右侧编辑每个组件的属性。底部生成的命令会随着每次更改而更新——点击 **Copy** 以获取整个脚本。

## 工作原理

画布上的每个组件都映射到一个生成器，每个连接都映射到<Link path="guides/connection">连接生成器</Link>。命令按依赖顺序发出：首先是工作区，然后是项目，然后是它们托管的组件，最后是将它们连接在一起的连接。

网站总是会在其后立即添加 <Link path="guides/react-website-auth">Cognito 身份验证</Link>，因为 `ts#website` 将其留给后续生成器处理。

最后会添加一个 `infra` 项目——<Link path="guides/typescript-infrastructure">`ts#infra`</Link> 或 <Link path="guides/terraform-project">`terraform#project`</Link>，与您的 IaC 选择相匹配。每个生成的项目都会为其提供要实例化的构造，因此这就是您要部署的内容。因为它拥有该名称，所以画布上的任何组件都不能被称为 `infra`。

使用工具栏中的 **Vertical** / **Horizontal** 来切换图形的流向——连接点会移动到每个组件的顶部和底部边缘，布局也会相应转置。

拖动画布背景以平移，拖动组件以重新定位它。按住 Shift 键单击以选择多个组件并将它们作为一组移动。单击连接以选择它，然后按 <kbd>Delete</kbd> 将其删除（或使用连接本身上的 ✕）。

调色板列出了可以参与连接的每个项目和组件类型，您只能绘制插件支持的连接——因此验证通过的图形就是可以搭建的图形。

有三条规则值得了解：

- **组件共享宿主项目。** 代理和 MCP 服务器是添加_到_项目中的，而不是它们自己的项目。给它们相同的宿主项目名称以将它们放在一个项目中，或使用不同的名称为每个创建一个项目。
- **某些连接会约束其端点。** 例如，将代理连接到另一个代理需要目标使用 `a2a` 协议。当属性设置会破坏您已绘制的连接时，构建器会在组件和连接旁边提示。
- **绘制连接可以调整目标。** 将网站连接到代理会将该代理切换到 `ag-ui` 协议，将代理连接到另一个代理会将目标切换到 `a2a`——这些是这些连接所基于的协议。您自己设置的属性永远不会被更改。
