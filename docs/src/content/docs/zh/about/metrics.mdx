---
title: 使用指标
description: "@aws/nx-plugin 如何收集指标"
---

为了帮助我们改进 Nx Plugin for AWS，我们会收集生成器使用情况的指标。此过程不涉及任何额外的网络请求，我们只是利用现有的 AWS 使用指标。

为了保持透明，我们会将 ID、版本和生成器 ID 列表附加到 CloudFormation Stack 描述中。这是在 CDK 的 `common/constructs` 中的 `MetricsAspect` 中完成的，或者在 Terraform 的 `metrics.tf` Cloudformation stack 中完成的。

## 选择退出

指标代码完全存在于您的工作空间中，因此您可以通过删除它来选择退出：

- **CDK**：从 `packages/common/constructs/src/core/app.ts` 中删除 `MetricsAspect` 类和 `Aspects.of(this).add(new MetricsAspect())` 调用。
- **Terraform**：删除 `packages/common/terraform/src/metrics/metrics.tf`。

生成器在删除后不会重新添加指标代码。
