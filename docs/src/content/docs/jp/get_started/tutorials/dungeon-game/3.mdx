## タスク 1: Story エージェントの実装

Story エージェントは、<Link path="get_started/tutorials/dungeon-game/1">モジュール 1</Link> で `--protocol=ag-ui` を使用して生成された [Strands](https://strandsagents.com/) エージェントです。これにより、UI は CopilotKit を介して [Agent-User Interaction protocol](https://docs.copilotkit.ai/aws-strands/protocol) 経由でストリーミングできます。このエージェントは、プレイヤーのアイテムを管理するために Inventory MCP Server を使用し、モジュール 2 でプロビジョニングしたセッションバケットに会話履歴を永続化するために Strands の組み込み [`S3SessionManager`](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/agents/sessions/) を使用します。

### エージェントの実装

`packages/story/dungeon_adventure_story/agent` 内の以下のファイルを更新します:

  <TabItem label="main.py">
<E2EDiff lang="python" before="dungeon-adventure/3/main.py.old.template" after="dungeon-adventure/3/main.py.template" />
  </TabItem>
  <TabItem label="agent.py">
<E2EDiff lang="python" before="dungeon-adventure/3/agent.py.old.template" after="dungeon-adventure/3/agent.py.template" />
  </TabItem>
</Tabs>

変更内容は以下の通りです:

- `main.py` は、デプロイ時に `thread_id` ごとに `S3SessionManager` を作成する `session_manager_provider` を追加し、`agent-dev` で実行する場合（`LOCAL_DEV=true`）は `/tmp/strands-sessions` 配下のディスク上の `FileSessionManager` にフォールバックします。デプロイされた場合、S3 バケットは Game API の `queryActions` が読み取るものと同じバケットであるため、ブラウザは再訪問時にトランスクリプトを再構築できます。ローカルでは、エージェントはセッションをディスクに永続化し、デプロイなしでローカル MCP サーバーと通信します。
- `agent.py` は、サンプルの `subtract` ツールを削除し、システムプロンプトをダンジョンマスター用のものに置き換えます。これは、最初のユーザーメッセージでプレイヤーの名前とジャンルを述べるよう促し、Inventory MCP Server のツールを使用します。

### エージェントとチャットする

生成された `agent-chat` ターゲットは、エージェントに対してインタラクティブな REPL を開きます。これはスタンドアロンで実行され、ローカルで実行中のエージェントに接続するため、まず 1 つのターミナルでエージェントのローカルサーバーを起動します:

<NxCommands commands={["agent-dev story"]} />

次に、2 つ目のターミナルでチャットを開始します:

<NxCommands commands={["agent-chat story"]} />

最初のメッセージでは、エージェントにヒーローの名前とジャンルを伝える必要があります（例: `My name is Alice. Start my zombie adventure.`）。すると、ストーリーがストリーミングで返されます。

<Aside type="caution" title="AWS 認証情報が必要">
エージェントはローカルで実行されますが、LLM のために [Amazon Bedrock](https://aws.amazon.com/bedrock/) を呼び出します。[Strands デフォルトモデル](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/model-providers/amazon-bedrock/)にアクセスできる AWS 認証情報が環境に必要です。詳細については、[Strands モデルプロバイダーのドキュメント](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/model-providers/amazon-bedrock/)を参照してください。
</Aside>
