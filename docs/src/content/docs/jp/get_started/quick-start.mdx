このガイドでは、`@aws/nx-plugin`をインストールして使用し、AWS上でプロジェクトを迅速に構築するための基本を説明します。

:::tip[フルスタックチュートリアル]

:::

## 前提条件

続行する前に、以下のグローバル依存関係が必要です：

<Snippet name="prerequisites" />

## ステップ1：新しいNxワークスペースの初期化

以下のコマンドを実行して、お好みのパッケージマネージャーで<Link path="guides/workspace">Nxワークスペース</Link>を作成します：

<CreateNxWorkspaceCommand workspace="my-project" />

:::tip[IaCプロバイダーの選択]
お好みのインフラストラクチャアズコード（IaC）プロバイダーとして、[CDK](https://docs.aws.amazon.com/cdk/)または[Terraform](https://developer.hashicorp.com/terraform)のいずれかを選択するよう求められます。`--iac`オプションを付けてコマンドを実行することで、プロンプトをスキップできます。例：

<Infrastructure>
<Fragment slot="cdk">
<CreateNxWorkspaceCommand workspace="my-project" iac="cdk" />
</Fragment>
<Fragment slot="terraform">
<CreateNxWorkspaceCommand workspace="my-project" iac="terraform" />
</Fragment>
</Infrastructure>
:::

完了したら、プロジェクトディレクトリに移動します：

```sh
cd my-project
```

## ステップ2：ジェネレーターを使用してプロジェクトをスキャフォールドする

このクイックスタートガイドでは、tRPC API、React Website、Cognito Authentication、およびCDKまたはTerraform Infrastructureを追加します。構築するプロジェクトのタイプに応じて、任意のジェネレーターの組み合わせを選択してプロジェクトを迅速にブートストラップできます。利用可能なオプションの完全なリストについては、左側のナビゲーションバーの__Generators__をご覧いただくか、<Link path="get_started/graph-builder">graph builder</Link>を試してワークスペースを視覚的に構築してください。

ショートカットとして、以下のボタンを使用して、完全なアプリケーションをスキャフォールドするコマンドをコピーできます。

<EmbeddedGraph preset="quick-start" workspace="my-project" iac="cdk" orientation="horizontal" skipWorkspace />

:::tip[AIで構築]
<Link path="get_started/building-with-ai">Nx Plugin for AWS MCP Server</Link>はワークスペースに既に設定されているため、CLIコマンドを自分で入力する代わりに、KiroやClaudeなどのお気に入りのAIコーディングエージェントにこれらのプロジェクトを構築するよう依頼できます。
:::

それ以外の場合は、以下の手順に従って各ジェネレーターを自分で実行してください。

### tRPC APIの追加

<RunGenerator generator="ts#api" requiredParameters={{ name: 'demo-api', framework: 'trpc', auth: 'iam' }} />

これにより、`packages/demo-api`フォルダー内にAPIが作成されます。

### React Websiteの追加

<RunGenerator generator="ts#website" requiredParameters={{ name: 'demo-website' }} />

これにより、`packages/demo-website`に新しいReact Websiteがスキャフォールドされます。

### Cognito Authenticationの追加

<RunGenerator generator="ts#website#auth" requiredParameters={{ project: '@my-project/demo-website', cognitoDomain: 'my-demo' }} />

これにより、WebsiteにCognito Authenticationを追加するために必要なインフラストラクチャとReactコードがセットアップされます。

### フロントエンドとバックエンドの接続

<RunGenerator generator="connection" requiredParameters={{ sourceProject: '@my-project/demo-website', targetProject: '@my-project/demo-api' }} />

これにより、WebsiteがtRPC APIを呼び出せるようにするために必要なプロバイダーが設定されます。

### インフラストラクチャの追加

選択したIACプロバイダーに基づいてインフラストラクチャプロジェクトを追加します。

<Infrastructure>
<Fragment slot="cdk">
<RunGenerator generator="ts#infra" requiredParameters={{ name: 'infra' }} />

これにより、AWSにインフラストラクチャをデプロイするために使用できるCDK Appが設定されます。
</Fragment>
<Fragment slot="terraform">
<RunGenerator generator="terraform#project" requiredParameters={{ name: 'infra' }} />

これにより、AWSにインフラストラクチャをデプロイするために使用できるTerraformプロジェクトが設定されます。
</Fragment>
</Infrastructure>

## ステップ3：WebsiteとAPIをローカルで実行する

以下のコマンドを使用して、Websiteと接続されたAPIのローカル開発サーバーを起動します：

<PackageManagerShortCommand commands={["dev"]} />

Websiteは`http://localhost:4200`で利用できます。

ローカルのWebsiteとAPIサーバーの両方がホットリロードされるため、WebsiteとAPIの両方への変更がリアルタイムで反映されます。

## ステップ4：クラウドリソースを定義してAWSにデプロイする

<Infrastructure>
<Fragment slot="cdk">
`packages/infra/src/stacks/application-stack.ts`を開き、以下のコードを追加します：

```typescript
import { Stack, StackProps } from 'aws-cdk-lib';
import { DemoApi, DemoWebsite, UserIdentity } from '@my-project/common-constructs';
import { Construct } from 'constructs';

export class ApplicationStack extends Stack {
  constructor(scope: Construct, id: string, props?: StackProps) {
    super(scope, id, props);

    const identity = new UserIdentity(this, 'identity');
    const api = new DemoApi(this, 'api', {
      integrations: DemoApi.defaultIntegrations(this).build(),
    });
    api.grantInvokeAccess(identity.identityPool.authenticatedRole);

    new DemoWebsite(this, 'website');
  }
}
```

これが、フルスタックアプリケーションをデプロイするために記述する必要があるすべてのCDKです。
</Fragment>
<Fragment slot="terraform">
`packages/infra/src/main.tf`を開き、以下のコードを追加します：

```hcl
# Include metrics tracking for @aws/nx-plugin usage
module "metrics" {
  source = "../../common/terraform/src/metrics"
}

# Deploy user identity
module "user_identity" {
  source = "../../common/terraform/src/core/user-identity"
}

# Shared asset bucket — stages Lambda deployment zips for every lambda / API module
module "asset_bucket" {
  source = "../../common/terraform/src/core/asset-bucket"
}

# Deploy API
module "demo_api" {
  source = "../../common/terraform/src/app/apis/demo-api"

  asset_bucket_name = module.asset_bucket.bucket_name
}

# Grant authenticated users access to invoke the API
resource "aws_iam_policy" "api_invoke_policy" {
  name        = "DemoApiInvokePolicy"
  description = "Policy to allow authenticated users to invoke the API"

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect = "Allow"
        Action = "execute-api:Invoke"
        Resource = "${module.demo_api.api_execution_arn}/*/*"
      }
    ]
  })
}

resource "aws_iam_role_policy_attachment" "authenticated_api_access" {
  role       = module.user_identity.authenticated_role_name
  policy_arn = aws_iam_policy.api_invoke_policy.arn
}

# Deploy website
provider "aws" {
  alias  = "us_east_1"
  region = "us-east-1"
}

module "demo_website" {
  source = "../../common/terraform/src/app/static-websites/demo-website"

  providers = {
    aws.us_east_1 = aws.us_east_1
  }

  depends_on = [module.user_identity, module.demo_api]
}
```

これが、フルスタックアプリケーションをデプロイするために記述する必要があるすべてのTerraformです。
</Fragment>
</Infrastructure>

### インフラストラクチャのビルドとデプロイ

次に、以下のコマンドを実行してプロジェクトをビルドします：

<PackageManagerShortCommand commands={["build"]} />

:::tip[Lintエラーの修正]
Lintエラーが発生した場合は、以下のコマンドを実行して自動的に修正できます。

<PackageManagerShortCommand commands={["lint"]} />
:::

インフラストラクチャをブートストラップします：

<Infrastructure>
<Fragment slot="cdk">
<NxCommands commands={['bootstrap infra']} />

:::tip[ブートストラップリージョン]
CDKブートストラップは、ターゲットデプロイメントAWSリージョンと、WebsiteのAWS WAF WebACLのデプロイを可能にするための`us-east-1`の両方で必要です。
:::
</Fragment>
<Fragment slot="terraform">
<NxCommands commands={['bootstrap infra']} />

:::tip[1回限りのセットアップ]
Terraformブートストラップは、Terraformステートファイルを保存するためのS3バケットを作成します。これは、AWSアカウント/リージョンの組み合わせごとに1回だけ実行する必要があります。
:::
</Fragment>
</Infrastructure>

プロジェクトをデプロイします：

<Infrastructure>
<Fragment slot="cdk">
<NxCommands commands={['deploy infra "my-project-sandbox/*"']} />
</Fragment>
<Fragment slot="terraform">
<NxCommands commands={['apply infra']} />

:::tip[適用前の計画]
このコマンドは、最初に`terraform plan`を実行して行われる変更を表示し、その後それらの変更を適用してインフラストラクチャをデプロイします。
:::
</Fragment>
</Infrastructure>

## ステップ5：デプロイされたクラウドリソースでWebsiteをテストする

<Steps>
1. `runtime-config.json`ファイルを取得します：

    <NxCommands commands={['load-runtime-config demo-website']} />

2. ローカルWebsiteサーバーを起動します

    <NxCommands commands={['serve demo-website']} />
</Steps>

Websiteは`http://localhost:4200`で利用でき、APIと認証用にデプロイしたリソースを指します。
