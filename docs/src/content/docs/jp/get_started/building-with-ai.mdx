## ワークスペースに既に設定済み

Nx Plugin for AWSプリセットで作成されたワークスペースには、一般的なコーディングエージェント（Claude Code、Cursor、Kiro、Gemini CLI、GitHub Copilot、OpenAI Codex）向けのプロジェクトレベルのMCP設定が含まれているため、ワークスペース内で動作するエージェントは、追加のセットアップなしでプラグインの[MCPサーバー](https://modelcontextprotocol.io/introduction)を使用できます。

ワークスペースをアシスタントで開き、必要なものを尋ねてください：

<Prompt>
Add a React website with an AG-UI agent, an MCP server for its tools and a DynamoDB table, and wire them together.
</Prompt>

アシスタントは、プラグインが提供するジェネレーターを検索し、依存関係が必要とする順序で実行します。そこからビジネスロジックを記入するには、エージェントを使用してください。

## グローバルにインストール

上記のワークスペース設定は構築に十分です。AIを使用して新しいワークスペースを作成したい場合、または<Link path="get_started/existing-project">既存のプロジェクトにNx Plugin for AWSを追加</Link>したい場合は、グローバルにインストールできます：

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    Nx Plugin for AWSは、MCPサーバーとステアリングドキュメント、ワークフローガイドをバンドルした[Kiro Power](https://kiro.dev/docs/powers/)として提供されています。

    <Steps>

    1. KiroのPowersパネルを開き、**Add power from GitHub**をクリックします
    2. 以下のURLを入力します：

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. **Install**をクリックします

    </Steps>

    Kiroは自動的にMCPサーバーを設定します — 追加のセットアップは不要です。

  </TabItem>
  <TabItem label="Kiro CLI">
    以下のコマンドを実行します：

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    詳細は[Kiro CLI MCP docs](https://kiro.dev/docs/cli/mcp/)を参照してください。

  </TabItem>
  <TabItem label="Claude Code">
    Nx Plugin for AWSは、[Skill](https://code.claude.com/docs/en/skills)とMCPサーバーをバンドルした[Claude Code plugin](https://code.claude.com/docs/en/plugins)として配布されています。

    Claude Code内で以下のコマンドを1つずつ実行します：

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    その後、`/reload-plugins`を実行してプラグインを有効化します。

  </TabItem>
  <TabItem label="Cursor">
    `~/.cursor/mcp.json`（またはプロジェクト内の`.cursor/mcp.json`）に以下を追加します：

    <Snippet name="mcp/config" />

    詳細は[Cursor MCP docs](https://cursor.com/docs/mcp)を参照してください。

  </TabItem>
  <TabItem label="Codex">
    `~/.codex/config.toml`に以下を追加します：

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    詳細は[Codex config docs](https://developers.openai.com/codex/config-reference)を参照してください。

## Vibe Codingを始める

プラグインがグローバルに利用可能になると、アシスタントはワークスペースも作成できます。次のようなプロンプトを試してみてください：

<Prompt>
Build a multi-agent application using the Nx Plugin for AWS. I want a React frontend that talks to a backend orchestrator agent which delegates to specialised research and writing agents.
</Prompt>

または、より小さな出発点として：

<Prompt>
Use the Nx Plugin for AWS to scaffold a React website backed by a tRPC API, with Cognito auth and CDK infrastructure.
</Prompt>
