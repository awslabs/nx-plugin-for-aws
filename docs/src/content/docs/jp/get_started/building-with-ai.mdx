[Claude Plugin](https://code.claude.com/docs/en/plugins)、[Kiro Power](https://kiro.dev/docs/powers/)、または[MCP Server](https://modelcontextprotocol.io/introduction)をインストールして、AIアシスタントがプラグインと効果的に連携できるようにします。これらを使用することで、AIを活用して開発ワークフローを加速させることができます。プロジェクトが一貫した方法でスキャフォールディングされることで、主要なコンポーネントのセットアップにかかる時間を削減し、プラグインに組み込まれたセキュリティ、可観測性、型安全性、ローカル開発の恩恵を受けることができます。

## AIアシスタントの設定

:::tip[プロジェクトレベルの設定は自動です]
Nx Plugin for AWSプリセットで作成されたワークスペースには、一般的なコーディングエージェント（Claude Code、Cursor、Kiro、Gemini CLI、GitHub Copilot、OpenAI Codex）向けのプロジェクトレベルのMCP設定がすでに含まれています。ワークスペース内で動作するエージェントは、追加のセットアップなしでMCPサーバーを使用できます。以下の手順は、すべてのプロジェクトで使用するためにMCPサーバーをグローバルに設定します。
:::

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    Nx Plugin for AWSは、MCPサーバーとステアリングドキュメント、ワークフローガイドをバンドルした[Kiro Power](https://kiro.dev/docs/powers/)として提供されています。

    <Steps>

    1. KiroのPowersパネルを開き、**Add power from GitHub**をクリックします
    2. 以下のURLを入力します：

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. **Install**をクリックします

    </Steps>

    Kiroは自動的にMCPサーバーを設定します — 追加のセットアップは不要です。

  </TabItem>
  <TabItem label="Kiro CLI">
    以下のコマンドを実行します：

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    詳細は[Kiro CLI MCP docs](https://kiro.dev/docs/cli/mcp/)を参照してください。

  </TabItem>
  <TabItem label="Claude Code">
    Nx Plugin for AWSは、[Skill](https://code.claude.com/docs/en/skills)とMCPサーバーをバンドルした[Claude Code plugin](https://code.claude.com/docs/en/plugins)として配布されています。

    Claude Code内で以下のコマンドを1つずつ実行します：

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    その後、`/reload-plugins`を実行してプラグインを有効化します。

  </TabItem>

## Vibe Codingを始める

AIアシスタントに`nx-plugin-for-aws`を使って何かを構築するように依頼してください！通常、ワークスペースを作成し、適用可能なジェネレーターでスキャフォールディングを行い、その後ビジネスロジックを記入します。

次のようなプロンプトを試してみてください：

> _"Nx Plugin for AWSを使ってマルチエージェントアプリケーションを構築してください。専門的なリサーチエージェントとライティングエージェントに委任するバックエンドオーケストレーターエージェントと通信するReactフロントエンドが欲しいです。"_

または、より小さな出発点として：

> _"Nx Plugin for AWSを使って、tRPC APIをバックエンドとし、Cognito認証とCDKインフラストラクチャを備えたReactウェブサイトをスキャフォールディングしてください。"_
