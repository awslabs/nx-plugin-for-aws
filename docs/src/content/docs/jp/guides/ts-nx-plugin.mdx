統合された[Model Context Protocol (MCP)](https://modelcontextprotocol.io/)サーバーを備えた完全なTypeScript [Nx Plugin](https://nx.dev/extending-nx/intro/getting-started)を生成します。このジェネレーターは、AIアシスタントによる自動コード生成とプロジェクトスキャフォールディングにシームレスに使用できるカスタムジェネレーターを構築するための基盤を作成します。

## ジェネレーターの出力

ジェネレーターは以下のプロジェクト構造を作成します：

<FileTree>
- your-plugin/
  - src/
    - index.ts Entry point for your plugin
    - mcp-server/
      - index.ts Exports your server
      - server.ts Main MCP server configuration
      - stdio.ts Entry point for your MCP server with STDIO transport
      - http.ts Entry point for your MCP server with Streamable HTTP transport
      - schema.ts Shared schemas for the MCP server's tools
      - utils.ts Utility functions for the MCP server
      - resources/
        - GENERAL_GUIDANCE.md Guidance served by the `general-guidance` tool
      - tools/
        - create-workspace-command.ts Tool for workspace creation guidance
        - general-guidance.ts Tool for general Nx and plugin guidance
        - list-generators.ts Tool to list available generators
        - generator-guide.ts Tool for detailed generator information
  - generators.json Nx generator configuration (initially empty)
  - package.json Plugin package configuration
  - project.json Nx project configuration with build and package targets
  - tsconfig.json TypeScript configuration, referencing the two below
  - tsconfig.lib.json TypeScript configuration for your plugin's source
  - tsconfig.spec.json TypeScript configuration for your plugin's tests
  - vitest.config.mts Vitest configuration for your plugin's tests
  - README.md Documentation for your plugin, served by the `generator-guide` tool
  - LICENSE Written by the `license` generator's sync, when configured
</FileTree>

## Nxプラグインの操作

### ジェネレーターの追加

プラグインプロジェクトを作成したら、<Link path="/guides/nx-generator">`ts#nx-generator`</Link>ジェネレーターを使用してジェネレーターを追加できます：

<RunGenerator generator="ts#nx-generator" requiredParameters={{ project: 'your-plugin' }} />

これにより、プラグインに新しいジェネレーターが追加されます。

:::tip[ジェネレーターのドキュメント]
ジェネレーターの実装方法の詳細については、<Link path="/guides/nx-generator">`ts#nx-generator`ガイド</Link>をお読みください。
:::

MCPサーバーの`generator-guide`ツールで使用されるため、ジェネレーター用に詳細な`README.md`を必ず記述してください。

### プロジェクトターゲット

生成されたプラグインには、いくつかの重要なターゲットが含まれています：

#### ビルドターゲット
TypeScriptコードをコンパイルし、プラグインを使用できるように準備します：

<NxCommands commands={['build your-plugin']} />

#### パッケージターゲット
NPM公開用の配布可能なパッケージを作成します：

<NxCommands commands={['package your-plugin']} />

パッケージターゲットには、必要なすべてのアセットが含まれます：
- コンパイルされたJavaScriptファイル
- TypeScript宣言ファイル
- 公開されたプラグインからNxが読み取る`generators.json`、`executors.json`、`migrations.json`マニフェスト
- ドキュメントとライセンスファイル

## MCPサーバーの統合

プラグインは<Link path="/guides/ts-mcp-server">`ts#mcp-server`</Link>ジェネレーターを使用してMCPサーバーを設定します。

### ツール

プラグインには、AIアシスタントに以下のツールを提供する完全なMCPサーバーが含まれています：

- `general-guidance`: Nxとプラグインでのベストプラクティスを取得
- `create-workspace-command`: プラグインを使用できる新しいワークスペースの作成方法を学習
- `list-generators`: プラグイン内の利用可能なすべてのジェネレーターをリスト
- `generator-guide`: スキーマと使用方法を含む特定のジェネレーターに関する詳細情報を取得

## プラグインの公開

### 公開の準備

1. **パッケージ情報の更新**: プラグインの[`package.json`](https://docs.npmjs.com/cli/v10/configuring-npm/package-json)を適切な名前、バージョン、説明、リポジトリ情報で編集します。また、`"private": true`を削除してください。

2. **パッケージのビルド**:
   <NxCommands commands={['package your-plugin']} />

   パッケージは`dist/<your-plugin's project root>/package`に配置されます。`--name=nx-plugin --directory=tools`で生成されたプラグインの場合、それは`dist/tools/nx-plugin/package`です。

3. **ローカルでのテスト**: 別のワークスペースにインストールすることで、プラグインをローカルでテストできます：
   ```bash
   npm install /path/to/your/workspace/dist/tools/nx-plugin/package
   ```

### NPMへの公開

プラグインの準備ができたら：

```bash
cd dist/tools/nx-plugin/package
npm publish
```

### 公開されたプラグインの使用

公開後、他のユーザーがプラグインをインストールして使用できます：

<InstallCommand pkg="your-plugin-name" />

次に、ジェネレーターを使用します：

<RunGenerator namespace="your-plugin-name" generator="your-generator-name" />

#### 公開されたプラグインでAIアシスタントを設定する

公開されたプラグインのMCPサーバーは、次のように設定できます：

```json {3-6}
{
  "mcpServers": {
    "aws-nx-mcp": {
      "command": "npx",
      "args": ["-y", "-p", "your-plugin-name", "your-plugin-name-mcp-server"]
    }
  }
}
```
