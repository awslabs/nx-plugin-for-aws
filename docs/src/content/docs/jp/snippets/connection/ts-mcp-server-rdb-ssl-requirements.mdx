---
title: RDS Proxyを使用せずに接続する場合のSSL要件
---

MCPサーバーがRDS Proxyを使用せずにAuroraクラスターに接続する場合、Node.jsはAmazon RDS認証局（CA）を信頼する必要があります。Node.jsはオペレーティングシステムのトラストストアを読み取りません。`NODE_EXTRA_CA_CERTS` 環境変数が指すファイルからのみ追加のCA証明書を読み込みます。

- MCPサーバーの `infra` が `agentcore-ecr` の場合、接続ジェネレーターはDockerfileを更新します。Amazon RDS CA バンドルを `/usr/local/share/ca-certificates/rds-bundle.crt` にダウンロードし、`NODE_EXTRA_CA_CERTS` をそのパスに設定するため、設定は不要です。以前のプラグインバージョンで生成されたDockerfileの場合、`nx migrate` が `NODE_EXTRA_CA_CERTS` 行を追加します。
- MCPサーバーの `infra` が `agentcore`（デフォルト）の場合、MCPサーバーはRDS CA バンドルを含まないコードパッケージとしてデプロイされます。RDS Proxyを有効のままにする（デフォルト）か、`agentcore-ecr` を使用してください。

詳細については、[Amazon RDS SSL/TLS ドキュメント](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/UsingWithRDS.SSL.html)を参照してください。RDS Proxyを使用する場合、`NODE_EXTRA_CA_CERTS` を設定する必要はありません。
