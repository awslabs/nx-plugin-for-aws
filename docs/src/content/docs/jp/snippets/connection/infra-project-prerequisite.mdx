:::note[インフラストラクチャプロジェクトが必要]
agent、MCP server、Gateway ジェネレーターは、それらのコンストラクトとモジュールを `packages/common` に提供しますが、それらをデプロイするためのアプリケーションは作成しません。そのため、`packages/infra` は生成するまで存在しません。以下のファイルを編集する前に、<Link path="guides/typescript-infrastructure">`ts#infra`</Link> ジェネレーター（CDK）または <Link path="guides/terraform-project">`terraform#project`</Link> ジェネレーター（Terraform）を実行してください。
:::
