[AWS Arch](https://aws.github.io/aws-pdk/developer_guides/aws-arch/index.html) は、CloudFormation リソースとそれに関連するアーキテクチャアイコンの間のマッピングを CDK Graph 上で提供していました。

アイコン関連のリソースについては、[AWS Architecture Icons ページ](https://aws.amazon.com/architecture/icons/)を参照してください。[Diagrams](https://diagrams.mingrammer.com/) も、コードとして図を構築する方法を提供しています。

これを直接使用していた場合は、プロジェクトをフォークして所有権を取得することを検討してください！
