:::note[Terraform CORS設定]
ソリューションにTerraform Webサイトモジュールが含まれている場合、そのCloudFrontドメイン名を使用してCORSを制限できます。
CloudFrontドメイン名`<domain_name>`が与えられた場合、APIをデプロイするためのTerraformモジュール内に以下を追加します
- HTTP APIの場合、`cors_allow_origins`プロパティを`["http://localhost:4200", "http://localhost:4300", "https://<domain name>"]`に設定します。これにより、API GatewayのCORSがこのディストリビューションとローカルホストに制限されます。
- REST APIの場合、`ALLOWED_ORIGINS`環境変数を`"https://<domain_name>"`に設定します。これにより、AWS Lambda統合において、CloudFrontディストリビューションが（ローカルホスト以外の）唯一許可されたCORSオリジンとして設定されます。この制限はプリフライトOPTIONSには適用されないことに注意してください - この問題への対処を優先順位付けするために、[このGitHub issue](https://github.com/awslabs/nx-plugin-for-aws/issues/377)に+1をお願いします。

```hcl {6,9}
module "my_api" {
  source = "../../common/terraform/src/app/apis/my-api"

  asset_bucket_name = module.asset_bucket.bucket_name

  cors_allow_origins = ["http://localhost:4200", "http://localhost:4300", "https://<domain name>"] // Only required for HTTP API

  env = {
    ALLOWED_ORIGINS = "https://<domain name>" // Only required for REST API
    ENVIRONMENT = var.environment
    LOG_LEVEL   = "INFO"
  }
}
```
`MyWebsite`コンストラクトは、<Link path="/jp/guides/react-website">`ts#website`ジェネレーター</Link>を使用して生成できます。この例では、Webサイトのローカルポートが`4200`/`4300`であることを前提としています - この方法で生成された各Webサイトには独自のポートが割り当てられるため、実際に割り当てられたポートについては`project.json`（または`vite.config.mts`）を確認してください。
:::
