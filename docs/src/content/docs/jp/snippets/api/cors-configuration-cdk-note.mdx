:::note[CDK CORS Configuration]
ソリューションにウェブサイトが含まれている場合、API ゲートウェイ / API AWS Lambda 統合の HTTP / REST API において、その CloudFront ディストリビューションを唯一許可された CORS オリジンとして設定できます。
API の `restrictCorsTo` メソッドを、ウェブサイトコンストラクト、CloudFront ディストリビューション、オリジン文字列、またはそれらの組み合わせで呼び出すことができます。

```ts
import { MyApi, MyWebsite } from '@my-scope/common-constructs';

export class ExampleStack extends Stack {
  constructor(scope: Construct, id: string) {
    const api = new MyApi(this, 'MyApi', {
      integrations: MyApi.defaultIntegrations(this).build(),
    });
    const website = new MyWebsite(this, 'MyWebsite');
    api.restrictCorsTo(website, 'http://localhost:4200', 'http://localhost:4300');
  }
}
```

`MyWebsite` コンストラクトは <Link path="/guides/react-website">`ts#website` ジェネレーター</Link>を使用して生成できます。この例では、ウェブサイトのローカル開発サーバーとプレビューポートが `4200`/`4300` であることを前提としています - この方法で生成された各ウェブサイトには独自のポートが割り当てられるため、実際に割り当てられたポートについては `project.json`（または `vite.config.mts`）を確認してください。
:::
