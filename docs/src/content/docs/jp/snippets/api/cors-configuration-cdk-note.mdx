:::note[CDK CORS Configuration]
ソリューションにウェブサイトが含まれている場合、API Gateway / API AWS Lambda統合（HTTP / REST API用）において、そのCloudFrontディストリビューションを唯一許可されたCORSオリジンとして設定できます。
APIの`restrictCorsTo`メソッドを、ウェブサイトコンストラクト、CloudFrontディストリビューション、オリジン文字列、またはそれらの組み合わせで呼び出すことができます。

```ts
import { MyApi, MyWebsite } from '@my-scope/common-constructs';

export class ExampleStack extends Stack {
  constructor(scope: Construct, id: string) {
    const api = new MyApi(this, 'MyApi', {
      integrations: MyApi.defaultIntegrations(this).build(),
    });
    const website = new MyWebsite(this, 'MyWebsite');
    api.restrictCorsTo(website, 'http://localhost:4200');
  }
}
```

`MyWebsite`コンストラクトは、<Link path="/guides/react-website">`ts#website`ジェネレーター</Link>を使用して生成できます。
:::
