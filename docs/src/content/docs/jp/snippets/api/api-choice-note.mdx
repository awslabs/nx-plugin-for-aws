---
title: RESTとHTTPの選択
---
:::note[APIタイプの選択]
APIをデプロイするには、[REST API](https://docs.aws.amazon.com/apigateway/latest/developerguide/apigateway-rest-api.html)または[HTTP API](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api.html)のいずれかを選択できます。決定に役立つ情報については、[API Gateway Developer Guide](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-vs-rest.html)を参照してください。
:::
