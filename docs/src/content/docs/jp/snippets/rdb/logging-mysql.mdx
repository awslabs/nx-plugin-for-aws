---
title: MySQL クエリログ
---

`audit` および `error` ログは [Aurora MySQL](https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/AuroraMySQL.Integrating.CloudWatch.html) 用にエクスポートされます — `general` および `slowquery` は、DML 値を含む完全なステートメントテキストをログに記録するため、意図的に除外されています。[Advanced Auditing](https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/AuroraMySQL.Auditing.html) は接続と DDL にスコープされており（`server_audit_events=CONNECT,QUERY_DDL`）、ステートメントパラメータ値はログに記録されません。
