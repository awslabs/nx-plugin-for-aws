### 設定ファイル

MCP をサポートするほとんどの AI アシスタントは、同様の設定アプローチを使用します。MCP サーバーの詳細を含む設定ファイルを作成または更新する必要があります：

```json
{
  "mcpServers": {
    "your-mcp-server": {
      "command": "uv",
      "args": [
        "run",
        "python",
        "-m",
        "my_module.mcp_server.stdio"
      ],
      "env": {
        "VIRTUAL_ENV": "/path/to/your/project/.venv"
      }
    }
  }
}
```

:::caution[パス解決]
サーバーへの接続時に `ENOENT uv` などのエラーが発生した場合、`uv` へのフルパスを指定する必要があるかもしれません。これは、ターミナルで `which uv` を実行することで取得できます。
:::
