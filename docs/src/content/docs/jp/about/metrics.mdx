---
title: 使用状況メトリクス
description: "@aws/nx-plugin がメトリクスを収集する方法"
---

Nx Plugin for AWS の改善を支援するため、ジェネレーターの使用状況に関するメトリクスを収集しています。このプロセスでは追加のネットワークリクエストは発生せず、既存の AWS 使用状況メトリクスを活用するだけです。

透明性を保つため、CloudFormation スタックの説明に ID、バージョン、およびジェネレーター ID のリストを追加しています。これは、CDK の場合は `common/constructs` の `MetricsAspect` で、Terraform の場合は `metrics.tf` Cloudformation スタックで行われます。

## オプトアウト

メトリクスコードは完全にワークスペース内に存在するため、削除することでオプトアウトできます：

- **CDK**: `packages/common/constructs/src/core/app.ts` から `MetricsAspect` クラスと `Aspects.of(this).add(new MetricsAspect())` 呼び出しを削除します。
- **Terraform**: `packages/common/terraform/src/metrics/metrics.tf` を削除します。

ジェネレーターは、一度削除されたメトリクスコードを再追加することはありません。
