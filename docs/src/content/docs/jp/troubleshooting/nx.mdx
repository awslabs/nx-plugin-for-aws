このページでは、Nx を使用する際に遭遇する可能性のある問題に対するトラブルシューティングのガイダンスを提供します。

## Nx Daemon

[Nx Daemon](https://nx.dev/docs/concepts/nx-daemon) は、プロジェクトグラフを再計算するためにワークスペースの変更を継続的に監視するプロセスです。これにより、特に大規模なプロジェクトでパフォーマンスが向上しますが、環境によっては問題の原因となることがあります。

これはさまざまな形で現れる可能性があり、その1つが次のエラーです：

```bash
 NX   Could not find project "@scope/project"

Pass --verbose to see the stacktrace.
```

このエラーや他の予期しないエラーについては、デーモンの問題の可能性があるため、常に Nx をリセットして再試行する価値があります。次のコマンドを使用できます：

<NxCommands commands={['reset']} />

それでも解決しない場合は、[デーモンを完全に無効にする](https://nx.dev/docs/concepts/nx-daemon#turning-it-off)ことを試すことができます。

:::note[Daemon Required]
`nx watch` コマンドはデーモンを必要とするため、ローカル開発サーバーをホットリロードするために依存する `dev` ターゲットにはデーモンを有効にする必要があります。
:::
