Nx Plugin for AWS fornece um gerador para integrar rapidamente seu <Link path="guides/py-agent">Python Agent</Link> com um site React. Ele configura toda a configuração necessária para conectar ao seu agente através de um cliente gerado por OpenAPI com segurança de tipos, incluindo suporte para autenticação AWS IAM e Cognito.

:::tip[Agentes AG-UI]
Se o seu Python Agent foi gerado com `protocol=ag-ui`, o gerador de conexão configura em vez disso o [CopilotKit](https://docs.copilotkit.ai/aws-strands) e um `HttpAgent` [`@ag-ui/client`](https://docs.ag-ui.com/) no site React. Consulte o guia <Link path="guides/connection/react-agui">React para AG-UI Agent</Link> para detalhes.
:::

## Pré-requisitos

Antes de usar este gerador, certifique-se de ter:

1. Um site React (gerado usando o <Link path="guides/react-website">gerador `ts#website`</Link>)
2. Um Python Agent com `protocol=http` (gerado usando o <Link path="guides/py-agent">gerador `py#agent`</Link>)
3. Cognito Auth adicionado através do <Link path="/guides/react-website-auth">gerador `ts#website#auth`</Link>

## Saída do Gerador

O gerador cria o seguinte no seu projeto Python Agent:

<FileTree>

- scripts
  - \<agent_name>_openapi.py Script para gerar uma especificação OpenAPI a partir do aplicativo FastAPI do agente
- project.json Um novo target `<agent-name>-openapi` é adicionado

</FileTree>

O gerador cria a seguinte estrutura na sua aplicação React:

<FileTree>

- src
  - components
    - \<AgentName>Provider.tsx Provider para o cliente OpenAPI
    - QueryClientProvider.tsx Provider do cliente TanStack React Query
  - hooks
    - useSigV4.tsx Hook para assinar requisições com SigV4 (apenas IAM)
    - use\<AgentName>.tsx Hook que retorna o proxy de opções TanStack Query para a API do seu agente
    - use\<AgentName>Client.tsx Hook que retorna o cliente de API vanilla
  - generated
    - \<agent-name>
      - types.gen.ts Tipos gerados a partir dos modelos Pydantic do agente
      - client.gen.ts Cliente com segurança de tipos para chamar a API do seu agente
      - options-proxy.gen.ts Opções de hooks TanStack Query para interagir com seu agente
- project.json Targets adicionados para geração de cliente e observação de mudanças
- .gitignore Os arquivos de cliente gerados são ignorados por padrão

</FileTree>

## Como Funciona

### Geração de Cliente OpenAPI

No momento da compilação, o aplicativo FastAPI do Python Agent é inspecionado para gerar uma especificação OpenAPI. Esta especificação é então usada para gerar um cliente TypeScript com segurança de tipos com hooks TanStack Query, seguindo o mesmo padrão da <Link path="guides/connection/react-fastapi">conexão React para FastAPI</Link>.

Cada agente obtém seu próprio script OpenAPI com escopo (por exemplo, `scripts/agent_openapi.py`) para que projetos com múltiplos agentes possam gerar especificações individuais.

### Configuração em Tempo de Execução

Executar este gerador de conexão também corrige o construto CDK/Terraform gerado do agente para publicar seu ARN de tempo de execução AgentCore no `runtime-config.json` do site (sob o namespace `connection`), então apenas os agentes que você conecta explicitamente são expostos ao frontend. Consulte <Link path="guides/runtime-config">Configuração em Tempo de Execução</Link> para detalhes.

### Autenticação

O código gerado lida com autenticação dependendo da configuração do seu agente:

- **IAM** (padrão): Usa AWS SigV4 para assinar requisições HTTP. As credenciais são obtidas do Cognito Identity Pool configurado com a autenticação do seu site
- **Cognito**: Incorpora o token de acesso JWT em um cabeçalho Authorization
- **None**: Sem autenticação

## Usando o Código Gerado

### Usando o Hook da API

O hook `use<AgentName>` fornece opções TanStack Query para chamar os endpoints da API do seu agente:

```tsx
import { useState } from 'react';
import { useMutation } from '@tanstack/react-query';
import { useMyAgent } from '../hooks/useMyAgent';
import type { StreamChunk } from '../generated/my-agent/types.gen';

function ChatComponent() {
  const api = useMyAgent();
  const [chunks, setChunks] = useState<StreamChunk[]>([]);

  const invoke = useMutation(api.invoke.mutationOptions({
    onSuccess: async (stream) => {
      setChunks([]);
      for await (const chunk of stream) {
        setChunks((prev) => [...prev, chunk]);
      }
    },
  }));

  const handleSend = (prompt: string) => {
    invoke.mutate({ prompt });
  };

  return (
    <div>
      <button onClick={() => handleSend('Hello!')}>Send</button>
      {invoke.isPending && <p>Agent is thinking...</p>}
      {chunks.map((chunk, i) => (
        <span key={i}>{chunk.content}</span>
      ))}
    </div>
  );
}
```

### Usando o Cliente Vanilla

O hook `use<AgentName>Client` fornece acesso direto ao cliente da API:

```tsx
import { useState } from 'react';
import { useMyAgentClient } from '../hooks/useMyAgentClient';
import type { StreamChunk } from '../generated/my-agent/types.gen';

function ChatComponent() {
  const client = useMyAgentClient();
  const [chunks, setChunks] = useState<StreamChunk[]>([]);

  const handleSend = async (prompt: string) => {
    setChunks([]);
    for await (const chunk of client.invoke({ prompt })) {
      setChunks((prev) => [...prev, chunk]);
    }
  };

  return (
    <div>
      <button onClick={() => handleSend('Hello!')}>Send</button>
      {chunks.map((chunk, i) => (
        <span key={i}>{chunk.content}</span>
      ))}
    </div>
  );
}
```

## Desenvolvimento Local

O gerador de conexão configura automaticamente a integração `dev`:

1. Executar `nx dev <website>` também iniciará o servidor FastAPI local do agente
2. A configuração de tempo de execução é substituída para apontar para a URL HTTP local (por exemplo, `http://localhost:8081/`)
3. O cliente TypeScript é regenerado automaticamente quando a API do agente muda

<NxCommands commands={['dev <WebsiteProject>']} />

:::tip[Hot Reloading]
O site e o agente conectado farão hot-reload, permitindo que você itere rapidamente em ambos juntos sem implantar na AWS.
:::
