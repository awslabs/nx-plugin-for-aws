O gerador `connection` conecta um <Link path="guides/py-mcp-server">Servidor MCP Python</Link> a um projeto <Link path="guides/py-dynamodb">DynamoDB Python</Link>, configurando o desenvolvimento local para que ambos iniciem juntos automaticamente.

## Pré-requisitos

Antes de usar este gerador, certifique-se de ter:

1. Um projeto <Link path="guides/py-mcp-server">`py#mcp-server`</Link>
2. Um projeto <Link path="guides/py-dynamodb">`py#dynamodb`</Link>

## Saída do Gerador

O gerador atualiza o target `<mcp-server-name>-dev` do servidor MCP em `project.json` para depender do target `dev` do projeto DynamoDB, e adiciona o pacote DynamoDB como uma dependência do workspace. Nenhum arquivo de código-fonte é modificado.

## Usando DynamoDB em Ferramentas

Importe classes de entidade do pacote DynamoDB e use-as dentro das ferramentas do seu servidor MCP:

```python title="packages/my_project/my_project/my_mcp_server/server.py"
from my_scope_my_table.entities.example import ExampleModel

@mcp.tool()
def list_examples() -> str:
    """List all example items."""
    items = list(ExampleModel.scan())
    return str([item.attribute_values for item in items])
```

`my_scope_my_table` é o nome do módulo do seu projeto DynamoDB — um único módulo plano nomeado `<scope>_<name>`, visível como o diretório do pacote dentro do projeto.

## Infraestrutura

Para permitir que a função Lambda do servidor MCP acesse a tabela DynamoDB, conceda as permissões necessárias em sua infraestrutura.

<Infrastructure>
<Fragment slot="cdk">

```ts title="packages/infra/src/stacks/application-stack.ts"
import { MyTable } from '@my-scope/common-constructs';

const table = new MyTable(this, 'Table');
const myMcpServer = new MyMcpServer(this, 'MyMcpServer');

table.grantReadWriteData(myMcpServer);
```

`grantReadWriteData` concede tanto as permissões do DynamoDB quanto do KMS para a role de execução do servidor MCP.
</Fragment>
<Fragment slot="terraform">

Conceda à role de runtime do servidor MCP acesso à tabela e sua chave de criptografia KMS via `additional_iam_policy_statements`:

```hcl title="packages/infra/src/main.tf"
module "my_table" {
  source = "../../common/terraform/src/app/dynamodb/my-table"
}

module "my_mcp_server" {
  source = "../../common/terraform/src/app/mcp-servers/my-mcp-server"

  additional_iam_policy_statements = [
    {
      Effect = "Allow"
      Action = [
        "dynamodb:GetItem", "dynamodb:PutItem", "dynamodb:UpdateItem",
        "dynamodb:DeleteItem", "dynamodb:Query", "dynamodb:Scan",
        "dynamodb:BatchGetItem", "dynamodb:BatchWriteItem",
      ]
      Resource = [
        module.my_table.table_arn,
        "${module.my_table.table_arn}/index/*",
      ]
    },
    {
      Effect = "Allow"
      Action = [
        "kms:Encrypt",
        "kms:Decrypt",
        "kms:ReEncrypt*",
        "kms:GenerateDataKey*",
        "kms:DescribeKey",
      ]
      Resource = [module.my_table.kms_key_arn]
    },
  ]
}
```
</Fragment>
</Infrastructure>
