---
title: Desenvolvimento Local do DynamoDB
---

O gerador `connection` configura o target `dev` do seu projeto para depender do target `dev` do projeto DynamoDB. O DynamoDB Local será iniciado automaticamente junto com seu projeto ao executar `dev`.

A variável de ambiente `LOCAL_DEV=true` é definida automaticamente, então `getDynamoDBClient()` e `resolveTableName()` se conectam à instância local do DynamoDB Local em vez da AWS.
