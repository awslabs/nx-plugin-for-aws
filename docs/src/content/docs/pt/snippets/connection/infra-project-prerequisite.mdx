:::note[Projeto de infraestrutura necessário]
Os geradores de agente, servidor MCP e Gateway fornecem seus construtos e módulos em `packages/common`, mas eles não criam uma aplicação para implantá-los — então `packages/infra` não existe até que você o gere. Execute o gerador <Link path="guides/typescript-infrastructure">`ts#infra`</Link> (CDK) ou o gerador <Link path="guides/terraform-project">`terraform#project`</Link> (Terraform) antes de editar o arquivo abaixo.
:::
