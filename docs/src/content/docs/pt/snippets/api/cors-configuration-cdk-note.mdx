:::note[Configuração CORS CDK]
Se sua solução incluir um website, você pode configurar sua distribuição CloudFront como a única origem CORS permitida no API gateway / integrações API AWS Lambda para APIs HTTP / REST.
Você pode chamar o método `restrictCorsTo` da API com constructs de website, distribuições CloudFront, strings de origem ou uma combinação deles.

```ts
import { MyApi, MyWebsite } from '@my-scope/common-constructs';

export class ExampleStack extends Stack {
  constructor(scope: Construct, id: string) {
    const api = new MyApi(this, 'MyApi', {
      integrations: MyApi.defaultIntegrations(this).build(),
    });
    const website = new MyWebsite(this, 'MyWebsite');
    api.restrictCorsTo(website, 'http://localhost:4200', 'http://localhost:4300');
  }
}
```

O construct `MyWebsite` pode ser gerado usando o <Link path="/guides/react-website">gerador `ts#website`</Link>. Este exemplo assume que as portas do servidor de desenvolvimento local e de preview do website são `4200`/`4300` - verifique seu `project.json` (ou `vite.config.mts`) para as portas realmente atribuídas a ele, já que cada website gerado dessa forma recebe suas próprias portas.
:::
