---
title: Métricas de Uso
description: Como o @aws/nx-plugin coleta métricas
---

Para nos ajudar a melhorar o Nx Plugin for AWS, coletamos métricas sobre o uso de geradores. Este processo não envolve solicitações de rede adicionais, simplesmente aproveitamos as métricas de uso existentes da AWS.

Para manter a transparência, anexamos um ID, versão e lista de IDs de geradores às descrições de Stack do CloudFormation. Isso é feito no `MetricsAspect` em `common/constructs` para CDK ou no stack Cloudformation `metrics.tf` para Terraform.

## Desativação

O código de métricas reside inteiramente no seu workspace, então você pode desativá-lo removendo-o:

- **CDK**: remova a classe `MetricsAspect` e a chamada `Aspects.of(this).add(new MetricsAspect())` de `packages/common/constructs/src/core/app.ts`.
- **Terraform**: exclua `packages/common/terraform/src/metrics/metrics.tf`.

Os geradores não adicionarão novamente o código de métricas uma vez removido.
