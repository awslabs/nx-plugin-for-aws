Esboce os projetos que seu workspace precisa e as conexões entre eles, e o builder gera os comandos que estruturam exatamente o que você desenhou. Copie-os, execute-os e você terá um workspace funcional.

Arraste componentes da paleta para a tela, arraste da borda direita de um componente para outro para conectá-los e edite as propriedades de cada componente à direita. Os comandos gerados na parte inferior são atualizados a cada mudança — clique em **Copy** para copiar o script completo.

## Como funciona

Cada componente na tela mapeia para um gerador, e cada conexão para o <Link path="guides/connection">gerador de conexão</Link>. Os comandos são emitidos em ordem de dependência: o workspace primeiro, depois os projetos, depois os componentes que eles hospedam e, por fim, as conexões que os conectam.

Um projeto `infra` é adicionado no final — <Link path="guides/typescript-infrastructure">`ts#infra`</Link> ou <Link path="guides/terraform-project">`terraform#project`</Link>, correspondendo à sua escolha de IaC. Cada projeto gerado fornece construtos para ele instanciar, então é isso que você implanta. Como ele possui esse nome, nenhum componente na tela pode ser chamado de `infra`.

Arraste o fundo da tela para navegar e arraste um componente para reposicioná-lo. Shift-clique para selecionar vários componentes e movê-los como um grupo.

A paleta lista todos os tipos de projeto e componente que podem participar de uma conexão, e você só pode desenhar as conexões que o plugin suporta — então um grafo que valida é um grafo que estrutura.

Duas regras valem a pena conhecer:

- **Componentes compartilham um projeto host.** Um agente e um servidor MCP são adicionados _a_ um projeto em vez de serem projetos próprios. Dê a eles o mesmo nome de projeto host para colocá-los em um projeto, ou nomes diferentes para um projeto cada.
- **Algumas conexões restringem seus endpoints.** Conectar um agente a outro agente requer que o destino use o protocolo `a2a`, por exemplo. Quando uma configuração de propriedade quebraria uma conexão que você desenhou, o builder informa isso no componente e na conexão.

:::tip[Prefere construir com IA?]
O plugin inclui um servidor MCP, então seu agente de codificação pode estruturar e conectar projetos para você. Veja <Link path="get_started/building-with-ai">Building with AI</Link>.
:::
