Instale o [Claude Plugin](https://code.claude.com/docs/en/plugins), [Kiro Power](https://kiro.dev/docs/powers/), ou [MCP Server](https://modelcontextprotocol.io/introduction) para permitir que assistentes de IA trabalhem efetivamente com o plugin. Ao usá-los, você pode acelerar seu fluxo de trabalho de desenvolvimento com IA enquanto se beneficia de seus projetos sendo estruturados de forma consistente, gastando menos tempo na configuração dos componentes principais e se beneficiando da segurança, observabilidade, segurança de tipos e desenvolvimento local integrados ao plugin.

## Configure seu Assistente de IA

:::tip[A configuração em nível de projeto é automática]
Workspaces criados com o preset Nx Plugin for AWS já incluem configuração MCP em nível de projeto para agentes de codificação comuns (Claude Code, Cursor, Kiro, Gemini CLI, GitHub Copilot e OpenAI Codex). Qualquer agente trabalhando dentro do workspace pode usar o servidor MCP sem configuração adicional. Os passos abaixo configuram o servidor MCP globalmente para uso em todos os seus projetos.
:::

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    O Nx Plugin for AWS é distribuído como um [Kiro Power](https://kiro.dev/docs/powers/) que agrupa o servidor MCP com documentação de orientação e guias de fluxo de trabalho.

    <Steps>

    1. Abra o painel Powers no Kiro e clique em **Add power from GitHub**
    2. Digite a seguinte URL:

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. Clique em **Install**

    </Steps>

    O Kiro configura automaticamente o servidor MCP — nenhuma configuração adicional é necessária.

  </TabItem>
  <TabItem label="Kiro CLI">
    Execute o seguinte comando:

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    Consulte a [documentação MCP do Kiro CLI](https://kiro.dev/docs/cli/mcp/) para mais detalhes.

  </TabItem>
  <TabItem label="Claude Code">
    O Nx Plugin for AWS é distribuído como um [plugin do Claude Code](https://code.claude.com/docs/en/plugins) que agrupa uma [Skill](https://code.claude.com/docs/en/skills) com o servidor MCP.

    Execute os seguintes comandos dentro do Claude Code, um de cada vez:

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    Em seguida, execute `/reload-plugins` para ativar o plugin.

  </TabItem>
  <TabItem label="Cursor">
    Adicione o seguinte a `~/.cursor/mcp.json` (ou `.cursor/mcp.json` no seu projeto):

    <Snippet name="mcp/config" />

    Consulte a [documentação MCP do Cursor](https://cursor.com/docs/mcp) para mais detalhes.

  </TabItem>
  <TabItem label="Codex">
    Adicione o seguinte a `~/.codex/config.toml`:

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    Consulte a [documentação de configuração do Codex](https://developers.openai.com/codex/config-reference) para mais detalhes.

## Comece a Programar com Vibe

Peça ao seu Assistente de IA para construir algo usando o `nx-plugin-for-aws`! Ele normalmente criará um workspace, estruturará com os geradores aplicáveis e então preencherá a lógica de negócios.

Experimente um prompt como:

> _"Construa uma aplicação multi-agente usando o Nx Plugin for AWS. Eu quero um frontend React que se comunique com um agente orquestrador de backend que delega para agentes especializados de pesquisa e escrita."_

Ou para um ponto de partida menor:

> _"Use o Nx Plugin for AWS para estruturar um site React apoiado por uma API tRPC, com autenticação Cognito e infraestrutura CDK."_
