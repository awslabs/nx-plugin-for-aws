## Já configurado no seu workspace

Workspaces criados com o preset Nx Plugin for AWS incluem configuração MCP em nível de projeto para agentes de codificação comuns — Claude Code, Cursor, Kiro, Gemini CLI, GitHub Copilot e OpenAI Codex — para que um agente trabalhando dentro do workspace possa usar o [servidor MCP](https://modelcontextprotocol.io/introduction) do plugin sem configuração adicional.

Abra seu workspace no seu assistente e peça o que você deseja:

<Prompt>
Add a React website with an AG-UI agent, an MCP server for its tools and a DynamoDB table, and wire them together.
</Prompt>

Ele procura os geradores que o plugin oferece, os executa na ordem que suas dependências precisam e preenche a lógica de negócios a partir daí.

## Instale globalmente

A <Link path="get_started/quick-start">configuração do workspace</Link> acima é suficiente para construir. Instale um plugin ou power também se você quiser o servidor MCP disponível em todos os seus projetos:

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    O Nx Plugin for AWS é distribuído como um [Kiro Power](https://kiro.dev/docs/powers/) que agrupa o servidor MCP com documentação de orientação e guias de fluxo de trabalho.

    <Steps>

    1. Abra o painel Powers no Kiro e clique em **Add power from GitHub**
    2. Digite a seguinte URL:

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. Clique em **Install**

    </Steps>

    O Kiro configura automaticamente o servidor MCP — nenhuma configuração adicional é necessária.

  </TabItem>
  <TabItem label="Kiro CLI">
    Execute o seguinte comando:

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    Consulte a [documentação MCP do Kiro CLI](https://kiro.dev/docs/cli/mcp/) para mais detalhes.

  </TabItem>
  <TabItem label="Claude Code">
    O Nx Plugin for AWS é distribuído como um [plugin do Claude Code](https://code.claude.com/docs/en/plugins) que agrupa uma [Skill](https://code.claude.com/docs/en/skills) com o servidor MCP.

    Execute os seguintes comandos dentro do Claude Code, um de cada vez:

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    Em seguida, execute `/reload-plugins` para ativar o plugin.

  </TabItem>
  <TabItem label="Cursor">
    Adicione o seguinte a `~/.cursor/mcp.json` (ou `.cursor/mcp.json` no seu projeto):

    <Snippet name="mcp/config" />

    Consulte a [documentação MCP do Cursor](https://cursor.com/docs/mcp) para mais detalhes.

  </TabItem>
  <TabItem label="Codex">
    Adicione o seguinte a `~/.codex/config.toml`:

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    Consulte a [documentação de configuração do Codex](https://developers.openai.com/codex/config-reference) para mais detalhes.

  </TabItem>
  <TabItem label="Other">
    A maioria dos assistentes compatíveis com MCP usa um arquivo de configuração JSON. Adicione a seguinte entrada:

    <Snippet name="mcp/config" />

    Se você tiver problemas como `ENOENT npx`, substitua o comando pelo caminho completo para `npx` (encontre-o com `which npx`).

    Para documentação específica do assistente:

    <Snippet name="mcp/assistant-docs" />

  </TabItem>
</Tabs>

## Comece a Programar com Vibe

Com o plugin disponível globalmente, seu assistente também pode criar o workspace. Experimente um prompt como:

<Prompt>
Build a multi-agent application using the Nx Plugin for AWS. I want a React frontend that talks to a backend orchestrator agent which delegates to specialised research and writing agents.
</Prompt>

Ou para um ponto de partida menor:

<Prompt>
Use the Nx Plugin for AWS to scaffold a React website backed by a tRPC API, with Cognito auth and CDK infrastructure.
</Prompt>
