## Tarefa 1: Implementar o Story Agent

O Story Agent é um agente [Strands](https://strandsagents.com/) gerado com `--protocol=ag-ui` no <Link path="get_started/tutorials/dungeon-game/1">Módulo 1</Link>, para que a UI possa transmitir a partir dele através do [protocolo Agent-User Interaction](https://docs.copilotkit.ai/aws-strands/protocol) via CopilotKit. Ele usa o Inventory MCP Server para gerenciar os itens do jogador e já persiste o histórico de conversação através do `session.py` que o gerador provisionou no Módulo 1 — quando implantado, isso é o [`S3SessionManager`](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/agents/sessions/) integrado do Strands escrevendo no mesmo bucket S3 do qual o `queryActions` da Game API lê, para que o navegador possa reconstruir transcrições em revisitas.

### Implementação do agente

Atualize `agent.py` em `packages/story/dungeon_adventure_story/agent`:

<E2EDiff lang="python" before="dungeon-adventure/3/agent.py.old.template" after="dungeon-adventure/3/agent.py.template" />

`agent.py` remove a ferramenta de exemplo `subtract` e troca o prompt do sistema por um de mestre de masmorra que convida a primeira mensagem do usuário a declarar o nome e o gênero do jogador, e usa as ferramentas do Inventory MCP Server. `main.py` não precisa de alterações aqui — o gerenciamento de sessão já foi configurado quando o agente foi gerado.

### Conversar com seu Agent

O target `agent-chat` gerado abre um REPL interativo contra seu agente. Ele é executado de forma independente e se conecta ao seu agente em execução local, então primeiro inicie o servidor local do agente em um terminal:

<NxCommands commands={["agent-dev story"]} />

Em seguida, em um segundo terminal, inicie o chat:

<NxCommands commands={["agent-chat story"]} />

Sua primeira mensagem deve informar ao agente o nome do seu herói e o gênero (por exemplo: `Meu nome é Alice. Comece minha aventura zumbi.`) e a história será transmitida de volta.

<Aside type="caution" title="Credenciais AWS necessárias">
Embora o agente seja executado localmente, ele invoca o [Amazon Bedrock](https://aws.amazon.com/bedrock/) para o LLM. Você precisará de credenciais AWS no seu ambiente com acesso ao [modelo padrão do Strands](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/model-providers/amazon-bedrock/). Consulte a [documentação de provedores de modelo do Strands](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/model-providers/amazon-bedrock/) para detalhes.
</Aside>
