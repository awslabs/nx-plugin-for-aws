Esta página fornece algumas orientações para solução de problemas que você pode encontrar ao usar o Nx.

## Nx Daemon

O [Nx Daemon](https://nx.dev/docs/concepts/nx-daemon) é um processo que monitora continuamente as mudanças no workspace para recalcular seu grafo de projetos. Isso proporciona um ganho de desempenho, particularmente para projetos grandes, mas às vezes pode ser a causa de problemas dependendo do seu ambiente.

Isso pode se manifestar de diferentes maneiras, uma das quais é o seguinte erro:

```bash
 NX   Could not find project "@scope/project"

Pass --verbose to see the stacktrace.
```

Para este e qualquer outro erro inesperado, sempre vale a pena redefinir o Nx e tentar novamente em caso de problema com o daemon. Você pode usar o seguinte comando:

<NxCommands commands={['reset']} />

Se isso falhar, você pode tentar [desabilitar o daemon completamente](https://nx.dev/docs/concepts/nx-daemon#turning-it-off).

:::note[Daemon Necessário]
O comando `nx watch` requer o daemon, então os alvos `dev` que dependem dele para fazer hot-reload dos seus servidores de desenvolvimento locais precisam que o daemon esteja habilitado.
:::
