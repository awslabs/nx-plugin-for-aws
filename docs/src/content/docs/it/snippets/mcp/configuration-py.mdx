### File di Configurazione

La maggior parte degli assistenti AI che supportano MCP utilizza un approccio di configurazione simile. Dovrai creare o aggiornare un file di configurazione con i dettagli del tuo server MCP:

```json
{
  "mcpServers": {
    "your-mcp-server": {
      "command": "uv",
      "args": [
        "run",
        "python",
        "-m",
        "my_module.mcp_server.stdio"
      ],
      "env": {
        "VIRTUAL_ENV": "/path/to/your/project/.venv"
      }
    }
  }
}
```

:::caution[Risoluzione del Percorso]
Se ricevi un errore come `ENOENT uv` durante la connessione al tuo server, potrebbe essere necessario specificare il percorso completo di `uv`, che puoi ottenere eseguendo `which uv` nel tuo terminale.
:::
