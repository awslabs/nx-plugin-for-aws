:::caution[Sperimentale]
Questo generatore è sperimentale. Il suo comportamento e l'output generato potrebbero cambiare in una versione futura senza che venga pubblicata una migrazione per applicare la modifica a un workspace esistente, quindi potrebbe essere necessario riconciliare tali modifiche manualmente quando si esegue l'aggiornamento.
:::
