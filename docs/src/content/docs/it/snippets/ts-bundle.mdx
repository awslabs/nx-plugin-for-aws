Il generatore configura automaticamente un target `bundle` che utilizza [Rolldown](https://rolldown.rs/) per creare un pacchetto di distribuzione:

<NxCommands commands={['bundle <project-name>']} />

La configurazione di Rolldown si trova in `rolldown.config.ts`, con una voce per ogni bundle da generare. Rolldown gestisce la creazione di più bundle in parallelo se definiti.

:::tip[Configurazione Personalizzata]
Puoi modificare la configurazione di Rolldown in `rolldown.config.ts`, ad esempio se hai dipendenze che si basano su percorsi di file e non possono essere raggruppate in bundle, puoi aggiungerle all'elenco dei moduli `external`.
:::
