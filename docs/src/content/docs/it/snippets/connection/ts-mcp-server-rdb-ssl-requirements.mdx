---
title: Requisiti SSL per la connessione senza RDS Proxy
---

Quando il server MCP si connette al cluster Aurora senza RDS Proxy, Node.js deve fidarsi dell'autorità di certificazione (CA) di Amazon RDS. Node.js non legge l'archivio di fiducia del sistema operativo. Carica certificati CA aggiuntivi solo dal file a cui punta la variabile d'ambiente `NODE_EXTRA_CA_CERTS`.

- Quando l'`infra` del server MCP è `agentcore-ecr`, il generatore di connessioni aggiorna il Dockerfile. Scarica il bundle CA di Amazon RDS in `/usr/local/share/ca-certificates/rds-bundle.crt` e imposta `NODE_EXTRA_CA_CERTS` su quel percorso, quindi non c'è nulla da configurare. Per un Dockerfile generato da una versione precedente del plugin, `nx migrate` aggiunge la riga `NODE_EXTRA_CA_CERTS`.
- Quando l'`infra` del server MCP è `agentcore` (l'impostazione predefinita), il server MCP viene distribuito come pacchetto di codice che non include il bundle CA di RDS. Mantieni RDS Proxy abilitato (l'impostazione predefinita) oppure usa `agentcore-ecr`.

Per maggiori dettagli, consulta la [documentazione SSL/TLS di Amazon RDS](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/UsingWithRDS.SSL.html). Quando si utilizza RDS Proxy, non è necessario configurare `NODE_EXTRA_CA_CERTS`.
