:::note[Progetto di infrastruttura richiesto]
I generatori agent, MCP server e Gateway forniscono i loro costrutti e moduli in `packages/common`, ma non creano un'applicazione da cui distribuirli — quindi `packages/infra` non esiste finché non lo generi. Esegui il generatore <Link path="guides/typescript-infrastructure">`ts#infra`</Link> (CDK) o il generatore <Link path="guides/terraform-project">`terraform#project`</Link> (Terraform) prima di modificare il file sottostante.
:::
