---
title: Requisiti SSL per la Connessione senza RDS Proxy
---

Quando l'agente si connette al cluster Aurora senza RDS Proxy, Node.js deve fidarsi dell'autorità di certificazione (CA) di Amazon RDS. Node.js non legge l'archivio di certificati attendibili del sistema operativo. Carica certificati CA aggiuntivi solo dal file a cui punta la variabile d'ambiente `NODE_EXTRA_CA_CERTS`.

- Quando l'`infra` dell'agente è `agentcore-ecr`, il generatore di connessione aggiorna il Dockerfile. Scarica il bundle CA di Amazon RDS in `/usr/local/share/ca-certificates/rds-bundle.crt` e imposta `NODE_EXTRA_CA_CERTS` su quel percorso, quindi non c'è nulla da configurare. Per un Dockerfile generato da una versione precedente del plugin, `nx migrate` aggiunge la riga `NODE_EXTRA_CA_CERTS`.
- Quando l'`infra` dell'agente è `agentcore` (il valore predefinito), l'agente viene distribuito come pacchetto di codice che non include il bundle CA di RDS. Mantieni RDS Proxy abilitato (il valore predefinito) oppure usa `agentcore-ecr`.

Per maggiori dettagli, consulta la [documentazione SSL/TLS di Amazon RDS](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/UsingWithRDS.SSL.html). Quando si utilizza RDS Proxy, non è necessario configurare `NODE_EXTRA_CA_CERTS`.
