[PDK Nag](https://aws.github.io/aws-pdk/developer_guides/pdk-nag/index.html) racchiude [CDK Nag](https://github.com/cdklabs/cdk-nag) e fornisce un insieme di [regole specifiche per la creazione di prototipi](https://github.com/aws/aws-pdk/blob/mainline/packages/pdk-nag/src/packs/aws-prototyping-rules.ts).

Per migrare da PDK Nag, utilizza CDK Nag direttamente. Se hai bisogno dello stesso insieme di regole, puoi creare un "pack" personalizzato seguendo la [documentazione qui](https://github.com/cdklabs/cdk-nag/blob/main/docs/NagPack.md).
