PDK è stato costruito su [Projen](https://projen.io/). Projen e Nx Generators hanno differenze abbastanza fondamentali, il che significa che sebbene sia tecnicamente possibile combinarli, è probabilmente un anti-pattern. Projen gestisce i file di progetto come codice in modo tale che non possano essere modificati direttamente, mentre i generatori Nx forniscono i file di progetto una volta sola e poi il codice può essere liberamente modificato.

Se desideri continuare a utilizzare Projen, puoi implementare tu stesso i tipi di progetto Projen desiderati. Per seguire i pattern di Nx Plugin for AWS, puoi eseguire i nostri generatori o esaminare il loro codice sorgente su GitHub per vedere come sono costruiti i tipi di progetto desiderati e implementare le parti rilevanti utilizzando le primitive di Projen.
