[AWS Arch](https://aws.github.io/aws-pdk/developer_guides/aws-arch/index.html) forniva mappature tra le risorse CloudFormation e le loro icone di architettura associate per CDK Graph sopra.

Fare riferimento alla [pagina AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) per le risorse relative alle icone. [Diagrams](https://diagrams.mingrammer.com/) fornisce anche un modo per costruire diagrammi come codice.

Se stavi utilizzando questo direttamente, considera di fare un fork del progetto e prenderne la proprietà!
