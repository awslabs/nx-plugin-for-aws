---
title: Prerequisiti Richiesti
---
- [Git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)
- [Node >= 22](https://nodejs.org/en/download) (Consigliamo di utilizzare qualcosa come [NVM](https://github.com/nvm-sh/nvm) per gestire le versioni di node)
  - verifica eseguendo `node --version`
- [UV >= 0.5.29](https://docs.astral.sh/uv/getting-started/installation/)
  1. installa Python 3.14 eseguendo: `uv python install 3.14.0`
  2. verifica con `uv python list --only-installed`
