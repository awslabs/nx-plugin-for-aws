Questa pagina fornisce alcune indicazioni per la risoluzione dei problemi che potresti incontrare quando usi Nx.

## Nx Daemon

Il [Nx Daemon](https://nx.dev/docs/concepts/nx-daemon) è un processo che monitora continuamente le modifiche dello spazio di lavoro per ricalcolare il suo grafo dei progetti. Questo fornisce un miglioramento delle prestazioni, in particolare per progetti di grandi dimensioni, ma a volte può essere la causa di problemi a seconda del tuo ambiente.

Questo può manifestarsi in diversi modi, uno dei quali è il seguente errore:

```bash
 NX   Could not find project "@scope/project"

Pass --verbose to see the stacktrace.
```

Per questo, e per qualsiasi altro errore imprevisto, vale sempre la pena reimpostare Nx e riprovare in caso di un problema con il daemon. Puoi usare il seguente comando:

<NxCommands commands={['reset']} />

In caso contrario, puoi provare a [disabilitare completamente il daemon](https://nx.dev/docs/concepts/nx-daemon#turning-it-off).

:::warning[Daemon Richiesto]
Il comando `nx watch` richiede il daemon, e pertanto alcuni dei tuoi target di hot-reloading potrebbero non funzionare se lo disabiliti.
:::
