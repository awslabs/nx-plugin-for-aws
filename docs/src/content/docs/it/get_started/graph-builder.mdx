Disegna i progetti di cui il tuo workspace ha bisogno e le connessioni tra di essi, e il builder genera i comandi che creano esattamente ciò che hai disegnato. Copiali, eseguili e avrai un workspace funzionante.

Trascina i componenti dalla palette sulla tela, trascina dal bordo destro di un componente a un altro per connetterli e modifica le proprietà di ciascun componente sulla destra. I comandi generati in basso si aggiornano ad ogni modifica — premi **Copy** per prendere l'intero script.

## Come funziona

Ogni componente sulla tela corrisponde a un generatore, e ogni connessione al <Link path="guides/connection">generatore di connessioni</Link>. I comandi vengono emessi in ordine di dipendenza: prima il workspace, poi i progetti, poi i componenti che ospitano, infine le connessioni che li collegano insieme.

Un website ottiene sempre l'<Link path="guides/react-website-auth">autenticazione Cognito</Link> aggiunta subito dopo, poiché `ts#website` lascia questo a un generatore successivo.

Un progetto `infra` viene aggiunto alla fine — <Link path="guides/typescript-infrastructure">`ts#infra`</Link> o <Link path="guides/terraform-project">`terraform#project`</Link>, corrispondente alla tua scelta IaC. Ogni progetto generato fornisce costrutti da istanziare, quindi questo è ciò che distribuisci. Poiché possiede quel nome, nessun componente sulla tela può essere chiamato `infra`.

Usa **Vertical** / **Horizontal** nella barra degli strumenti per cambiare la direzione del flusso del grafo — i punti di connessione si spostano sui bordi superiore e inferiore di ciascun componente, e il layout viene trasposto di conseguenza.

Trascina lo sfondo della tela per spostarti, e trascina un componente per riposizionarlo. Shift-click per selezionare più componenti e spostarli come gruppo. Clicca su una connessione per selezionarla, poi premi <kbd>Delete</kbd> per rimuoverla (o usa la ✕ sulla connessione stessa).

La palette elenca ogni tipo di progetto e componente che può partecipare a una connessione, e puoi disegnare solo le connessioni supportate dal plugin — quindi un grafo che valida è un grafo che si può generare.

Tre regole vale la pena conoscere:

- **I componenti condividono un progetto host.** Un agent e un server MCP vengono aggiunti _a_ un progetto piuttosto che essere progetti a sé stanti. Dai loro lo stesso nome di progetto host per metterli in un unico progetto, o nomi diversi per un progetto ciascuno.
- **Alcune connessioni vincolano i loro endpoint.** Connettere un agent a un altro agent richiede che il target usi il protocollo `a2a`, per esempio. Dove un'impostazione di proprietà romperebbe una connessione che hai disegnato, il builder lo segnala sul componente e sulla connessione.
- **Disegnare una connessione può modificare il target.** Connettere un website a un agent cambia quell'agent al protocollo `ag-ui`, e connettere un agent a un altro agent cambia il target a `a2a` — i protocolli su cui si basano quelle connessioni. Una proprietà che hai impostato tu stesso non viene mai modificata.
