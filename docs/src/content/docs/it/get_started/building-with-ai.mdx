## Già configurato nel tuo workspace

I workspace creati con il preset Nx Plugin for AWS includono la configurazione MCP a livello di progetto per gli agenti di codifica comuni — Claude Code, Cursor, Kiro, Gemini CLI, GitHub Copilot e OpenAI Codex — così un agente che lavora all'interno del workspace può utilizzare il [server MCP](https://modelcontextprotocol.io/introduction) del plugin senza ulteriori configurazioni.

Apri il tuo workspace nel tuo assistente e chiedigli ciò che vuoi:

<Prompt>
Add a React website with an AG-UI agent, an MCP server for its tools and a DynamoDB table, and wire them together.
</Prompt>

Cerca i generatori che il plugin offre, li esegue nell'ordine richiesto dalle loro dipendenze. Usa il tuo agente per compilare la logica di business da lì.

## Installa globalmente

La configurazione del workspace sopra è sufficiente per costruire. Puoi installare globalmente se desideri utilizzare l'AI per creare nuovi workspace, o <Link path="get_started/existing-project">aggiungere il Nx Plugin for AWS a un progetto esistente</Link>:

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    Il Nx Plugin for AWS viene fornito come [Kiro Power](https://kiro.dev/docs/powers/) che raggruppa il server MCP con documentazione di guida e guide del flusso di lavoro.

    <Steps>

    1. Apri il pannello Powers in Kiro e fai clic su **Add power from GitHub**
    2. Inserisci il seguente URL:

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. Fai clic su **Install**

    </Steps>

    Kiro configura automaticamente il server MCP — non è richiesta alcuna configurazione aggiuntiva.

  </TabItem>
  <TabItem label="Kiro CLI">
    Esegui il seguente comando:

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    Consulta la [documentazione Kiro CLI MCP](https://kiro.dev/docs/cli/mcp/) per maggiori dettagli.

  </TabItem>
  <TabItem label="Claude Code">
    Il Nx Plugin for AWS è distribuito come [plugin Claude Code](https://code.claude.com/docs/en/plugins) che raggruppa una [Skill](https://code.claude.com/docs/en/skills) con il server MCP.

    Esegui i seguenti comandi all'interno di Claude Code, uno alla volta:

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    Quindi esegui `/reload-plugins` per attivare il plugin.

  </TabItem>
  <TabItem label="Cursor">
    Aggiungi quanto segue a `~/.cursor/mcp.json` (o `.cursor/mcp.json` nel tuo progetto):

    <Snippet name="mcp/config" />

    Consulta la [documentazione Cursor MCP](https://cursor.com/docs/mcp) per maggiori dettagli.

  </TabItem>
  <TabItem label="Codex">
    Aggiungi quanto segue a `~/.codex/config.toml`:

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    Consulta la [documentazione di configurazione Codex](https://developers.openai.com/codex/config-reference) per maggiori dettagli.

  </TabItem>
  <TabItem label="Other">
    La maggior parte degli assistenti compatibili con MCP utilizza un file di configurazione JSON. Aggiungi la seguente voce:

    <Snippet name="mcp/config" />

    Se riscontri problemi come `ENOENT npx`, sostituisci il comando con il percorso completo di `npx` (trovalo con `which npx`).

    Per la documentazione specifica dell'assistente:

    <Snippet name="mcp/assistant-docs" />

  </TabItem>
</Tabs>

## Inizia a Programmare con Vibe

Con il plugin disponibile globalmente, il tuo assistente può creare anche il workspace. Prova un prompt come:

<Prompt>
Build a multi-agent application using the Nx Plugin for AWS. I want a React frontend that talks to a backend orchestrator agent which delegates to specialised research and writing agents.
</Prompt>

Oppure per un punto di partenza più piccolo:

<Prompt>
Use the Nx Plugin for AWS to scaffold a React website backed by a tRPC API, with Cognito auth and CDK infrastructure.
</Prompt>
