Installa il [Claude Plugin](https://code.claude.com/docs/en/plugins), [Kiro Power](https://kiro.dev/docs/powers/), o [MCP Server](https://modelcontextprotocol.io/introduction) per consentire agli assistenti AI di lavorare efficacemente con il plugin. Utilizzandoli, puoi accelerare il tuo flusso di lavoro di sviluppo con l'AI beneficiando al contempo del fatto che i tuoi progetti vengono strutturati in modo coerente, spendendo meno tempo nella configurazione dei componenti principali e beneficiando della sicurezza, osservabilità, type-safety e sviluppo locale integrati nel plugin.

## Configura il tuo Assistente AI

:::tip[La configurazione a livello di progetto è automatica]
I workspace creati con il preset Nx Plugin for AWS includono già la configurazione MCP a livello di progetto per gli agenti di codifica comuni (Claude Code, Cursor, Kiro, Gemini CLI, GitHub Copilot e OpenAI Codex). Qualsiasi agente che lavora all'interno del workspace può utilizzare il server MCP senza ulteriori configurazioni. I passaggi seguenti configurano il server MCP globalmente per l'uso in tutti i tuoi progetti.
:::

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    Il Nx Plugin for AWS viene fornito come [Kiro Power](https://kiro.dev/docs/powers/) che raggruppa il server MCP con documentazione di guida e guide del flusso di lavoro.

    <Steps>

    1. Apri il pannello Powers in Kiro e fai clic su **Add power from GitHub**
    2. Inserisci il seguente URL:

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. Fai clic su **Install**

    </Steps>

    Kiro configura automaticamente il server MCP — non è richiesta alcuna configurazione aggiuntiva.

  </TabItem>
  <TabItem label="Kiro CLI">
    Esegui il seguente comando:

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    Consulta la [documentazione Kiro CLI MCP](https://kiro.dev/docs/cli/mcp/) per maggiori dettagli.

  </TabItem>
  <TabItem label="Claude Code">
    Il Nx Plugin for AWS è distribuito come [plugin Claude Code](https://code.claude.com/docs/en/plugins) che raggruppa una [Skill](https://code.claude.com/docs/en/skills) con il server MCP.

    Esegui i seguenti comandi all'interno di Claude Code, uno alla volta:

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    Quindi esegui `/reload-plugins` per attivare il plugin.

  </TabItem>
  <TabItem label="Cursor">
    Aggiungi quanto segue a `~/.cursor/mcp.json` (o `.cursor/mcp.json` nel tuo progetto):

    <Snippet name="mcp/config" />

    Consulta la [documentazione Cursor MCP](https://cursor.com/docs/mcp) per maggiori dettagli.

  </TabItem>
  <TabItem label="Codex">
    Aggiungi quanto segue a `~/.codex/config.toml`:

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    Consulta la [documentazione di configurazione Codex](https://developers.openai.com/codex/config-reference) per maggiori dettagli.

## Inizia a Programmare con Vibe

Chiedi al tuo Assistente AI di costruire qualcosa usando il `nx-plugin-for-aws`! Tipicamente creerà un workspace, strutturerà con i generatori applicabili, quindi compilerà la logica di business.

Prova un prompt come:

> _"Costruisci un'applicazione multi-agente usando il Nx Plugin for AWS. Voglio un frontend React che comunichi con un agente orchestratore backend che delega ad agenti specializzati di ricerca e scrittura."_

Oppure per un punto di partenza più piccolo:

> _"Usa il Nx Plugin for AWS per strutturare un sito web React supportato da un'API tRPC, con autenticazione Cognito e infrastruttura CDK."_
