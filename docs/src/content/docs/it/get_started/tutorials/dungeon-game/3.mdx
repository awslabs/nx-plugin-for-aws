## Task 1: Implementare l'agente Story

L'agente Story è un agente [Strands](https://strandsagents.com/) generato con `--protocol=ag-ui` nel <Link path="get_started/tutorials/dungeon-game/1">Modulo 1</Link>, in modo che l'interfaccia utente possa ricevere lo streaming da esso tramite il [protocollo Agent-User Interaction](https://docs.copilotkit.ai/aws-strands/protocol) via CopilotKit. Utilizza il server MCP Inventory per gestire gli oggetti del giocatore e persiste già la cronologia delle conversazioni tramite il `session.py` che il generatore ha fornito nel Modulo 1 — una volta distribuito, si tratta del [`S3SessionManager`](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/agents/sessions/) integrato di Strands che scrive nello stesso bucket S3 da cui legge il `queryActions` dell'API Game, in modo che il browser possa ricostruire le trascrizioni alla rivisitazione.

### Chattare con l'agente

Il target generato `agent-chat` apre un REPL interattivo contro il tuo agente. Viene eseguito in modo autonomo e si connette al tuo agente in esecuzione locale, quindi prima avvia il server locale dell'agente in un terminale:

<NxCommands commands={["agent-dev story"]} />

Quindi, in un secondo terminale, avvia la chat:

<NxCommands commands={["agent-chat story"]} />

Il tuo primo messaggio dovrebbe comunicare all'agente il nome del tuo eroe e il genere (ad esempio: `My name is Alice. Start my zombie adventure.`) e la storia verrà trasmessa in streaming.

<Aside type="caution" title="Credenziali AWS richieste">
Sebbene l'agente venga eseguito localmente, invoca [Amazon Bedrock](https://aws.amazon.com/bedrock/) per l'LLM. Avrai bisogno di credenziali AWS nel tuo ambiente con accesso al [modello predefinito di Strands](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/model-providers/amazon-bedrock/). Consulta la [documentazione sui provider di modelli di Strands](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/model-providers/amazon-bedrock/) per i dettagli.
</Aside>
