Questa guida ti accompagna attraverso un esempio di migrazione di un progetto [AWS PDK](https://github.com/aws/aws-pdk) al Nx Plugin for AWS, fornendo anche indicazioni generali su questo argomento.

La migrazione al Nx Plugin for AWS offre i seguenti vantaggi rispetto a PDK:

- Build più veloci
- Più facile da usare (UI e CLI)
- Adatto al vibe-coding (<Link path="/get_started/building-with-ai">prova il nostro server MCP!</Link>)
- Tecnologie più moderne
- Sviluppo locale di API e siti web
- Maggiore controllo (modifica i file forniti per adattarli al tuo caso d'uso)
- E molto altro!

:::caution[Non è una Guida Passo-Passo]
Ci sono molte sfumature e considerazioni quando si migra un progetto. Questa guida è per un esempio semplice e potrebbero mancare passaggi necessari per il tuo progetto.

Questa guida opta per un approccio in cui creiamo un workspace nuovo e copiamo pezzi dal nostro progetto PDK in un nuovo progetto. Se hai bisogno di migrare in modo diverso, o hai domande sul passaggio da PDK al Nx Plugin for AWS, [contattaci su GitHub discussions](https://github.com/awslabs/nx-plugin-for-aws/discussions)!

Nota anche che alcune funzionalità di PDK non hanno equivalenti esatti. Fai riferimento alla sezione [FAQ](#domande-frequenti) per alcuni suggerimenti/idee per queste.
:::

:::caution[Guida Temporale]
Questa è scritta come una guida temporale e molto probabilmente non verrà aggiornata man mano che il Nx Plugin for AWS evolve. Per compensare questo, la guida fissa la versione di `@aws/nx-plugin` a `1.0.0`. Puoi provare con l'ultima versione se segui la guida, ma potrebbero esserci alcune deviazioni dalla guida.
:::

## Esempio di Migrazione: Applicazione Shopping List

In questa guida, useremo la [Shopping List Application dal Tutorial PDK](https://aws.github.io/aws-pdk/getting_started/shopping_list_app.html) come progetto target da migrare. Segui i passaggi in quel tutorial per creare il progetto target se desideri seguire tu stesso.

L'applicazione shopping list consiste nei seguenti tipi di progetto PDK:

- `MonorepoTsProject`
- `TypeSafeApiProject`
- `CloudscapeReactTsWebsiteProject`
- `InfrastructureTsProject`

### Crea Workspace

Per iniziare, creeremo un nuovo workspace per il nostro nuovo progetto. Sebbene più estremo di una migrazione in loco, questo approccio ci dà il risultato finale più pulito. Creare un workspace Nx è equivalente a usare il `MonorepoTsProject` di PDK:

<CreateNxWorkspaceCommand workspace="shopping-list" iac="cdk" tag="1.0.0" />

Apri la directory `shopping-list` che questo comando crea nel tuo IDE preferito.
