---
title: Metriche di Utilizzo
description: Come @aws/nx-plugin raccoglie le metriche
---

Per aiutarci a migliorare l'Nx Plugin for AWS, raccogliamo metriche sull'utilizzo dei generatori. Questo processo non comporta richieste di rete aggiuntive, sfruttiamo semplicemente le metriche di utilizzo AWS esistenti.

Per rimanere trasparenti, aggiungiamo un ID, una versione e un elenco di ID dei generatori alle descrizioni degli Stack CloudFormation. Questo viene fatto nel `MetricsAspect` in `common/constructs` per CDK o nello stack Cloudformation `metrics.tf` per Terraform.

## Disattivazione

Il codice delle metriche risiede interamente nel tuo workspace, quindi puoi disattivarlo rimuovendolo:

- **CDK**: rimuovi la classe `MetricsAspect` e la chiamata `Aspects.of(this).add(new MetricsAspect())` da `packages/common/constructs/src/core/app.ts`.
- **Terraform**: elimina `packages/common/terraform/src/metrics/metrics.tf`.

I generatori non aggiungeranno nuovamente il codice delle metriche una volta rimosso.
