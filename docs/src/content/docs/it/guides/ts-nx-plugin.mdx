Genera un [Nx Plugin](https://nx.dev/extending-nx/intro/getting-started) TypeScript completo con un server [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) integrato. Questo generatore crea una base per costruire generatori personalizzati che possono essere utilizzati senza problemi dagli assistenti AI per la generazione automatica di codice e lo scaffolding di progetti.

## Utilizzo

### Generare un Nx Plugin

Puoi generare un TypeScript Nx Plugin in due modi:

<RunGenerator generator="ts#nx-plugin" />

### Opzioni

<GeneratorParameters generator="ts#nx-plugin" />

## Output del Generatore

Il generatore creerà la seguente struttura di progetto:

<FileTree>
- your-plugin/
  - src/
    - index.ts Empty entry point for your plugin
    - mcp-server/
      - index.ts Exports your server
      - server.ts Main MCP server configuration
      - stdio.ts Entry point for your MCP server with STDIO transport
      - http.ts Entry point for your MCP server with Streamable HTTP transport
      - tools/
        - create-workspace-command.ts Tool for workspace creation guidance
        - general-guidance.ts Tool for general Nx and plugin guidance
        - list-generators.ts Tool to list available generators
        - generator-guide.ts Tool for detailed generator information
      - utils.ts Utility functions for the MCP server
  - generators.json Nx generator configuration (initially empty)
  - package.json Plugin package configuration
  - tsconfig.json TypeScript configuration (CommonJS for Nx compatibility)
  - project.json Nx project configuration with build and package targets
</FileTree>

## Lavorare con il Tuo Nx Plugin

### Aggiungere Generatori

Una volta che hai il tuo progetto plugin, puoi aggiungere generatori utilizzando il generatore <Link path="/it/guides/nx-generator">`ts#nx-generator`</Link>:

<RunGenerator generator="ts#nx-generator" requiredParameters={{ pluginProject: 'your-plugin' }} />

Questo aggiungerà un nuovo generatore al tuo plugin.

:::tip[Documentazione del Generatore]
Leggi la <Link path="/it/guides/nx-generator">guida `ts#nx-generator`</Link> per i dettagli su come implementare i generatori.
:::

Assicurati di scrivere un `README.md` dettagliato per il tuo generatore, poiché questo viene utilizzato dallo strumento `generator-guide` del MCP Server.

### Target del Progetto

Il plugin generato include diversi target importanti:

#### Target Build
Compila il tuo codice TypeScript e prepara il plugin per l'uso:

<NxCommands commands={['build your-plugin']} />

#### Target Package
Crea un package distribuibile pronto per la pubblicazione su NPM:

<NxCommands commands={['package your-plugin']} />

Il target package include tutte le risorse necessarie:
- File JavaScript compilati
- File di dichiarazione TypeScript
- File di configurazione per generatori ed executor
- Documentazione e file di licenza

## Integrazione MCP Server

Il plugin configura un server MCP utilizzando il generatore <Link path="/it/guides/ts-mcp-server">`ts#mcp-server`</Link>.

### Strumenti

Il plugin include un server MCP completo che fornisce agli assistenti AI i seguenti strumenti:

- `general-guidance`: Ottieni le best practice per lavorare con Nx e il tuo plugin
- `create-workspace-command`: Scopri come creare nuovi workspace che possono utilizzare il tuo plugin
- `list-generators`: Elenca tutti i generatori disponibili nel tuo plugin
- `generator-guide`: Ottieni informazioni dettagliate su generatori specifici inclusi schemi e utilizzo

## Pubblicare il Tuo Plugin

### Preparazione per la Pubblicazione

1. **Aggiorna le Informazioni del Pacchetto**: Modifica il [`package.json`](https://docs.npmjs.com/cli/v10/configuring-npm/package-json) del tuo plugin con nome, versione, descrizione e informazioni sul repository appropriati.

2. **Costruisci il Pacchetto**:
   <NxCommands commands={['package your-plugin']} />

3. **Testa Localmente**: Puoi testare il tuo plugin localmente installandolo in un altro workspace:
   ```bash
   npm install /path/to/your/workspace/dist/your-plugin/package
   ```

### Pubblicazione su NPM

Una volta che il tuo plugin è pronto:

```bash
cd dist/your-plugin/package
npm publish
```

### Utilizzare Plugin Pubblicati

Dopo la pubblicazione, altri possono installare e utilizzare il tuo plugin:

<InstallCommand pkg="your-plugin-name" />

Quindi utilizzare i tuoi generatori:

<RunGenerator namespace="your-plugin-name" generator="your-generator-name" />

#### Configurare Assistenti AI con il Tuo Plugin Pubblicato

Il server MCP del tuo plugin pubblicato può essere configurato come segue:

```json {3-6}
{
  "mcpServers": {
    "aws-nx-mcp": {
      "command": "npx",
      "args": ["-y", "-p", "your-plugin-name", "your-plugin-name-mcp-server"]
    }
  }
}
```
