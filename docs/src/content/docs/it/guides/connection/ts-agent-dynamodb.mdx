Il generatore `connection` collega un <Link path="guides/ts-agent">TypeScript Agent</Link> a un progetto <Link path="guides/ts-dynamodb">TypeScript DynamoDB</Link>, configurando lo sviluppo locale in modo che entrambi si avviino insieme automaticamente.

## Prerequisiti

Prima di utilizzare questo generatore, assicurati di avere:

1. Un progetto <Link path="guides/ts-agent">`ts#agent`</Link>
2. Un progetto <Link path="guides/ts-dynamodb">`ts#dynamodb`</Link>

## Output del Generatore

Il generatore aggiorna il target `<agent-name>-dev` dell'agent in `project.json` per dipendere dal target `dev` del progetto DynamoDB. Nessun file sorgente viene modificato.

## Utilizzare DynamoDB negli Agent

Importa le factory di entità dal pacchetto DynamoDB e utilizzale all'interno della definizione del tuo agent:

```ts title="packages/my-service/src/my-agent/agent.ts"
import { createExampleEntity } from '@my-scope/my-table';
import { z } from 'zod';

const listExamples = tool({
  name: 'list_examples',
  description: 'List all example items',
  inputSchema: z.object({}),
  callback: async () => {
    const entity = await createExampleEntity();
    const result = await entity.scan.go();
    return result.data;
  },
});

export const getAgent = async () => {
  // ...
  return new Agent({
    tools: [listExamples],
  });
};
```

## Infrastruttura

Per consentire alla funzione Lambda dell'agent di accedere alla tabella DynamoDB, concedi le autorizzazioni necessarie nella tua infrastruttura.

<Infrastructure>
<Fragment slot="cdk">

```ts title="packages/infra/src/stacks/application-stack.ts"
import { MyTable } from '@my-scope/common-constructs';

const table = new MyTable(this, 'Table');
const myAgent = new MyAgent(this, 'MyAgent');

table.grantReadWriteData(myAgent);
```

`grantReadWriteData` concede sia le autorizzazioni DynamoDB che KMS al ruolo di esecuzione dell'agent.
</Fragment>
<Fragment slot="terraform">

Concedi al ruolo di runtime dell'agent l'accesso alla tabella e alla sua chiave di crittografia KMS tramite `additional_iam_policy_statements`:

```hcl title="packages/infra/src/main.tf"
module "my_table" {
  source = "../../common/terraform/src/app/dynamodb/my-table"
}

module "my_agent" {
  source = "../../common/terraform/src/app/agents/my-agent"

  additional_iam_policy_statements = [
    {
      Effect = "Allow"
      Action = [
        "dynamodb:GetItem", "dynamodb:PutItem", "dynamodb:UpdateItem",
        "dynamodb:DeleteItem", "dynamodb:Query", "dynamodb:Scan",
        "dynamodb:BatchGetItem", "dynamodb:BatchWriteItem",
      ]
      Resource = [
        module.my_table.table_arn,
        "${module.my_table.table_arn}/index/*",
      ]
    },
    {
      Effect = "Allow"
      Action = [
        "kms:Encrypt",
        "kms:Decrypt",
        "kms:ReEncrypt*",
        "kms:GenerateDataKey*",
        "kms:DescribeKey",
      ]
      Resource = [module.my_table.kms_key_arn]
    },
  ]
}
```
</Fragment>
</Infrastructure>
