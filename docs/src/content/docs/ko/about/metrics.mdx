---
title: 사용 메트릭
description: "@aws/nx-plugin이 메트릭을 수집하는 방법"
---

Nx Plugin for AWS를 개선하는 데 도움을 주기 위해 제너레이터 사용에 대한 메트릭을 수집합니다. 이 프로세스는 추가 네트워크 요청을 포함하지 않으며, 단순히 기존 AWS 사용 메트릭을 활용합니다.

투명성을 유지하기 위해 CloudFormation Stack 설명에 ID, 버전 및 제너레이터 ID 목록을 추가합니다. 이는 CDK의 경우 `common/constructs`의 `MetricsAspect`에서 수행되며, Terraform의 경우 `metrics.tf` Cloudformation 스택에서 수행됩니다.

## 옵트아웃

메트릭 코드는 전적으로 워크스페이스에 존재하므로 제거하여 옵트아웃할 수 있습니다:

- **CDK**: `packages/common/constructs/src/core/app.ts`에서 `MetricsAspect` 클래스와 `Aspects.of(this).add(new MetricsAspect())` 호출을 제거합니다.
- **Terraform**: `packages/common/terraform/src/metrics/metrics.tf`를 삭제합니다.

제너레이터는 메트릭 코드가 제거된 후 다시 추가하지 않습니다.
