PDK는 CDK 인프라 프로젝트를 설정하고 일부 [CDK Pipelines](https://docs.aws.amazon.com/cdk/api/v2/docs/aws-cdk-lib.pipelines-readme.html) 리소스를 래핑한 CDK 구성 요소를 사용하는 [`PDKPipelineProject`](https://aws.github.io/aws-pdk/developer_guides/pipeline/index.html)를 제공했습니다.

이를 마이그레이션하려면 CDK Pipelines 구성 요소를 직접 사용할 수 있습니다. 그러나 실제로는 GitHub actions 또는 GitLab CI/CD와 같은 것을 사용하는 것이 더 간단할 수 있습니다. 여기서 [CDK Stages](https://docs.aws.amazon.com/cdk/v2/guide/stages.html)를 정의하고 적절한 스테이지에 대한 배포 명령을 직접 실행합니다.
