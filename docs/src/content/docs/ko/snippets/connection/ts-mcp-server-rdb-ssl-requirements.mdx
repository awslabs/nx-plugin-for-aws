---
title: RDS Proxy 없이 연결할 때 SSL 요구사항
---

MCP 서버가 RDS Proxy 없이 Aurora 클러스터에 연결할 때, Node.js는 Amazon RDS 인증 기관(CA)을 신뢰해야 합니다. Node.js는 운영 체제 신뢰 저장소를 읽지 않습니다. `NODE_EXTRA_CA_CERTS` 환경 변수가 가리키는 파일에서만 추가 CA 인증서를 로드합니다.

- MCP 서버의 `infra`가 `agentcore-ecr`인 경우, 연결 생성기가 Dockerfile을 업데이트합니다. Amazon RDS CA 번들을 `/usr/local/share/ca-certificates/rds-bundle.crt`에 다운로드하고 `NODE_EXTRA_CA_CERTS`를 해당 경로로 설정하므로 구성할 것이 없습니다. 이전 플러그인 버전에서 생성된 Dockerfile의 경우 `nx migrate`가 `NODE_EXTRA_CA_CERTS` 라인을 추가합니다.
- MCP 서버의 `infra`가 `agentcore`(기본값)인 경우, MCP 서버는 RDS CA 번들을 포함하지 않는 코드 패키지로 배포됩니다. RDS Proxy를 활성화 상태로 유지하거나(기본값) `agentcore-ecr`을 사용하세요.

자세한 내용은 [Amazon RDS SSL/TLS 문서](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/UsingWithRDS.SSL.html)를 참조하세요. RDS Proxy를 사용하는 경우 `NODE_EXTRA_CA_CERTS`를 구성할 필요가 없습니다.
