:::note[인프라 프로젝트 필요]
에이전트, MCP 서버 및 Gateway 생성기는 구성 요소와 모듈을 `packages/common`으로 제공하지만, 이를 배포할 애플리케이션을 생성하지는 않습니다. 따라서 `packages/infra`는 생성하기 전까지 존재하지 않습니다. 아래 파일을 편집하기 전에 <Link path="guides/typescript-infrastructure">`ts#infra`</Link> 생성기(CDK) 또는 <Link path="guides/terraform-project">`terraform#project`</Link> 생성기(Terraform)를 실행하세요.
:::
