:::note[CDK CORS 구성]
솔루션에 웹사이트가 포함된 경우 HTTP / REST API용 API 게이트웨이 / API AWS Lambda 통합에서 해당 CloudFront 배포를 유일하게 허용된 CORS 원본으로 구성할 수 있습니다.
웹사이트 구성, CloudFront 배포, 원본 문자열 또는 이들의 조합으로 API `restrictCorsTo` 메서드를 호출할 수 있습니다.

```ts
import { MyApi, MyWebsite } from '@my-scope/common-constructs';

export class ExampleStack extends Stack {
  constructor(scope: Construct, id: string) {
    const api = new MyApi(this, 'MyApi', {
      integrations: MyApi.defaultIntegrations(this).build(),
    });
    const website = new MyWebsite(this, 'MyWebsite');
    api.restrictCorsTo(website, 'http://localhost:4200', 'http://localhost:4300');
  }
}
```

`MyWebsite` 구성은 <Link path="/guides/react-website">`ts#website` 생성기</Link>를 사용하여 생성할 수 있습니다. 이 예제는 웹사이트의 로컬 개발 서버 및 미리보기 포트가 `4200`/`4300`이라고 가정합니다 - 이 방식으로 생성된 각 웹사이트는 고유한 포트를 가지므로 실제로 할당된 포트는 `project.json`(또는 `vite.config.mts`)을 확인하세요.
:::
