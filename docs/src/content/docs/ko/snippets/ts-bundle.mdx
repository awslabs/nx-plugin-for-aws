import NxCommands from '@components/nx-commands.astro';

제너레이터는 [Rolldown](https://rolldown.rs/)을 사용하여 배포 패키지를 생성하는 `bundle` 타겟을 자동으로 구성합니다:

<NxCommands commands={['bundle <project-name>']} />

Rolldown 구성은 `rolldown.config.ts`에서 찾을 수 있으며, 생성할 번들마다 항목이 있습니다. Rolldown은 정의된 경우 여러 번들을 병렬로 생성하는 것을 관리합니다.

:::tip[사용자 정의 구성]
`rolldown.config.ts`에서 Rolldown 구성을 조정할 수 있습니다. 예를 들어 파일 경로에 의존하고 번들링할 수 없는 종속성이 있는 경우 `external` 모듈 목록에 추가할 수 있습니다.
:::
