이 생성기는 웹사이트가 API를 호출하는 것과 같이 프로젝트를 서로 연결하는 데 사용됩니다. 소스 프로젝트(예: API를 호출할 프로젝트)와 대상 프로젝트(예: API 프로젝트)를 선택하기만 하면 이 생성기가 두 프로젝트를 통합하는 작업을 처리합니다.

:::tip[시각적으로 스케치하기]
워크스페이스를 먼저 설계하고 싶으신가요? <Link path="get_started/graph-builder">Graph Builder</Link>를 사용하면 프로젝트를 드래그하고 프로젝트 간의 연결을 그린 다음, 전체를 스캐폴딩하는 명령을 제공합니다.
:::

## 사용법

### 생성기 실행

<RunGenerator generator="connection" />

### 옵션

<GeneratorParameters generator="connection" />

:::note[런타임 구성]
connection 생성기는 <Link path="guides/runtime-config">Runtime Configuration</Link>을 사용하여 배포 시점 값(예: API URL, Cognito 설정, 에이전트 런타임 ARN)을 생성된 프로젝트와 컴포넌트 간에 런타임에 전달하여 서로를 검색하고 연결할 수 있도록 합니다.
:::

:::tip[로컬 개발]
연결된 프로젝트는 `serve` 및 `dev` 타겟을 사용하여 로컬 머신에서 실행할 수 있습니다. 자세한 내용은 <Link path="guides/local-development">Local Development</Link> 가이드를 참조하세요.
:::
