이 가이드는 [AWS PDK](https://github.com/aws/aws-pdk) 프로젝트를 Nx Plugin for AWS로 마이그레이션하는 예제를 안내하고, 이 주제에 대한 일반적인 지침을 제공합니다.

Nx Plugin for AWS로 마이그레이션하면 PDK 대비 다음과 같은 이점을 얻을 수 있습니다:

- 더 빠른 빌드
- 더 쉬운 사용 (UI 및 CLI)
- 바이브 코딩 친화적 (<Link path="/get_started/building-with-ai">MCP 서버를 사용해보세요!</Link>)
- 더 현대적인 기술
- 로컬 API 및 웹사이트 개발
- 더 많은 제어 (사용 사례에 맞게 제공된 파일 수정 가능)
- 그리고 더 많은 것들!

:::caution[단계별 가이드가 아닙니다]
프로젝트를 마이그레이션할 때 고려해야 할 많은 뉘앙스와 사항들이 있습니다. 이 가이드는 간단한 예제를 위한 것이며, 여러분의 프로젝트에 필요한 단계가 여기에 누락되어 있을 수 있습니다.

이 가이드는 새로운 워크스페이스를 생성하고 PDK 프로젝트의 일부를 새 프로젝트로 복사하는 접근 방식을 선택합니다. 다르게 마이그레이션해야 하거나 PDK에서 Nx Plugin for AWS로 이동하는 것에 대한 질문이 있다면, [GitHub 토론에서 문의하세요](https://github.com/awslabs/nx-plugin-for-aws/discussions)!

또한 PDK의 일부 기능은 정확히 동등한 기능이 없을 수 있습니다. 이에 대한 힌트/아이디어는 [FAQ](#frequently-asked-questions) 섹션을 참조하세요.
:::

:::caution[특정 시점 가이드]
이 가이드는 특정 시점의 가이드로 작성되었으며 Nx Plugin for AWS가 발전함에 따라 업데이트되지 않을 가능성이 높습니다. 이를 보완하기 위해 가이드는 `@aws/nx-plugin` 버전을 `1.0.0-rc.47`로 고정합니다. 따라하실 때 최신 버전으로 시도할 수 있지만, 가이드와 약간의 차이가 있을 수 있습니다.
:::

## 예제 마이그레이션: 쇼핑 목록 애플리케이션

이 가이드에서는 [PDK 튜토리얼의 쇼핑 목록 애플리케이션](https://aws.github.io/aws-pdk/getting_started/shopping_list_app.html)을 마이그레이션 대상 프로젝트로 사용합니다. 직접 따라하고 싶다면 해당 튜토리얼의 단계를 따라 대상 프로젝트를 생성하세요.

쇼핑 목록 애플리케이션은 다음 PDK 프로젝트 타입으로 구성됩니다:

- `MonorepoTsProject`
- `TypeSafeApiProject`
- `CloudscapeReactTsWebsiteProject`
- `InfrastructureTsProject`

### 워크스페이스 생성

시작하려면 새 프로젝트를 위한 새 워크스페이스를 생성합니다. 제자리 마이그레이션보다 더 극단적이지만, 이 접근 방식은 가장 깔끔한 최종 결과를 제공합니다. Nx 워크스페이스를 생성하는 것은 PDK의 `MonorepoTsProject`를 사용하는 것과 동등합니다:

<CreateNxWorkspaceCommand workspace="shopping-list" iac="cdk" tag="1.0.0-rc.47" />

이 명령이 생성하는 `shopping-list` 디렉토리를 선호하는 IDE에서 엽니다.
