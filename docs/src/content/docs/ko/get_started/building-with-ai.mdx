[Claude Plugin](https://code.claude.com/docs/en/plugins), [Kiro Power](https://kiro.dev/docs/powers/), 또는 [MCP Server](https://modelcontextprotocol.io/introduction)를 설치하여 AI 어시스턴트가 플러그인과 효과적으로 작동하도록 할 수 있습니다. 이를 사용하면 AI로 개발 워크플로를 가속화할 수 있으며, 프로젝트가 일관된 방식으로 스캐폴딩되어 주요 구성 요소 설정에 소요되는 시간을 줄이고 플러그인에 내장된 보안, 관찰성, 타입 안전성 및 로컬 개발의 이점을 누릴 수 있습니다.

## AI 어시스턴트 구성하기

:::tip[프로젝트 수준 구성은 자동입니다]
Nx Plugin for AWS 프리셋으로 생성된 워크스페이스에는 일반적인 코딩 에이전트(Claude Code, Cursor, Kiro, Gemini CLI, GitHub Copilot 및 OpenAI Codex)를 위한 프로젝트 수준 MCP 구성이 이미 포함되어 있습니다. 워크스페이스 내에서 작동하는 모든 에이전트는 추가 설정 없이 MCP 서버를 사용할 수 있습니다. 아래 단계는 모든 프로젝트에서 사용할 수 있도록 MCP 서버를 전역으로 구성합니다.
:::

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    Nx Plugin for AWS는 MCP 서버를 스티어링 문서 및 워크플로 가이드와 함께 번들로 제공하는 [Kiro Power](https://kiro.dev/docs/powers/)로 제공됩니다.

    <Steps>

    1. Kiro에서 Powers 패널을 열고 **Add power from GitHub**를 클릭합니다
    2. 다음 URL을 입력합니다:

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. **Install**을 클릭합니다

    </Steps>

    Kiro는 MCP 서버를 자동으로 구성하므로 추가 설정이 필요하지 않습니다.

  </TabItem>
  <TabItem label="Kiro CLI">
    다음 명령을 실행합니다:

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    자세한 내용은 [Kiro CLI MCP docs](https://kiro.dev/docs/cli/mcp/)를 참조하세요.

  </TabItem>
  <TabItem label="Claude Code">
    Nx Plugin for AWS는 [Skill](https://code.claude.com/docs/en/skills)과 MCP 서버를 번들로 제공하는 [Claude Code plugin](https://code.claude.com/docs/en/plugins)으로 배포됩니다.

    Claude Code 내에서 다음 명령을 한 번에 하나씩 실행합니다:

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    그런 다음 `/reload-plugins`를 실행하여 플러그인을 활성화합니다.

  </TabItem>
  <TabItem label="Cursor">
    `~/.cursor/mcp.json`(또는 프로젝트의 `.cursor/mcp.json`)에 다음을 추가합니다:

    <Snippet name="mcp/config" />

    자세한 내용은 [Cursor MCP docs](https://cursor.com/docs/mcp)를 참조하세요.

  </TabItem>
  <TabItem label="Codex">
    `~/.codex/config.toml`에 다음을 추가합니다:

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    자세한 내용은 [Codex config docs](https://developers.openai.com/codex/config-reference)를 참조하세요.

  </TabItem>
  <TabItem label="Other">

## Vibe Coding 시작하기

AI 어시스턴트에게 `nx-plugin-for-aws`를 사용하여 무언가를 빌드하도록 요청하세요! 일반적으로 워크스페이스를 생성하고 해당 제너레이터로 스캐폴딩한 다음 비즈니스 로직을 채웁니다.

다음과 같은 프롬프트를 시도해 보세요:

> _"Nx Plugin for AWS를 사용하여 멀티 에이전트 애플리케이션을 빌드해줘. 전문화된 연구 및 작성 에이전트에 위임하는 백엔드 오케스트레이터 에이전트와 통신하는 React 프론트엔드를 원해."_

또는 더 작은 시작점으로:

> _"Nx Plugin for AWS를 사용하여 Cognito 인증 및 CDK 인프라가 있는 tRPC API로 지원되는 React 웹사이트를 스캐폴딩해줘."_
