## 워크스페이스에 이미 구성되어 있습니다

Nx Plugin for AWS 프리셋으로 생성된 워크스페이스에는 일반적인 코딩 에이전트(Claude Code, Cursor, Kiro, Gemini CLI, GitHub Copilot 및 OpenAI Codex)를 위한 프로젝트 수준 MCP 구성이 포함되어 있으므로, 워크스페이스 내에서 작동하는 에이전트는 추가 설정 없이 플러그인의 [MCP server](https://modelcontextprotocol.io/introduction)를 사용할 수 있습니다.

워크스페이스를 어시스턴트에서 열고 원하는 것을 요청하세요:

<Prompt>
Add a React website with an AG-UI agent, an MCP server for its tools and a DynamoDB table, and wire them together.
</Prompt>

플러그인이 제공하는 제너레이터를 조회하고, 의존성이 필요한 순서대로 실행한 다음, 비즈니스 로직을 채웁니다.

## 전역으로 설치

위의 <Link path="get_started/quick-start">워크스페이스 구성</Link>만으로도 빌드하기에 충분합니다. 모든 프로젝트에서 MCP 서버를 사용하고 싶다면 플러그인이나 파워도 설치하세요:

<Tabs syncKey="ai-assistant">
  <TabItem label="Kiro">
    Nx Plugin for AWS는 MCP 서버를 스티어링 문서 및 워크플로 가이드와 함께 번들로 제공하는 [Kiro Power](https://kiro.dev/docs/powers/)로 제공됩니다.

    <Steps>

    1. Kiro에서 Powers 패널을 열고 **Add power from GitHub**를 클릭합니다
    2. 다음 URL을 입력합니다:

       ```
       https://github.com/awslabs/nx-plugin-for-aws/tree/main/powers/nx-plugin-for-aws
       ```

    3. **Install**을 클릭합니다

    </Steps>

    Kiro는 MCP 서버를 자동으로 구성하므로 추가 설정이 필요하지 않습니다.

  </TabItem>
  <TabItem label="Kiro CLI">
    다음 명령을 실행합니다:

    ```bash
    kiro-cli mcp add \
      --name nx-plugin-for-aws \
      --scope global \
      --command npx \
      --args "-y,@aws/nx-plugin-mcp"
    ```

    자세한 내용은 [Kiro CLI MCP docs](https://kiro.dev/docs/cli/mcp/)를 참조하세요.

  </TabItem>
  <TabItem label="Claude Code">
    Nx Plugin for AWS는 [Skill](https://code.claude.com/docs/en/skills)과 MCP 서버를 번들로 제공하는 [Claude Code plugin](https://code.claude.com/docs/en/plugins)으로 배포됩니다.

    Claude Code 내에서 다음 명령을 한 번에 하나씩 실행합니다:

    ```
    /plugin marketplace add awslabs/nx-plugin-for-aws
    ```

    ```
    /plugin install nx-plugin-for-aws@nx-plugin-for-aws
    ```

    그런 다음 `/reload-plugins`를 실행하여 플러그인을 활성화합니다.

  </TabItem>
  <TabItem label="Cursor">
    `~/.cursor/mcp.json`(또는 프로젝트의 `.cursor/mcp.json`)에 다음을 추가합니다:

    <Snippet name="mcp/config" />

    자세한 내용은 [Cursor MCP docs](https://cursor.com/docs/mcp)를 참조하세요.

  </TabItem>
  <TabItem label="Codex">
    `~/.codex/config.toml`에 다음을 추가합니다:

    ```toml
    [mcp_servers.nx-plugin-for-aws]
    command = "npx"
    args = ["-y", "@aws/nx-plugin-mcp"]
    ```

    자세한 내용은 [Codex config docs](https://developers.openai.com/codex/config-reference)를 참조하세요.

  </TabItem>
  <TabItem label="Other">
    대부분의 MCP 호환 어시스턴트는 JSON 구성 파일을 사용합니다. 다음 항목을 추가합니다:

    <Snippet name="mcp/config" />

    `ENOENT npx`와 같은 문제가 발생하면 명령을 `npx`의 전체 경로로 바꾸세요(`which npx`로 찾을 수 있습니다).

    어시스턴트별 문서는 다음을 참조하세요:

    <Snippet name="mcp/assistant-docs" />

  </TabItem>
</Tabs>

<Prompt>
Build a multi-agent application using the Nx Plugin for AWS. I want a React frontend that talks to a backend orchestrator agent which delegates to specialised research and writing agents.
</Prompt>

또는 더 작은 시작점으로:

Use the Nx Plugin for AWS to scaffold a React website backed by a tRPC API, with Cognito auth and CDK infrastructure.
</Prompt>
