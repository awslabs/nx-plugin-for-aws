## 작업 1: Story 에이전트 구현

Story 에이전트는 <Link path="get_started/tutorials/dungeon-game/1">모듈 1</Link>에서 `--protocol=ag-ui`로 생성된 [Strands](https://strandsagents.com/) 에이전트로, UI가 CopilotKit을 통해 [Agent-User Interaction protocol](https://docs.copilotkit.ai/aws-strands/protocol)로 스트리밍할 수 있습니다. 플레이어의 아이템을 관리하기 위해 Inventory MCP Server를 사용하며, 모듈 1에서 생성기가 프로비저닝한 `session.py`를 통해 대화 기록을 이미 유지합니다 — 배포되면 이는 Strands의 내장 [`S3SessionManager`](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/agents/sessions/)가 Game API의 `queryActions`가 읽는 동일한 S3 버킷에 쓰는 것이므로, 브라우저가 재방문 시 대화 기록을 재구성할 수 있습니다.

### 에이전트 구현

`packages/story/dungeon_adventure_story/agent`의 `agent.py`를 업데이트합니다:

<E2EDiff lang="python" before="dungeon-adventure/3/agent.py.old.template" after="dungeon-adventure/3/agent.py.template" />

`agent.py`는 샘플 `subtract` 도구를 제거하고 시스템 프롬프트를 던전 마스터 프롬프트로 교체합니다. 이 프롬프트는 첫 번째 사용자 메시지에서 플레이어의 이름과 장르를 명시하도록 유도하며, Inventory MCP Server의 도구를 사용합니다. `main.py`는 여기서 변경할 필요가 없습니다 — 에이전트가 생성될 때 세션 관리가 이미 연결되어 있었습니다.

## 작업 2: 로컬에서 에이전트 테스트

### 코드 빌드

코드를 빌드하려면:

<PackageManagerShortCommand commands={["build"]} />

<Aside type="tip" title="린트 오류 수정">
린트 오류가 발생하면 다음 명령을 실행하여 자동으로 수정할 수 있습니다.

<PackageManagerShortCommand commands={["lint"]} />
</Aside>

<Aside type="tip" title="The workspace is out of sync">
빌드에서 `The workspace is out of sync`라고 보고하면 `nx sync`를 실행하고 다시 빌드하세요.
</Aside>

### 에이전트와 대화하기

생성된 `agent-chat` 타겟은 에이전트에 대한 대화형 REPL을 엽니다. 독립적으로 실행되며 로컬에서 실행 중인 에이전트에 연결되므로, 먼저 한 터미널에서 에이전트의 로컬 서버를 시작합니다:

<NxCommands commands={["agent-dev story"]} />

그런 다음 두 번째 터미널에서 채팅을 시작합니다:

<NxCommands commands={["agent-chat story"]} />

첫 번째 메시지는 에이전트에게 영웅의 이름과 장르를 알려야 합니다(예: `My name is Alice. Start my zombie adventure.`). 그러면 스토리가 스트리밍됩니다.

<Aside type="caution" title="AWS 자격 증명 필요">
에이전트가 로컬에서 실행되지만 LLM을 위해 [Amazon Bedrock](https://aws.amazon.com/bedrock/)을 호출합니다. [Strands 기본 모델](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/model-providers/amazon-bedrock/)에 액세스할 수 있는 AWS 자격 증명이 환경에 필요합니다. 자세한 내용은 [Strands 모델 제공자 문서](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/model-providers/amazon-bedrock/)를 참조하세요.
</Aside>
